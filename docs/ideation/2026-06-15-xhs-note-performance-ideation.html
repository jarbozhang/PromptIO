I1.

路线图型收藏机器

Confidence 90%Complexity Low
Description
把“单个项目介绍”改成“中文用户怎么选路径”：每篇围绕 3-5 个同类资源、适合谁、从哪里开始、坑在哪里、今晚能做什么。标题优先使用“从零”“四条路”“路线图”“怎么选”“中文教程”这类明确收藏意图词。
Axis
收藏/转发价值
Basis
direct: “从零学大模型，国内中文教程已经有四条路” 1,138 浏览、86 赞、198 收藏、29 分享；“我跟着 GitHub 42k 星的中文指南用 Gemini” 966 浏览、99 赞、203 收藏、35 分享但未通过；本地 dive-into-llms xhs 版正文包含“四个教程各自适合谁 / 按起点选路线 / 几个坑提前讲”。
Rationale
这类内容的浏览未必最高，但收藏率最高，且能建立账号的“技术路线规划”定位。关键是用国内可访问入口替代境外工具教程，保留学习路径价值，去掉规则风险。
Downsides
需要更多同类资源横向整理；标题不能过度承诺“唯一/最全”，否则会落入虚假夸张。
I2.

本地可跑低成本系列

Confidence 88%Complexity Low
Description
把 AI 模型新闻落到“普通人/国内开发者能不能跑、花多少钱、需要什么设备、替代入口是什么”。固定结构为：一句话结论、硬件/费用门槛、国内入口、可复现步骤、适合/不适合谁。
Axis
流量触发器
Basis
direct: “Google偷偷上架了一个不联网的AI听写App” 5,303 浏览；“免费满血Gemma 4本地跑” 4,937 浏览；“一张4090就够-Gemma 4离线知识库Agent完整” 775 浏览；“DGX Spark 单卡跑 Qwen3.6-35B 100+ tok/s” 688 浏览。
Rationale
后台显示“免费、本地、离线、单卡、安卓机、4090”是技术内容在小红书上的强翻译器：它把抽象模型能力翻译成成本、设备和可操作性。
Downsides
容易滑向硬件党小圈层；需要避免海淘、灰色资源、破解授权等实现路径。
I3.

高需求题材的安全壳

Confidence 82%Complexity Medium
Description
保留“赚钱、交易、商业效率”这类强需求题材，但统一套安全壳：不承诺收益、不教实盘、不导流接单、不把模拟盘写成真实结果。内容焦点放在架构复盘、风险提示、工具边界和可迁移工作流。
Axis
平台规则与风控
Basis
direct: “交大学生用Claude Code做了个交易bot” 17,729 浏览、776 收藏、249 分享，是全样本第一；本地稿件正文明确写“模拟交易所”“不是真金白银”“不构成金融、投资或交易建议”“跑完别直接去开通实盘”。
Rationale
强需求题材能带来最大初始流量，但规则风险也最大。这个方向的可复制部分不是“收益标题”，而是“强钩子 + 正文降风险 + 架构学习价值”。
Downsides
金融、赚钱、副业类题材天然敏感；需要更严格 QA，且不适合连续密集发布。
I4.

GitHub Trending 本土化模板

Confidence 78%Complexity Medium
Description
把 GitHub 增长信号做成固定模板：为什么突然火、解决什么中国用户痛点、国内可用替代入口、我会怎么试、哪些人不该跟。标题保留 star 数，但不让项目名和英文名占满前半句。
Axis
流量触发器
Basis
direct: “一天涨 2548 个 star，这个开源项目想干掉” 1,191 浏览、178 收藏、54 分享；“Datawhale hello-agents 一夜涨 1197 星” 99 浏览但 10 赞、11 收藏、3 分享，互动率高；“一个开源工具用 LLM 翻译整本书” 382 浏览、52 收藏。
Rationale
Trending 是可靠选题雷达，但必须二次翻译成小红书语言。后台低分样本说明，仅写项目名、作者名或工具目录很难获得平台初始理解。
Downsides
容易被同质化账号模仿；需要保持“国内怎么用/坑在哪”的独家判断。
I5.

标题中文化与场景化闸门

Confidence 84%Complexity Low
Description
发布小红书前，把标题过一遍“中文场景闸门”：前 18 个字必须回答一个中文用户能立刻理解的问题，例如省钱、跑通、替代、学习路线、设备门槛、真实风险。英文项目名可以出现，但不能承担主钩子。
Axis
标题与受众可读性
Basis
direct: “一行 curl 查全网 AI 模型价格，models.dev” 2 浏览；“Simon Willison 用 5 分钟把过去 6 个月 LL” 2 浏览；“Clawdmeter 把 Claude Code 用量做成桌面小” 3 浏览。相对地，“Google偷偷上架了一个不联网的AI听写App” 5,303 浏览，“免费满血Gemma 4本地跑” 4,937 浏览。
Rationale
平台初始分发需要快速判断内容给谁看。纯工具名/英文人名标题让算法和用户都难以归类，中文场景标题能把技术内容翻译成明确需求。
Downsides
标题重写可能损失一部分极客风格；需要避免写成夸张营销号。
I6.

发布前规则信号仪表盘

Confidence 86%Complexity Medium
Description
把小红书发布前检查从“写完再修”前移到选题和标题阶段，输出一个三色信号：红色为未通过高危，黄色为可能仅自己可见/降分发，绿色为可发。规则至少覆盖拉踩评测、境外访问教程、玄学、收益承诺、站外导流、自动化运营。
Axis
生产流程改造
Basis
direct: 后台未通过只有 3 条，且和本地合规文件列出的三类案例完全对齐；公开笔记浏览中位数 382，仅自己可见中位数 46，说明“通过但仅自己可见/私密”的分发差异也需要单独处理。
Rationale
当前风险不是没有规则，而是规则太靠后。把规则信号变成选题门和标题门，可以避免高价值内容写完后才发现不适合小红书。
Downsides
需要维护规则和例外；过严会误杀有传播潜力的争议题，需要保留人工 override。

Rejection Summary

#IdeaReason Rejected
1继续复制“X 干掉 / 吊打 Y”的冲突标题后台未通过样本和本地规则都指向拉踩评测风险；短期可拿点击，长期会伤账号。
2境外工具教程照常写，只在末尾加免责声明Gemini 英语稿收藏率很强但未通过；问题在访问教程本身，不是免责声明不够。
3恢复 AI 玄学/占卜/风水选题明确未通过且本地复盘归为封建迷信；属于强制排除，不值得优化表达。
4纯工具目录型内容批量发布models.dev、Simon Willison、Clawdmeter 等低分样本显示，缺少中文用户场景时初始分发极差。
5只追最高浏览，不看收藏和规则最高浏览集中在高需求题材；若忽略风险壳，会把“有效钩子”误读成“可无脑复制的标题”。
6把所有仅自己可见都视为平台惩罚后台只显示“仅自己可见”，可能来自主动设置或历史状态；文档只把它作为分发限制信号，不作为违规结论。
