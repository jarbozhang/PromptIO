## 高风险品类（触发即需加固）

**R1 评测对比类**，任何文章出现"X 好于 Y""X 不如 Y""X 比 Y 强/弱"
**R2 境外工具类**，涉及 ChatGPT web、Gemini web、Claude web、Midjourney web 等国内无法直接访问的服务
**R3 玄学/传统文化应用类**，算命、风水、八字、占卜、塔罗、运势、符咒、开光、预测未来

## 规则分层

### Layer 1，选题门过滤（scoring 阶段）

**强制排除（REACH 不计算，直接跳过）：**
- 标题或正文涉及算命、风水、八字、占卜、塔罗、运势测算、符咒、开光、代参拜、代开光
- 标题或正文把 AI 和"预测未来""改变命运""转运""招财"等结果承诺并列
- 主旨是"如何翻墙/科学上网/魔法上网使用 X"
- 主旨是"境外软件国内怎么登录"
- 标题句式是"X 干翻/吊打/砍掉/杀死/完爆 Y"（纯拉踩）
- 标题句式是"X 平替 Y"，其中 Y 是活跃在运营的竞品品牌

**降权（REACH -2）：**
- 评测对比类（涉及 2 个或以上在运营竞品的优劣对比）
- "X 是 Y 平替"句式（即使 Y 已过气）
- "X 订阅可以退了"""X 可以卸载了"类标题（贬损竞品服务）

### Layer 2，写作层约束（wechat.md 增补）

**标题禁用句式：**

禁止以下模式出现在标题：
- X 干翻/吊打/砍掉/杀死/完爆 Y
- X 订阅可以退了/可以卸载了
- X 不如 Y/X 好于 Y（直接断言式对比）
- X 真的凉了/要凉了
- X 变笨了/变差了（针对活跃竞品）

**允许的对比句式：**
- 带限定词，"在 XX 场景下 X 比 Y 快"
- 带数据，"X 的 YY benchmark 得分 Z 分"
- 客观描述，"X 和 Y 各自的设计取向"
- 中立并列，"国产 X 和 Y 同天发布，各有侧重"

**境外工具提及规范：**
- 可以讲境外工具的事件、技术、发布（新闻/解读类安全）
- 不可以给访问教程（注册、登录、下单、连接流程）
- 推荐使用方式必须是国内可访问的路径，OpenRouter、Hugging Face 镜像、国内云 API、开源本地部署
- 绝对禁用词，翻墙、梯子、科学上网、魔法上网、全局代理、自建节点、机场、订阅链接、Clash、V2Ray、SS、SSR、Shadowsocks

**玄学话题完全禁区：**
- 算命、风水、八字、占卜、塔罗、运势、符咒、开光、道教法器、预测未来、改变命运、转运、招财、破财、开运、命格、紫微斗数、奇门遁甲、易经预测
- "AI + 传统文化"的安全角度仍可写，如 AI 做古籍 OCR、AI 标点古文、AI 生成书法、AI 做诗词赏析（只要不涉及占卜/预测/运势）

**对比类写作模板：**

```
❌ 我试了 X，发现它比 Y 好 / X 比 Y 快
✓ 我试了 X，在 XX 场景下跑出 N tokens/s（benchmark 链接）
✓ X 和 Y 走了两条路，X 走 MoE 极致规模，Y 走 Dense 灵活落地
✓ 一句带过，其他国产同类我们之前覆盖过（链接到历史文章）
```

### Layer 3，QA 新增 L6 小红书合规检查

新增到 `config/prompts/qa-check.md`：

**L6 小红书合规（pass/fail）**

检查以下任一命中即 fail：

1. 标题是否使用禁用句式（见 Layer 2 标题禁用句式）
2. 正文是否出现玄学完全禁区词
3. 正文是否出现境外工具访问教程禁用词
4. 正文是否存在"我的产品优势 vs 竞品劣势"列表
5. 行动建议是否指向需要翻墙才能用的境外服务

fail 时，必须生成 xhs-version 再发小红书；不影响公众号/X 发布。

### Layer 4，双版本机制

对 meta.yaml 增加字段：

```yaml
platforms:
  wechat: primary      # 主版本 slug.md
  xhs: compliant       # 如 L6 fail 或 REACH>=8，自动生成 xhs-version.md
  x: primary           # X 用主版本
```

**xhs-version.md 生成规则：**
- 标题去掉所有 Layer 2 禁用句式
- 对比段落改为并列/中立
- 境外工具访问教程段落删除，改为"国内用户可以通过 OpenRouter/镜像/国产替代使用"
- 字数可以压缩到 800-1200（小红书短一点更吃香）
- 结尾明确标"本文不涉及境外软件访问教程"作为免责声明
