# HN 1848 票顶上来的「本地 AI 应该成为默认」，国内玩家怎么按预算上车

昨天 Hacker News 出了一篇神帖。

标题《Local AI needs to be the norm》，本地 AI 必须成为主流。作者 unix.foo，独立博主，发文到我刷到的时候 **1848 票、736 条评论**，顶在首页第二好几个小时。

HN 一篇个人博客能冲到 1500+ 票一年也就那么十几篇。能顶到这个分数，说明海外开发者的情绪攒到了一个临界点。

我把全文读完，热评翻了一遍，再回头看最近三天我跟过的几个相关项目，写一篇给国内玩家做对照。

## 海外这股情绪是怎么攒起来的

unix.foo 那篇论点没什么新鲜东西，云端 AI 的隐私、订阅费、被随机降智，这些每个月都有人写。

这次能顶到 1848 票，是因为评论区集体涌出来另一件事，**人们突然发现本地真的能跑出可用的东西了**。

热评高赞翻来覆去就那几句，

- M4 Mac mini 跑 GLM-4.6、Qwen3 30B，比半年前 ChatGPT Plus 的体验还好
- LM Studio 给全家配了 100% 离线助手，小孩查作业、老婆查菜谱，不再喂数据出去
- 换到本地三个月，账单从每月 80 刀降到 0，开发体验只损失 5%

2026 年开年到现在三件事同时发生，开源权重追上来（GLM-4.6 对标 Claude 4.5 Sonnet、Qwen3 30B MoE 达到密集 70B 水准），硬件门槛塌下来（Mac mini M4 64GB 一万五、二手 3090 不到六千），服务化工具链补齐了（omlx 把 Mac mini 做成 vLLM 风格的推理服务器、Cactus 开源 26M 参数的 tool calling 模型 Needle）。

云端那边还在涨价、限速、收紧免费额度，本地这边把「能用」和「够用」之间最后那条沟填上了。

## 国内为什么这件事更重要

把这件事放回国内，账要算得更细一点。

豆包、Kimi、DeepSeek、智谱这些国产 API 价格压得很低，DeepSeek V3.2 输入 token 每百万 0.5 元，看起来「省钱」这个动机不强。

但仔细看，这个低价是**有代价的**。上下文涨上去之后费率非线性增长，agent 多轮调用很快推到三位数每天。国产 API 普遍带强 prompt 检查和输出过滤，做医疗、法律、金融、学术辅助的人一茬接一茬被卡。企业内数据合规要求越来越紧，能把推理放在内网就放在内网，从去年下半年开始变成硬约束。

对国内有效的不是隐私焦虑，是**成本可预测性 + 合规自主权 + 不被随时降智的稳定体验**。这三件事云端 API 都卖不彻底。

下面按硬件预算分三档，每档我都给一个明确的目标场景，别走错档位。

## 第一档，4GB 显存破卡，AirLLM 路线

预算 0 到 1 千元，手里只有一张游戏卡或一台二手矿渣机。

工具选 AirLLM，原理是把 70B 模型按 transformer 层拆开，每次只把一层搬到 GPU，算完丢掉再加载下一层。GPU 显存只装当前层加激活值。

适合的场景，

- 离线批处理，夜里挂机用 70B 模型给一万条文本打标签、做摘要
- 验证模型行为，想看看 Qwen3 235B 写出来的代码什么样
- 配 cron + 微信机器人，早上自动生成英文 AI 资讯的中文摘要

不要拿它做实时对话或 agent。它的真实定位是**「破卡白嫖」**，性能换零成本。

## 第二档，Mac mini 或一张 3090，omlx + Ollama 路线

预算 6 千到 1.5 万元，国内开发者性价比最高的区间。

两个硬件选项，Mac mini M4 24GB 起步（5499 元起）或顶配 M4 Pro 64GB（约 1.5 万）适合 24 小时开机当家庭推理服务器；二手 RTX 3090 24GB（5000 元上下）配普通主板，显存带宽更猛，30B 以下推理比 Mac 快 2-3 倍。

软件层最值得跟的是 omlx（Apple Silicon）和 Ollama（跨平台）。omlx 三个关键设计，分层 KV 缓存把冷数据甩到 SSD（重启不丢 prefix）、连续 batching 默认 8 路并发、菜单栏原生应用。Ollama 是 3090 用户的默认选择，模型库覆盖 GLM-4.6、Qwen3、DeepSeek R1/V3、Llama 3.x、Gemma 3，一行 `ollama pull` 搞定，server 模式暴露 OpenAI 兼容 endpoint，Cursor、Continue.dev 都能直接接。

适合的场景，

- IDE 全本地化，让 Cursor 调用本地 Mac mini 或 3090 写代码
- 公司内部知识库 RAG，文档喂给本地模型，员工内网调用
- Obsidian / Notion 摘要改写，长文章 AI 摘要、跨笔记问答全本地化

这一档是 80% 的国内开发者真正应该上车的位置。不是最强，但**够用 + 可控 + 一次投入**。

## 第三档，手机手表眼镜，Cactus Needle 路线

预算只有「一台手机」。

5 月 13 日 Cactus Compute 开源的 Needle 把端侧局面撕开一道口子。**26M 参数**，二千六百万。Cactus 的洞察是，agent 体验本质是 tool calling 不是 reasoning，tool calling 说到底是 retrieval-and-assembly，用 cross-attention 这个原语足够了，FFN 那些参数纯属浪费。

所以他们做了一个**完全没有 MLP 层、只有 attention 和 gating** 的极简架构。消费级设备上 prefill 6000 tok/s、decode 1200 tok/s，single-shot function calling 击败了比它大 10 倍以上的 Qwen-0.6B、Granite-350M、LFM2.5-350M。

意味着你可以在**任何一台两年内的安卓手机或 iPhone 上**，跑一个能理解「帮我设个 8 点闹钟」、「把客厅灯调成 50%」并输出标准 tool call JSON 的模型。整个推理在设备完成，不联网、不上传、不计费。

国产硬件这块尤其值得跟，小米、华为、OPPO 的 AI 眼镜、AI 手表都在搜端侧 agent 模型，Needle 的「无 MLP」思路是个现成的参考实现。

## 我的判断

unix.foo 那篇能顶到 1848 票，不是论点新，是海外开发者群体在 2026 年开年三个月里**集体跨过了「本地真的能用」那条线**。

国内现在还在用国产 API「每百万 token 几毛钱」做心理锚定，所以本地推理这股潮流来得会比海外晚半年到一年。但合规和稳定性这两个因素会推着企业用户先走，医疗、法律、金融、教育、政企内部 AI，2026 年下半年开始会大规模迁回本地。

个人开发者这边门槛已经低到不可思议。5499 元的 Mac mini 24GB + 免费 Ollama，性能就是去年这个时候 ChatGPT Plus 的水平。

我自己过去三周完成了 80% 的迁移，本地写文章用 GLM-4.6（omlx 跑在 Mac mini 上）、本地写代码用 Qwen3 Coder 32B（Ollama 跑在 3090 上）、复杂的多文件 refactor 才动云端。月支出从 80 美元 + 国产 API 100 元降到了 20 美元。

「默认本地、必要时云端」这个心智模型，正在 2026 年这一波工具链补齐之后变成新的常识。

## 行动建议

- 预算 0–1 千，装 AirLLM 找一台带显卡的旧电脑跑离线批处理，别期待实时对话
- 预算 6 千–1.5 万，买 Mac mini M4（推荐 24GB 起步）或二手 3090，装 omlx 或 Ollama，日常 80% 的 AI 调用迁过去
- 预算只有手机，盯 Cactus Needle 的工程化进展，有 app 开发能力的可以现在就把 intent 识别那段从云端 API 换成本地 26M 模型
- 企业用户，合规迁移别再拖了，Mac mini 集群（4 台 64GB 顶配只要 6 万）能撑住 50 人公司的内部 AI 调用
