# OpenAI 手机被加速到 2027 量产，新爆料藏着三个变量

四月底我写过一次 OpenAI 要造手机，那时只有三家供应商的名字，没有时间表。

十天过去，Ming-Chi Kuo 又放出更细的报告。这一次时间被钉死了，2027 年上半年开始量产。

不是"在做"，是"在赶"，Kuo 用的词是 fast-track。

## 多出来的硬件细节

新爆料里最值得拎出来的是芯片。

OpenAI 这部手机会用一颗定制版联发科天玑 9600，台积电 2nm 工艺。今年秋天先量产标准版给 Vivo X300 Pro 这种旗舰，OpenAI 拿改过的版本走自己的产线。

定制集中在两块。一块是 ISP 图像信号处理器，HDR 处理被加强。Kuo 原话是"提升真实世界视觉感知能力"，听上去像在说拍照，其实更像在说多模态推理，让手机看清屏幕外的东西，agent 才能基于摄像头执行任务。

另一块是双 NPU 架构、LPDDR6 内存、UFS 5.0 闪存，外加 pKVM 和内联哈希这些安全特性。这套组合不是为了跑分，是为了让常驻的 ChatGPT agent 一直在后台运行，不把电池吸干、不把隐私吐出去。

Kuo 给了出货预期，2027-2028 两年合计约 3000 万台。这个量级是什么概念，iPhone 一个季度全球销量是它的三倍。OpenAI 没在和苹果抢规模，它在抢一个新品类的开局。

## Jony Ive 的位置反而模糊了

四月底那篇我提过，io 这家子公司的方向看起来是无屏幕设备，类似 AI Pin 高配版。

新爆料没否定这条线，但把"手机"这条线推到了前面。OpenAI 现在公开的硬件路线至少是双线，io 主导的无屏幕产品可能更早面世，手机是更大销量的载体。

从供应链结构看，这部手机不会是一台外形非常激进的产品。要在 2027 上半年量产、走联发科+富士康/立讯系标准产线、支持 LPDDR6，留给 ID 设计师颠覆形态的空间不多。

我的判断是，Jony Ive 给这部手机的痕迹会落在交互层而不是工业设计层。无 Home 键、无传统 App 抽屉、可能没有应用商店，硬件本身却是个看起来正常的玻璃方块。

Humane AI Pin 已经死了。OpenAI 不会再赌一次形态创新，它要赌的是交互范式更换。

## 国产对照，三家公司三条路线

OpenAI 这部手机要 2027 上半年才量产，等于给国产厂商留了一年多时间窗口。这一年里中国市场已经在跑三种不同路线。

**字节豆包，先做眼镜不做手机。** 字节自研的豆包 AI 眼镜，无屏版定档 2026 年一季度发售，带显示功能的版本年底跟上。重量不到 50 克，起步价压在 2000 元以内，由龙旗科技代工。字节没造手机，策略是把豆包做成"平台级 AI 入口"，绑在眼镜和已有手机的助手 App 上。

**小米，AI 眼镜 + AI 手机系统并行。** 小米 AI 眼镜早就上市，HyperOS 这一年也在把"用户用一句话叫 agent 干完一件事"的能力往系统底层做。和字节比，小米手里有自己的手机硬件，做 agent OS 的反馈链路天然完整。SU7 那条产品线证明了小米能把硬件迭代节奏提起来。

**华为，鸿蒙小艺继续吃自家硬件生态。** Mate 系列加上鸿蒙的小艺已经能在国行版手机里跑较深的端云协同 agent，和 OpenAI 对照，华为有完整的中文场景适配和国内服务对接。一句"帮我退掉那张高铁票"，国内能立刻落地的目前只有华为和小米这条线。

把三家拼到一起看，OpenAI 手机要解决的问题，国产厂商已经各自挑了一段在做。字节抢入口，小米抢 OS，华为抢场景闭环。OpenAI 想一次把三件事都做了，还把时间压到 2027 上半年，这是非常激进的工程目标。

## 三件事可以盯

距离 2027 上半年量产还有约 14 个月，有三件事如果发生，意味着这部手机大概率按时上市。

第一，台积电 2nm 工艺良率公开新闻。今年三季度前后会有 2nm 量产进度披露。

第二，立讯精密或富士康在 2026 年下半年财报里出现"美国大客户新机型"相关表述。组装订单的轮廓会先在产业链电话会议里漏出来。

第三，OpenAI 在 2026 年底或 2027 年初公布面向开发者的 agent SDK，明确"如何为 ChatGPT agent 写一个原生应用"。这是软件侧最后一块拼图。

## 国内能做什么

中国用户能买到这部手机的概率短期内仍然不高，后端依赖 ChatGPT。但这不影响国内的两个机会窗口。

一个是供应链。立讯精密、龙旗科技、舜宇光学这些公司都在同时给国产 AI 终端和海外 AI 公司做产品，AI 硬件这一轮带来的代工订单不再只属于苹果一家。

另一个是体验。国产 AI 手机和 AI 眼镜在 2026 年会密集上新，想提前感受"agent 替代 App"是什么手感，最便宜的路径是去线下小米之家试一台 HyperOS 新机，或者等下个月豆包眼镜出货拿一副用一周。

四月底我说过一句，风口不在硅谷，风口在东莞和苏州。一个月过去，这句话只是更具体了一点。

下一次值得停下来看的爆料，应该是台积电 2nm 良率新闻，盯着那条线就够了。
