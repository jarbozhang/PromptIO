# 用友金蝶要小心了 SAP 刚花 11.6 亿圈了一道 ERP 围墙

家人们 这条新闻国内 ERP 圈值得抄作业 我先把它讲清楚 再讲我看到的国产对照 📊

## 一句话讲清楚事件

5 月 5 日 TechCrunch 爆出 SAP 收购了德国 Freiburg 的 Prior Labs 几乎全现金 三位创始人到手超过 5 亿美元 加上未来四年再追加 10 亿欧元 总盘子约 11.6 亿美元 💰

Prior Labs 才成立 18 个月 2025 年 2 月才完成 900 万欧元第一轮 现在估值翻了 100 倍以上 这种节奏欧洲上一次出现还是 Mistral

## Prior Labs 在做什么

它做的是"表格基础模型" 旗舰开源模型 TabPFN 下载量过 300 万次 处理对象不是文本不是图像 是数据库里那种行列结构化数据 📑

传统机器学习处理表格数据要先训练 TabPFN 是预训练好的 给一张陌生的表 直接做分类和回归推理 不需要微调 客户的销售表 库存表 应收账款表 过去要数据科学家写脚本 调参数 现在直接吃表给答案 链路从周缩到秒 ⏱️

## 真正值钱的不是模型 是"门票"

收购同一天 SAP 顺手公布了 Joule 助手的新底层 Nvidia Agent Toolkit 也就是 Nvidia 企业级 agent 框架 NemoClaw 的基础 🚪

TechCrunch 原文有句话被很多中文转载漏掉了 SAP 通过 API 政策只放行少数几个"自己背书"的 agent 框架进入客户 ERP NemoClaw 在白名单里 其他开源 agent 路线被关在门外

SAP 是全球最大 ERP 厂商 财富 500 强里 78% 在用 它和 Nvidia 联手在欧洲企业 ERP 这个口子上画了一道生态围墙 11.6 亿是表面的钱 "谁能在 SAP 客户的 ERP 上跑 agent"才是真正的标的 🧱

## 我对国内 ERP 的三层判断

第一层 收购溢价不会被复制 ✋
用友 金蝶 浪潮手里没有 11.6 亿现金砸一个 18 个月的 AI lab 国产 ERP 更可能走"自研 + 合作国产大模型"路线 用友 BIP 已经接了通义千问 金蝶云苍穹接了 DeepSeek 但合作深度跟 SAP 直接买下整支团队完全是两回事

第二层 "agent 白名单"这个动作国内一定会学 ✅
SAP 用 API 政策圈定哪些 agent 能进客户系统 这套对国产 ERP 极有吸引力 既保护自家 Joule 类产品 又能跟某家国产大模型厂商绑定 豆包 通义 DeepSeek 接下来一两年大概率会出现在某家国产 ERP 的"独家 agent 合作伙伴"位置上

第三层 表格基础模型这个方向被严重低估 📈
国内做 LLM 的厂商把注意力都放在文本和多模态 但真正能在企业落地的 80% 是表格 报表 明细账 Prior Labs 卖出 11.6 亿是个信号 国内做表格 AI 的小团队这两年应该会被资本重新看一眼
