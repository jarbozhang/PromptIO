# Claude Code 2.1.224 支持跨会话通信，两个终端终于不用来回复制上下文

我同时开两个 Claude Code 会话时，最烦的不是多开终端，而是来回复制上下文。一个会话写代码，另一个会话做审查，中间还得靠我当传话人。

Claude Code 2.1.224 加入跨会话通信后，这段人工搬运可以省掉。会话能够发现同一台机器上的其他会话，再把任务直接发给指定对象。

这套能力最适合已经在并行使用 Claude Code 的开发者。照着下面的最小路径走完，你可以验证会话发现、任务发送和入站消息控制，并把实现、测试、审查拆到不同终端。

## 选一个能看出分工价值的最小场景

我建议不要拿复杂项目开场，选一个能在几分钟内判断结果的任务就够了。

例如保留两个终端。主会话负责修改代码，review 会话只检查 `src/db.ts` 的连接池配置。目标不是让两个会话一起改文件，而是验证主会话能否发现 review 会话，并直接把审查任务交过去。

这一步有个很实用的判断。跨会话通信解决的是协调，不是自动消除文件冲突。实现、测试和审查可以并行，但文件归属仍要提前说清楚。

## 跑通升级、发现和发送路径

整个尝鲜过程可以压成下面 5 步。

- 执行 `claude update`，把 Claude Code 升级到 `2.1.224`
- 进入会话后执行 `/peers`，检查命令是否已经出现
- 如果没有，在 `~/.claude/settings.json` 的 `env` 配置中加入 `"CLAUDE_CODE_HARBOR_KITE": "1"`
- 分别启动两个 Claude Code 进程
- 在主会话里用 `ListAgents` 查看当前 peer 会话，再把 `检查 src/db.ts 的连接池配置并回复结论` 发给 review 会话

源材料提到，启用对应环境变量后不必继续等待功能开关。配置完成并启动进程时，`/tmp/cc-socks/` 下会为每个会话出现一个权限为 `0600` 的 socket 文件。

这个实现细节很关键。通信落在本机 socket 上，每个会话拥有自己的入口，`0600` 则把文件访问限制在当前用户范围内。它不是把所有终端混成一个共享聊天框，而是让会话拥有可发现、可寻址的通信通道。

## 用四个结果判断是否真的跑通

我会把验收标准写得很具体，避免只看到命令存在就算完成。

- `/peers` 能正常调用
- `ListAgents` 能列出另一个正在运行的会话
- `/tmp/cc-socks/` 能看到对应的 socket 文件，权限显示为 `0600`
- review 会话收到针对 `src/db.ts` 的任务，并把审查结论回给发起会话

四项都成立，才说明发现、发送、接收和回复形成了完整链路。如果只能看到 peer，却收不到消息，检查重点应该落在入站策略，而不是反复重启两个终端。

## 把实现、测试和审查拆给不同会话

跑通以后，我更愿意按交付物拆分，而不是让多个会话同时漫游整个仓库。

主会话负责实现，并明确改动文件。测试会话只接收改动范围和预期行为，运行相关测试后返回失败信息。review 会话读取 diff，重点检查边界条件、回归风险和缺失测试。

一条适合复用的任务描述应包含这些信息。

- 对象，例如 `src/db.ts`
- 动作，例如检查连接池配置
- 边界，例如只审查，不修改文件
- 回传内容，例如问题位置、风险和建议

我的判断是，跨会话通信最有价值的地方不是多开几个 Claude Code，而是让每个会话保持更窄的上下文。实现会话不用背审查提示，审查会话也不必继承整段开发过程。

## 控制自动接收消息的信任边界

`crossSessionInbound` 是最需要认真决定的配置。默认情况下，入站消息会先进入 hold 状态，等待确认。把它设置为 `accept` 后，消息可以自动进入会话。

自动接收确实省动作，但我不会在所有场景里直接打开。只要某个会话能够被其他 peer 投递任务，就要考虑发送方是否可信，以及收到的内容会不会触发文件修改、命令执行或范围扩张。

更稳妥的使用方式是按场景选择。

- 本人控制、职责清晰的本机会话，可以考虑设置 `"crossSessionInbound": "accept"`
- 会话来源或任务范围不明确时，保留 hold 和人工确认
- 自动接收后仍在任务中声明文件范围、允许动作和返回格式
- 涉及修改的会话避免共享同一文件，审查会话优先保持只读职责

我会先保留确认机制跑通一次完整链路，再决定是否开启自动接收。省掉一次确认很方便，但它同时把信任判断从每条消息前移到了配置阶段。

下一步就开两个终端，用一个文件完成一次实现与审查交接。等消息能够准确送达、结果能够原路返回，再把测试会话加进来。
