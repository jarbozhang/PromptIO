# Apple 换 CEO 第一周，Musk 就要 600 亿买 Cursor

Tim Cook 9 月退，硬件主管 John Ternus 接班。同一周，xAI 跟 Cursor 签了 100 亿美元合同，外加 600 亿收购权。

两件事看着没关系，其实是一件事。

科技圈最大的两台印钞机，一台正在换驾驶员，另一台正在抢一台还没造完的火箭发动机，就是 AI 编程工具。

我看到这两条新闻同一天蹦出来，第一反应不是震惊，是有点恍惚。Cook 干了 14 年，把 Apple 干到了 3.5 万亿美元市值，结果交班那一周，最大的科技话题不是他的离任，是 Musk 给一个三年前还在 Y Combinator 路演的工具开 600 亿支票。

什么叫时代变了，这就叫时代变了。

## Cook 退、Ternus 上、AI 编程市场重洗牌

先把事情讲清楚。

TechCrunch 这周的播客里说得很明白，Cook 9 月正式卸任，接班人是 John Ternus，Apple 现任硬件工程主管，负责过 iPad、Apple Silicon、Vision Pro 这些硬件大件儿。

Apple 把硬件主管推到 CEO 这个位置上，信号很清楚，未来几年它还是想押硬件，AI 软件这条线大概率不会自己重头烧。这跟 Google 押 Gemini、Meta 押开源、Microsoft 抱 OpenAI 的路子完全不一样。

Ternus 接的不是 Cook 那个 Apple。App Store 30% 的抽成已经被各国监管捶得满头包，Apple 当年在硬件供应链里一手遮天的话语权，也在被 TSMC、三星、各家代工厂分摊。最关键的是，AI 编程、AI Agent、AI 操作系统这些新地盘，Apple 一个也没占住。

然后看另一边，Latent Space 的 newsletter 里有一句话我反复读了三遍，"Cursor 拿到 xAI 100 亿美元合同，附带 600 亿美元收购权"。

我先解释下 600 亿收购权（acquisition right）是什么意思。这不是现在就花 600 亿买，这是 Musk 在合同里锁了一个未来按这个价格收购的优先权。你想想看 xAI 现在用 100 亿先把 Cursor 的 token 消费、技术合作、客户数据全圈进来，然后随时可以用 600 亿把整个公司吃下去。这是一种典型的"先包养再求婚"打法。

Cursor 估值的脉络也值得说一下。这家公司 2023 年走出 YC 的时候估值还是 4 亿美元级别的，2024 年到 26 亿，2025 年传过 100 亿，到 2026 年初传过 200 多亿。如果 Musk 真按 600 亿吃下来，等于 18 个月翻 6 倍。

OpenAI 收 Windsurf 的传闻、Anthropic 自家做 Claude Code、Google 收 Cognition 的小道消息，这一切都是同一个故事的不同回合，AI 编程工具是当下唯一一个真金白银能跑出 ARR 的 AI 应用赛道，谁也不想在这个赛道上没有自己的桩。

## 社区在吵什么

社区数据这次拉得不太好，Reddit 直接 403，X 的 cookies 也没认上，但我之前刷过的圈子里几个声音值得拎出来。

HN 的高赞评论一直有一条主线，Cursor 的护城河到底是产品还是模型。一派认为它的 codebase indexing、Composer 多文件编辑、Tab 补全的细节打磨深得人心，普通用户半年都换不掉。另一派的反驳很尖锐，Cursor 自己不训模型，底层调的是 Claude 和 GPT，一旦 Anthropic 把 Claude Code 做成本地 IDE，或者 OpenAI 把 Codex 拉回桌面，Cursor 就是个会被绕开的中间层。

Anthropic 自家 Claude Code 用户里有个普遍观点我同意，Cursor 现在赢在交互，不在引擎。引擎是别人家的，交互这层壁垒不薄但也不厚。

X 上有个我觉得很尖的吐槽，xAI 一年内发了 Grok Code Fast、收了 Cursor 的 token、又签了 100 亿合同，看起来像一个"我没有最强模型，所以我把所有用最强模型的工具都买下来"的策略。这话刻薄，但我觉得有点道理。

中文圈这边，知乎和 V2EX 上对 Cursor 的讨论这一年从"神器"慢慢变成"贵且卡"。Pro 套餐 20 美元一个月，Ultra 200 美元一个月，对国内独立开发者门槛不低。Trae、CodeBuddy、CodeGeeX 这些国产工具补位的速度比想象中快，但工程化细节确实还有差距。

## 我的判断

我认为 Apple 这次换帅，是被 AI 焦虑逼急了。

把硬件主管推到 CEO 位置上不是稳健，是收缩。Apple 在用一个明确的信号告诉投资人，我们就守住硬件这一亩三分地，AI 这盘大棋我不下了。Vision Pro 没卖动，Apple Intelligence 上线一年用户感知接近零，Siri 重写了三遍还在难产。Cook 这时候交棒，不是功成身退，是把一个更难的牌局甩给后面的人。

至于 Cursor 600 亿值不值，我的判断是，单看 ARR 不值，单看战略位置值。

Cursor 现在 ARR 大概在 5 亿到 10 亿美元区间，按 SaaS 估值公式 600 亿是 60 倍 PS，离谱。但如果你把它看成"未来五年所有用 Claude/GPT 写代码的开发者的入口"，那就不是 SaaS 估值，那是平台估值。Musk 买的不是一个工具，是一个分发渠道，把所有走 Cursor 的 token 都引到 Grok 上。

但我有个不太一样的看法，我觉得 Musk 真要 600 亿吃下 Cursor 的概率其实不高。这种 right-to-acquire 在硅谷投资里更多是估值锚定的工具，给 Cursor 后续融资定一个"上限保护价"。真到了执行那一天，xAI 自己的现金流、监管的反垄断审查、Cursor 创始团队愿不愿意被并掉，每一关都是变数。

OpenAI 和 Anthropic 这边怎么应对，我觉得方向已经很清楚了。OpenAI 的 Codex 会回到桌面端、做成跟 Cursor 直接对位的产品，Anthropic 的 Claude Code 会继续吃 CLI 和 agent 用例，把"程序员开终端就用 Claude"这个心智占住。Google 那边 Gemini Code Assist 还在吃企业市场。

四家在抢同一个东西，开发者一天 8 小时盯着的那个 IDE 窗口。

## 行动建议

我自己也还在摸索，但有几个判断现在就可以做。

国内开发者要不要 lock-in Cursor，我的看法是，现阶段不要把工作流死死绑在它上面。Cursor 国内付费、抽签、订阅有时不稳定，加上 Musk 收购变数大，万一明年它从一个工具变成 xAI 生态的一部分，国产开发者用起来更别扭。

我自己的工作流是 Cursor + Claude Code 混着用，前者吃多文件编辑和重构，后者吃 CLI、自动化任务和长 context。两条腿走路，哪边出问题切另一边。

国产替代这边，Trae 我跑过一周，重构能力不输 Cursor，唯一弱在 codebase indexing 还没那么聪明。CodeBuddy 适合腾讯云生态，CodeGeeX 适合本地隐私场景。这三个值得放在备胎位上，至少不至于真到 Cursor 出大变数那天措手不及。

最后一个开放问题，留给读者，Apple 换 CEO 推硬件主管上位，到底是退守，还是在为某个我们还看不到的硬件 + AI 大棋盘做铺垫？

我自己倾向第一种，但我希望我是错的。
