# Microsoft 把 VibeVoice 开源了，一天涨 757 颗星

一天 +757 颗星，仓库说明只有一行字，Open-Source Frontier Voice AI。

发布方是 Microsoft 官方，repo 名叫 VibeVoice。我刷到的时候揉了揉眼睛，因为这家公司在语音生成赛道已经安静太久，过去几年最响亮的 TTS 项目还停留在论文阶段，模型从来没真正放过权重。

这次反着来了，模型挂在 Hugging Face，license 是 MIT。

## 一个仓库塞了三个模型

VibeVoice 是一个家族。

最大的是 ASR，7B 参数，做长语音识别，README 写支持单次跑 60 分钟音频，50 多种语言，能识别说话人，能打时间戳。

中间的是 TTS，1.5B 参数，做多说话人合成，单次最长输出 90 分钟，最多 4 个说话人。1.5B 这个尺寸跑在消费级显卡上完全没问题。

最小的是 Realtime，0.5B，主打实时流式合成，README 标的延迟是 300 毫秒左右，如果属实已经够做实时对话 agent 了。

三个模型共享一个底层架构，连续语音 tokenizer 跑在 7.5 Hz 的极低帧率上，再叠 next-token diffusion 和 LLM。坦率讲帧率压到 7.5 Hz 是这次最有意思的工程选择，等于把语音压成"几乎是文本"的稀疏序列，长音频算力消耗能掉一个数量级。

## 中文能跑，但要看是哪个模型

我把三个模型的语言支持挨个对了一遍。

ASR 模型全语种通吃，中文在第一梯队。TTS 模型 README 直接列了英文和中文，还提到 cross-lingual 能力，用一个英文 voice prompt 也能合成中文。Realtime 那个 0.5B 是个例外，官方列的 9 种语言里没有中文。

所以场景拆开看，长文本 TTS 跑中文播客、有声书、视频配音，1.5B 那个能直接用。要做实时中文对话 agent，要么等微软更新，要么自己拿 1.5B 那个改改流式推理。

我的判断是 1.5B 这个 TTS 模型才是这次开源里对中文用户价值最大的那一块。

## 拿来跑的几个路径

最快能动手的方式是去 Hugging Face 找 microsoft 组织页面，三个模型权重都在上面。配合 transformers 或 vLLM 加载，跟跑普通 LLM 没本质区别。

如果只想先听听效果，微软挂了一个 ASR 在线 playground，浏览器直接打开就能上传音频测试。

本地部署，1.5B TTS 大概 6 到 8GB 显存能跑推理，3060 12GB 之类的卡就够了。0.5B Realtime 4GB 级别的卡都能塞下。7B 的 ASR 大一些，但 ASR 不是高频 inference 场景。

国内拉权重慢的问题，HF 镜像站之前一直能用，魔搭社区估计这两天也会有人搬运过去。

## 和国产 TTS 怎么选

社区这两天讨论最多的，就是 VibeVoice 和国产开源 TTS 怎么选。

国产 TTS 在中文社区已经有相当成熟的生态。VibeVoice 进来要解决的不是"能不能跑"，而是"凭什么换"。我的判断是，VibeVoice 在长音频和多说话人这两个具体场景上有差异化优势，90 分钟单次输出是个相当激进的目标，国产开源里目前没有对标的。

但日常做 5 到 30 秒的短文本配音，国产 TTS 在中文上更熟更稳，没必要换。主流商业 TTS 的 API 账单一直是个隐痛，能本地跑的开源选项多一个总是好事。

## 我担心的一件事

写到这里说一句不一定讨喜的话。

微软这次开源的姿态很漂亮，但 README 里那段 deepfake 免责声明我读了三遍，看得出来内部法务有顾虑。这种顾虑会不会变成下一步的功能调整，比如克隆能力被限制，或者权重在某个点被悄悄替换成"安全版"，是我接下来会持续盯的事。

模型权重一旦放出来就收不回去，但仓库本身、issue 区、demo 地址这些都是可以随时撤的。所以你如果真的想用，今天就把权重拉下来存好。

## 行动建议

第一，去 Hugging Face 搜 microsoft/VibeVoice，把 1.5B TTS 权重 clone 到本地或自己的对象存储里。

第二，打开微软那个 ASR playground，传一段中文音频，看识别质量到不到你的产品要求。

第三，如果你手上有需要 30 分钟以上长语音生成的项目，比如有声书、长播客、知识付费课程，把 VibeVoice-TTS 加到候选列表里和你现在用的国产 TTS 跑一次盲测。

回到开头那 757 颗星。涨这么多不是因为微软招牌响，是因为社区憋了太久没等到一个能塞下整本书的开源 TTS。Frontier 这个词最终落不落得住，要看这周末第三方测评出来之后大家还愿不愿意继续点星。
