# OpenAI 真的要造手机了，AI agent 直接干掉 App

爆料这事的不是科技博主，是 Ming-Chi Kuo，那个把 iPhone 供应链摸得比 Tim Cook 还熟的分析师。

他今天放出来的内容就一句话，OpenAI 在和 MediaTek（联发科）、Qualcomm（高通）、Luxshare（立讯精密）一起做一部手机，定位是"用 AI agent 替代 App"。

我看到 Luxshare 这个名字停了三秒。这家是国内的，富士康最大的对手，AirPods 和部分 iPhone 就是它代工的。如果这事是真的，OpenAI 这部手机的整机组装很可能在中国。

## 为什么这条爆料值得停下来看

之前所有关于 OpenAI 硬件的传言，主线都是"耳机"。Sam Altman 和 Jony Ive（前苹果首席设计师）合伙的那家公司叫 io，去年高调收购、然后就开始低调做产品，路线图泄露过一次，写的是一个"无屏幕、随身佩戴、用语音和 AI 交互"的设备。听起来像是 AI Pin 的高配版。

Ming-Chi Kuo 这次直接把"手机"这个词放出来，是个升级。

耳机和手机在产品逻辑上不是一个东西。耳机是配件，必须依附手机存在。手机是入口，谁握住手机谁就握住流量分发权。OpenAI 如果真的造手机，意味着它不打算继续躺在 iPhone 和 Android 上做"另一个 App"。

它想自己做底盘。

## 把这事讲清楚，三家供应商各自承担什么

爆料里出现的三个名字不是随便凑的，每家在手机产业链里有明确的位置。

MediaTek（联发科）做 SoC，就是手机里那颗主芯片。中端 Android 机大量用它的天玑系列，性价比比高通骁龙好。OpenAI 找它，最可能的目的是定制一颗带 NPU（神经网络处理单元）加强的芯片，让端侧跑 agent 不至于太卡。

Qualcomm（高通）也是 SoC 厂，旗舰 Android 手机几乎被它垄断。同时高通有完整的基带方案，全球频段、5G、卫星通信它都覆盖。OpenAI 同时找 MediaTek 和 Qualcomm，要么是双供应商策略，要么是 SoC 走联发科、基带走高通，分工合作。

Luxshare（立讯精密）做整机组装和精密组件。这家公司起家是做连接器，后来一路吃掉了 AirPods 大部分订单，现在在抢 iPhone 的代工份额。OpenAI 把组装放在 Luxshare 而不是富士康，姿态很明显，他们不想被苹果系的供应链绑架。

我看完这三家的组合，第一反应是，这部手机的底层逻辑跟 iPhone 完全不一样。iPhone 是软硬一体、闭环优化、A 系列芯片自研。OpenAI 这套是"我设计大脑（agent 系统），你们出身体（芯片+整机）"，更像 Google Pixel 早期的思路，但比那个还轻。

## io 项目和这部手机什么关系

这里有个容易混的地方。

io 是 Sam Altman 和 Jony Ive 合伙的硬件公司，OpenAI 去年完成对 io 的全资收购，所以现在 io 是 OpenAI 的硬件子公司。Jony Ive 在 io 主导设计。

之前的传言说 io 第一款产品是个"无屏幕的随身设备"，靠语音和 AI 互动。Ming-Chi Kuo 这次说的是手机，有屏幕、有完整电话功能。

这两条线可能是两个产品，也可能是一个产品的两种形态。我倾向于第一种，io 先出一个无屏幕的探索性产品试水，跟 Humane AI Pin 同类，用来收集用户怎么跟 agent 交互的数据。手机是第二款，把验证过的交互模式放到一个销量天花板更高的载体上。

如果是这样，OpenAI 做硬件的节奏就跟所有人想象的不一样。不是一锤子买卖，是阶梯式产品矩阵。

## 社区里的声音

坦率讲，这条爆料刚出来几个小时，Reddit、HN 上还没有形成有质量的讨论，知乎和微博上的中文讨论也都停留在"卧槽 OpenAI 要造手机？"的情绪层面。

我能找到的有点意思的观点，集中在两个方向。

一派是怀疑派，说 Ming-Chi Kuo 也不是次次准，去年他爆苹果折叠屏出货时间就跳票了。而且 OpenAI 现在亏成这样，烧钱做硬件是不是在赌一个没赢面的局。

另一派是路径派，重点不是"OpenAI 能不能做出来"，而是"做出来卖给谁"。Android 阵营本来就是开放生态，国产厂商已经在内置 AI agent 了，OpenAI 一部不上 Google Play、不连 App Store 的"agent 手机"，欧美市场愿意为它放弃整个 App 生态吗？

我觉得第二派问到了点上。

## 我的判断

这部手机能不能颠覆 iPhone，我的判断是不能，至少前两代不能。

理由很简单，手机是个生态产品，不是个性能产品。iPhone 卖的不是 A 系列芯片有多快，是 iMessage、AirPods、Apple Watch、Apple Pay、家人共享这套已经织进生活的网。OpenAI 一部首发机型不可能复制这张网。

但能不能成为一个"重要的小品类"，我觉得能。就像 Kindle 没干掉 iPad，但在阅读这个细分场景活到了今天。如果 OpenAI 这部手机把"agent 替代 App"做扎实，让用户真的可以"我要订一张明天去上海的高铁票"一句话搞定不打开任何 App，它就有自己的护城河。

中国市场能买到吗，我的判断是首发不会有国行版。原因不是供应链问题，立讯精密能做整机说明产能在国内。问题是合规，OpenAI 的服务进不来国内，一部依赖 ChatGPT 后端的手机在国内开机就是一块板砖。

OpenAI 学小米还是学苹果，我的判断是它谁都没学，它在学 Google Pixel 早期，硬件给品牌站台、跑通系统、收集数据，销量不是第一目标。差别在于 Pixel 是给 Android 当样板间，OpenAI 这部手机是给 agent 操作系统当样板间。

## 中国用户现在能做什么

第一，把这三家公司放进观察列表。MediaTek 和 Qualcomm 是上市公司，立讯精密在 A 股 002475，这条新闻坐实之后供应链相关公司的财报和电话会议会有更多细节漏出来。

第二，国产 AI 手机不需要等 OpenAI。荣耀 Magic 系列、小米 HyperOS、vivo 蓝心、华为鸿蒙的小艺，这一批已经把"语音叫一句、agent 帮你订酒店"的功能落地了。我自己手机上试过几次小艺定外卖，体验远没到惊艳，但流程是通的。OpenAI 那部手机做的事情，国产厂商已经在做，只是没人做到"把 App 全部替换掉"那一步。

第三，如果你想现在就体验"agent 替代 App"是什么感觉，最低成本的方法是在电脑上跑 Claude 的 Computer Use 或者 OpenAI 的 Operator，让模型自己控制浏览器。能跑通几个真实任务之后，你对"手机版 agent OS 到底有多大想象空间"会有自己的判断。

回到开头那个停了三秒的瞬间，我盯着 Luxshare 那个名字看的时候，想的是另一件事。AI 大公司开始抢硬件入口，意味着接下来三年中国供应链会被卷进新一轮竞争。这次不再只是给苹果代工，是给 OpenAI、Google、Anthropic 这些 AI 公司同时代工。

风口不在硅谷，风口在东莞和苏州。
