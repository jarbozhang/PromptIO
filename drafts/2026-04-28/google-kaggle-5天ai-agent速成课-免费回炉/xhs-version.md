# Google + Kaggle 又开了一期 5 天 AI Agent 速成课，6 月开课

那门被 150 万人刷过的 5-Day GenAI Intensive 又拉回来了一期。

这次主题换了，叫 5-Day AI Agents Intensive，配套口号是 Vibe Coding。开课时间 2026 年 6 月 15 日到 19 日，五天连上，免费报名。

我先把结论摆这儿，**这不是那种"看完就忘"的网课**。上一届跑完是要交 capstone 的，没交完拿不到证书。这一届依然要做完 final capstone project，也就是说，你得真把一个 Agent 跑通。

## 这门课到底要教什么

官方原话给了几个关键词，我不打算硬塞，能确认的就这些，

- **核心概念**，从 foundational concepts 一路到 production-ready systems
- **Vibe Coding 工作流**，把"自然语言当主要编程接口"这件事单拎出来当主题
- **工具与 API 集成**，原文写的是 10x agents，意思是怎么把 LLM 接外部工具，把单点能力变成行动力
- **Capstone 项目**，五天结束你得交一个能跑的东西

至于 Day 1 到 Day 5 每天具体讲什么，**截至今天还没放课表**，参考上一届节奏，是开课前两周才铺完整 codelab。2024 年第一届的五天分别是基础模型与 prompt engineering、embeddings 与向量数据库、AI agents、领域微调、MLOps。这一届主题换成 Agent，结构会重写，**别拿老课表当这届的预告**。

## 我的判断和怎么用国内环境跟下来

这门课对中国 AI 工程师，**值得跟，但不要当主菜**。

如果你已经在做 Agent 相关项目，这五天能给你三样东西，一是大厂对 Agent 的"官方叙事"，知道工业界怎么想这件事；二是一个能跑通的 capstone，写在简历里挺硬；三是一个被工程师亲口确认的"当前最佳实践"参照系。你自己摸索半年得出的结论和大厂工程师当面讲的，权威性不一样。

但如果你刚入门，**别指望它替代系统课**。五天的密度决定了它是"快闪"，不是"打地基"。

我把这门课当成一个**知识范式**来用，国内完全可以平替环境跟下来，

- **运行环境**，用魔搭 ModelScope 的 Notebook 或者阿里云 PAI-DSW，免费 GPU 配额够跑课程里的 notebook，Python 代码本身和 Colab 通用
- **模型 API**，把课程里的 LLM 调用换成 DeepSeek 或通义千问的 API，国内直接申请 key，免费额度做完 capstone 绰绰有余
- **向量数据库**，课程会用到 embedding 与检索，国内可以用 DashVector、阿里云 OpenSearch 或者本地 Chroma 跑通同一套思路
- **Agent 框架**，LangChain、LlamaIndex 在国内都能直接 pip 装，不依赖境外前端

也就是说，课程教的是"Agent 的工程化思路 + 一个 capstone 范式"，**这部分知识是可迁移的**，工具链可以全套换成国产或开源。

## 社区怎么看上一届

我把能搜到的反馈过了一遍，几个高频评价，

**正面**，"五天密度比我读半学期 ML 课还高"出现频率最高。第一届的白皮书在技术圈被反复传，做企业 AI 的人当作内部入门材料发。

**负面**，"livestream 节奏太赶"、"capstone 题目偏开放，没思路的人会卡住"、"答疑后期人太多刷不过来"。

**中肯**，国内做大模型的工程师讲过，这门课的价值不是教你新东西，是给你一个工业界确认过的参照系。

## 行动建议

如果你打算跟，

**第一步**，去 Kaggle 搜 5-Day AI Agents Intensive，找到 2026 年 6 月那期登记，邮箱注册账号即可。

**第二步**，提前在魔搭 ModelScope 或阿里云 PAI-DSW 开一个 Notebook 环境，跑通 `pip install` 几个常用库，环境 OK 就行。

**第三步**，去 DeepSeek 开放平台或者阿里云百炼申请通义千问 API key，把后续 capstone 的 LLM 调用全部对接到这两家。

**第四步**，把 6 月 15 日到 19 日五个晚上空出来，没跟上直播没关系，看 codelab 也能补。

最后给一个真实预期，**报名的人里有一半会在 Day 2 掉队**，capstone 那道关，能走到的不到一成。要是真想跟下来，从 Day 1 就得每天保证两三个小时投入。

我会跟。我打算用 capstone 做一个 openclaw 生态相关的 Agent demo，全部用国内 API 跑通，到时候单独写一篇复盘。

如果你也打算跟，欢迎留言告诉我你打算用 capstone 做什么。这种东西聊起来比一个人闷头搞有意思多了。
