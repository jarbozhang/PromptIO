# Chrome 把 prompt 库做进了浏览器，国产浏览器跟进只是时间问题

我盯了一周浏览器 AI 的更新，最值得国内用户提前看的是 Chrome 的 Skills，4 月 14 日推送，简单说就是把"你最常用的那条 prompt"变成浏览器里的一键工具，下次按个斜杠 `/` 就能跑。

这件事在国内用户层面短期意义不大（国产浏览器场景不同），但**它定义了未来一年浏览器 AI 的交互范式**，国内厂商一定会跟。我把它讲清楚，再给你 5 个可以立刻在国内工具里复用的 prompt 模板。

## Skills 到底干了什么

核心动作只有一个，把高频 prompt 存下来，下次一键调用，三件事，

- **保存**，把你常用的 prompt 存成一个 Skill，命名归类
- **触发**，浏览器任意页面按 `/`，下拉里选 Skill
- **模板库**，官方提供了一批 ready-to-use 的现成模板（写邮件、对比商品、扫描文档要点），可以直接加进自己的库再改

它和 ChatGPT 的 Custom GPTs 不在一个层，Custom GPTs 是带知识库的小机器人，Skills 更轻，就是 prompt 模板加上当前页面上下文。和 Notion 里那些 prompt 收藏文档比，优势是调用路径短了 10 步。

## 国产工具怎么复用这套思路

**这是本文重点**。Skills 的范式不复杂，国产 AI 工具今天就能模拟这个体验，按使用顺序我推荐三档，

**第一档，浏览器 + AI 一体的国产方案**

- **夸克 AI**，自带 AI 搜索 + 文档总结，已经支持把当前网页内容直接喂给 AI
- **豆包浏览器**（字节出的）和**豆包桌面端**，划词、截图、当前页问答都很顺
- **QQ 浏览器**的 AI 助手，国内场景覆盖最全（带购物比价、网盘内容总结）
- **360 AI 浏览器**，文档处理是强项

这一档对应 Chrome Skills 的"浏览器原生 AI"层，国产方案在中文网页处理上反而更顺手。

**第二档，纯 prompt 库工具**

如果你不换浏览器，就把 prompt 库做在文档工具里，

- **腾讯文档**，开个共享文档专门放 prompt 模板，多端同步，团队也能用
- **飞书文档 + 多维表格**，按场景分类（邮件、翻译、总结、代码 review），点开复制
- **Notion 中文版**（如果你已经在用）配合个人页面收藏

第二档调用路径长了几步，但好处是跨工具通用，复制到豆包、Kimi、元宝、DeepSeek 网页版都能跑。

**第三档，桌面端快捷调用**

- **utools / uTools** 插件市场里有 prompt 管理器
- **Raycast**（Mac）的 Snippets 功能可以做成 `;email` 触发的全局缩写

这一档最接近 Chrome Skills 的"按键即触发"体验。

## 5 个我每天都在用的 prompt 模板

下面这 5 条不挑工具，复制到豆包 / Kimi / 元宝 / DeepSeek / 通义任意一个对话框都能跑，按使用频率排序，

**1. 邮件改写三档**
```
把这封邮件改成三个版本，(1) 正式商务版 (2) 友好对话版 (3) 简短直接版。事实信息保持不变，不清楚的地方用 [需澄清] 标出。
```

**2. 当前网页 5 句话总结**
```
用 5 个要点总结这段内容，(1) 这是什么 (2) 核心观点 (3) 支撑证据 (4) 缺什么或哪里弱 (5) 如果我是读者，行动项是什么。
```

**3. 中英技术翻译（保留专有名词）**
```
翻译成简体中文。不要翻译，产品名、代码、库名、模型名。语气贴近中文科技博客（清晰、口语化、不端着）。只输出译文。
```

**4. 代码片段 review**
```
review 这段代码，关注 (1) bug (2) 安全问题 (3) 可读性。每条给出严重程度（高/中/低）和一句话修复建议。除非我要求，不要重写整个文件。
```

**5. 截图转结构化说明**
```
把这张图当作产品需求描述，(1) 用户看到了什么 (2) 主要交互 (3) 图里的文字逐字列出 (4) 暗示的用户需求。用 markdown 列表输出。
```

把这 5 条存进你的腾讯文档或飞书文档，每天用上一两条，比追任何新功能都实在。

## 我的判断

第一，浏览器 AI 的入口正在从聊天框转向地址栏，这点 Chrome 看得很清楚，国产浏览器不会落下太久。夸克、UC、豆包浏览器做"prompt 一键库"是时间问题，今年下半年会有动作。

第二，那种"密码本式 prompt 收藏夹"工具会被压扁，无论是 Chrome Skills 这种原生方案，还是国产浏览器跟进的版本，都会把这个动作压到一次按键。靠卖 prompt 模板订阅赚钱的产品要重新想定位。

第三，对个人用户的真实建议，**不用等浏览器更新**，今天就在腾讯文档或飞书里建一个"我的 prompt 库"，按场景分 5 到 10 条最常用的。等国产浏览器推出原生功能，你直接迁移就行。范式是固定的，工具谁先做不重要。

提前练，不亏。
