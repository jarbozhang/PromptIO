# Google Veo 3.1 Lite 上线，对比国产即梦/可灵的性价比怎么算

## 为什么我专门写一篇

Google 把 Veo 3.1 Lite 推到了 paid preview，**720p 一秒 0.05 美元，1080p 一秒 0.08 美元**。这是 Google 视频生成全家桶里目前最便宜的一档，比 Veo 3.1 Fast 便宜一半，比 Standard 便宜八倍。

按 8 秒最长片段算，720p 一条 0.4 美元（约 2.9 元人民币），1080p 一条 0.64 美元（约 4.6 元）。对一个长期被即梦、可灵会员套餐"超额单价陡升"折磨的内容创作者来说，这是第一次"批量生 100 条短视频试创意"听起来像是合理预算的一档 AI 视频模型。

我自己最近在做小红书短视频素材，下面这套对比是我实际跑过几个工具后整理出来的省钱思路。

## Veo 3.1 全家桶的价格梯度

按 Gemini API 官方定价页，

| 档位 | 720p/秒 | 1080p/秒 | 4K/秒 |
|------|---------|----------|-------|
| Veo 3.1 **Lite** | $0.05 | $0.08 | 不支持 |
| Veo 3.1 **Fast** | $0.10 | $0.12 | $0.30 |
| Veo 3.1 **Standard** | $0.40 | $0.40 | $0.60 |

价格已经包含音轨。Google 自己的说法是 Lite "成本不到 Fast 的一半，速度和 Fast 相当"。代价是质量再降一档。

如果你不需要 4K、不需要电影级镜头细节，单纯是给小红书/视频号做配图、做短素材，Lite 就是性价比最高的那一档。

## Lite 能做什么

按 Google 官方说明，

- **支持**，文生视频、图生视频、4/6/8 秒可选、16:9 横屏 + 9:16 竖屏、720p/1080p 双分辨率
- **不支持 4K**（这一档需要走 Fast 或 Standard）
- **进阶能力归 Standard**，Veo 3.1 旗舰加的 Reference-to-Video（最多 3 张参考图保持角色一致）和首尾帧插值，官方文章没把这些功能明确划到 Lite 名下，目前可以保守理解为 Lite 主打基础文生视频和图生视频

定位很清楚，**做 vlog 转场、产品展示、商品视频背景、AI 拟人广告，Lite 够用；想做有连贯主角的剧情短片，上 Standard**。

## 国内创作者怎么调用

国内用户可以通过 **Replicate API 或国内代理服务**接入 Veo 3.1 Lite，本文不展开境外前端的访问细节。

- **Replicate**，Veo 3.1 系列已上线 Replicate 平台，按秒计费，定价通常比官方贵 20%-50%，但优势是集成进现有 pipeline 简单，国内开发者直连方便
- **国产中转 API 服务**，国内已有几家做 AI 模型聚合的中转平台，把 Veo 3.1 接进来按量计费，单价比 Replicate 略高但省去信用卡和支付环节

调用时模型 ID 选 `veo-3.1-lite`，按秒计费，本地脚本批量生成都可以。

## prompt 写法（共用 Veo 系列结构）

Veo 系列对 prompt 结构有明显偏好，Lite 共享同一套提示词逻辑，

1. **镜头构图**，明确镜头类型（"medium shot"、"close-up"、"wide establishing shot"）
2. **镜头运动**，dolly shot、tracking shot、pan shot 这类专业词比"camera moves"管用
3. **镜头特性**，shallow focus（浅景深）、macro lens（微距）、35mm film grain（胶片颗粒）
4. **风格定调**，sci-fi、anime、documentary、cinematic 这类风格关键词放前面

一个直接能套用的产品视频模板，

```
A medium shot of a [产品] on a marble countertop,
soft morning light from the left, shallow focus,
slow dolly-in camera movement, 8 seconds, cinematic,
warm color grading.
```

跑 Lite，720p 8 秒一条成本 0.4 美元。

## 对比国产即梦/可灵，怎么算账

这是我最关心的部分。

- **即梦**（字节），会员套餐里包额度，套餐内单条折算很便宜，**中文 prompt 理解和东亚审美最贴**，但超出套餐后单价会陡升
- **可灵**（快手），高清档画质上限不错，**人物表演和镜头语言在国产里属于第一梯队**，单条价格折算后高于 Veo 3.1 Lite
- **Veo 3.1 Lite**，英文 prompt 友好，跨场景泛化强，**单价做到 0.05/0.08 美元，是目前批量场景里最便宜的一档**

我自己的用法是，

- 拍中文人物对话、东亚街景、本土产品 → 用即梦/可灵，省 prompt 调试时间
- 跑产品空镜、抽象转场、英文场景背景、批量备选素材 → 用 Veo 3.1 Lite，单价压到底
- 想做有连贯主角的短剧 → Veo Lite 不够，回到可灵或 Veo Standard

**Lite 不会赢质量，Lite 赢的是单价。** 一周做 50 条素材成本不到 250 块，这是第一次出现"我可以为每个内容点子都生成 5 个备选视频，挑一个最好的留下"的预算合理性。

## 我的判断

值得在这个窗口期把 Lite 跑一遍，尤其是手里已经有素材 pipeline、平时用即梦/可灵不够用的创作者。

需要警惕两件事，

1. Lite 是 Standard 的精简版，不要拿它去对标旗舰档质量，预期错位会失望
2. paid preview 阶段定价会变，0.05/0.08 美元是窗口期价格，GA 后小幅涨价是常态

视频 AI 进入"白菜价"时代的那个临界点，Veo 3.1 Lite 是迄今最接近的一次定价。但对国内创作者来说，**真正的最优解大概率是"国产工具打底 + Veo Lite 做批量补充"的混搭组合**，而不是单押任何一边。
