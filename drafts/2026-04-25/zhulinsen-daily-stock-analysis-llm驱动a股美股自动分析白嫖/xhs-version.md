# 国产开发者搞了个 LLM 股票分析仪表盘，整套架构月费 0 元跑

GitHub trending 今天蹦出来一个项目，单日涨了 173 颗星，名字叫 daily_stock_analysis，作者是国内开发者 ZhuLinsen。

一句话介绍，LLM 驱动的 A 股/港股/美股智能分析器，多数据源行情加实时新闻，输出 LLM 决策仪表盘并多渠道推送，零成本定时运行。

我点进去翻了一晚上 README，把它跑了一遍，几个细节值得讲讲。

## 它到底在做什么

每天定时跑一次，从你预设的股票池里挨个抓行情、抓新闻，把数据喂给 LLM，让模型吐出一份决策仪表盘，再推送到企业微信、飞书、Telegram、邮箱。

仪表盘不是花里胡哨的图表堆砌，是一句话结论加买卖区间加操作清单。比如"今日观望，若跌破 XX 则减仓"，配上技术面、筹码分布、情绪指标这些维度。

A 股走"三段式复盘"，美股套 Regime Strategy，港股可以接长桥拿数据。还顺手做了 AI 回测，看模型过去预测得准不准。

## 为什么"零成本"能成立

行情、新闻、LLM、服务器，这四块成本作者都拆掉了。

行情这块走 AkShare、Tushare、Pytdx、Baostock、YFinance 几个开源/免费源轮询，港美股优先长桥。这几个库基本是国内量化圈老熟人，免费版够日频用。

新闻接 Tavily、SerpAPI、Brave、MiniMax 任选，多数都有免费额度。

LLM 这层用 LiteLLM 做了统一封装，DeepSeek、通义千问、Gemini、Ollama 本地模型都能接，还支持多 Key 负载均衡。国内开发者用 DeepSeek，单股票分析一次的 token 成本几乎可以忽略。

服务器最骚的一步，作者直接推荐 GitHub Actions。Fork 仓库、配 Secrets、开 Actions，定时任务默认工作日 18:00 北京时间触发。GitHub 个人账号每月 2000 分钟免费 CI 时长，跑日频任务绰绰有余。

四块都是免费额度拼出来的，所以叫月费 0 元。

## 我自己跑了一下，几个坑

第一个坑，LLM Key。我换成国内 DeepSeek，配一个 Key 直接跑通，单次分析十来只股票几分钱，比走 Gemini 稳定得多。

第二个坑，Tushare 对积分有要求，新账户拿不到完整数据。只看 A 股大盘股，AkShare 加 Baostock 其实够用，Tushare 可以先跳过。

第三个坑，推送渠道。企业微信和飞书都要建机器人拿 Webhook，邮箱要开 SMTP 授权码。我个人最后只留了一个 Telegram，消息聚合最干净。

第四个坑，筹码分布模块默认在 GitHub Actions 里关掉了，作者自己也说这块"潜在不稳"。本地跑可以打开，云端定时任务别开，省得 workflow 失败。

从 fork 到第一次收到推送，我大概花了一个半小时，一半时间花在调 Key 上。

## 我的判断

先说保留的一面。任何"AI 选股"工具的本质都是把人类偏见换了个数据管道，不会因为接了大模型就能预测市场。LLM 在金融文本理解、数据归纳、结构化输出上确实有用，但它不会让你稳赚。

这个项目真正打动我的，是把"用 LLM 自动消化每日资讯"跑通了一个完整闭环。哪怕你不炒股，把里面的 LLM 编排、多源数据兜底、GitHub Actions 定时调度拆出来，换成竞品价格监控、跨境电商选品、行业新闻摘要，都是一模一样的骨架。

独立开发者最缺的不是 idea，是这种可复用的工程模板。

至于炒股本身，把它当成"每天早上的市场速读机"，比当成"自动决策机"健康得多。开盘前扫一眼推送，知道你关心的票出了什么动静，剩下的判断还得自己做。它是信息整理工，不是投资建议生成器。

## 你可以怎么动手

最低成本路径，Fork 仓库，去 DeepSeek 拿一个 API Key，在 Settings/Secrets 里配上 STOCK_LIST 和一个推送渠道（Telegram 最省事），把 GitHub Actions 打开，cron 用默认值。明天工作日 18:00 收到第一份推送。

工程师可以把项目当架构样本读，重点看 LiteLLM 的统一封装、多数据源 fallback、prompt 怎么把行情和新闻结构化喂给模型。这三块抠出来，可以改造成你自己的领域 Agent。
