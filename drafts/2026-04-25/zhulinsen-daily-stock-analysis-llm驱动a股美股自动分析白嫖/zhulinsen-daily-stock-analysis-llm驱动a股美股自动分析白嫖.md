# 一个国产开发者用 LLM 做了 A/H/美股 自动分析仪表盘，整套架构白嫖跑

GitHub trending 今天蹦出来一个项目，单日涨了 173 颗星，名字叫 daily_stock_analysis。

作者是国内开发者 ZhuLinsen，自我描述用一句话讲完，"LLM 驱动的 A/H/美股 智能分析器，多数据源行情 + 实时新闻 + LLM 决策仪表盘 + 多渠道推送，零成本定时运行，纯白嫖"。

我看到"纯白嫖"三个字就坐不住了，点进去翻了一晚上 README。

## 它到底在做什么

把这事拆开讲。

每天定时跑一次，从你预设的股票池里挨个抓行情、抓新闻，把这些数据喂给 LLM，让模型吐出一份"决策仪表盘"，再推送到企业微信、飞书、Telegram、邮箱。

仪表盘不是那种花里胡哨的图表堆砌，是一句话结论加精确买卖点加操作清单。比如"今日观望，若跌破 XX 则减仓"，配上技术面 MA 排列、筹码分布、情绪指标、实时行情这些维度。

A 股走"三段式复盘"，美股套"Regime Strategy"，港股可以接长桥拿数据。还顺手做了 AI 回测，让你看看模型过去预测得准不准。

听起来是不是有点像把同花顺、富途、雪球的部分功能拆出来，重新用 LLM 串了一遍。

## 为什么标榜"零成本"能成立

我一开始是不信的。

行情数据要钱，新闻 API 要钱，LLM 要钱，服务器也要钱，这四块能全部白嫖？

翻完代码我大概理解了作者的拼装思路。

行情这块走 AkShare、Tushare、Pytdx、Baostock、YFinance 几个开源/免费源轮询，港美股优先长桥。这几个库基本都是国内量化圈的老熟人，免费版够日频用。

新闻接 Anspire、Tavily、SerpAPI、Bocha、Brave、MiniMax 任选，多数都有免费额度。

LLM 这层用 LiteLLM 做了统一封装，DeepSeek、通义千问、Gemini、AIHubMix、OpenAI 兼容 API、Ollama 本地模型都能接，还支持多 Key 负载均衡。国产开发者用 DeepSeek 和通义，单股票分析一次的 token 成本基本可以忽略。

服务器最骚的一步，作者直接推荐 GitHub Actions。Fork 仓库、配 Secrets、开 Actions，定时任务默认工作日 18:00 北京时间触发。GitHub 个人账号每个月 2000 分钟免费 CI 时长，跑日频任务绰绰有余。

四块成本被一一拆解掉，"零成本"这三个字才站得住。

## 我自己跑了一下，几个坑提前说

我把仓库 fork 过来跑了一遍，整个过程没那么"一键"，几个地方需要心理准备。

第一个坑是 LLM Key 的获取。作者推荐 AIHubMix 和 Gemini，但默认的几个免费额度对新手并不友好。我换成了国内的 DeepSeek，配了一个 Key 直接跑通，单次分析十来只股票大概几分钱，比 Gemini 走代理稳定得多。

第二个坑是 Tushare。它对积分有要求，没积分的新账户拿不到完整数据。如果你只看 A 股大盘股，AkShare 加 Baostock 其实够用，可以先把 Tushare 跳过。

第三个坑是推送渠道的配置体感。企业微信和飞书都需要建机器人拿 Webhook，邮箱要开 SMTP 授权码。我个人最后只留了一个 Telegram，因为消息聚合最干净。

第四个坑是筹码分布模块默认在 GitHub Actions 里关掉了，作者自己也说这块"潜在不稳"。如果你在本地跑可以打开试试，云端定时任务别开，省得整个 workflow 失败。

总结下来，从 fork 到第一次收到推送，我大概花了一个半小时，里面一半时间花在调 Key 上。

## 跟同类项目放一起怎么看

最近半年，LLM + 量化的开源项目冒出来了一波。

TradingAgents 走的是多 Agent 协作那条路，模拟基本面分析师、技术面分析师、风控经理几个角色互相辩论。架构更复杂，对模型能力要求更高。

ZhuLinsen 这个项目走的是另一条路，单 Agent 加结构化提示词，把多源数据塞进上下文让模型直接出结论。轻量，跑得快，对 LLM 的要求也低，DeepSeek 之类的国产模型就能扛住。

两条路各有受众。想研究 Agent 协作机制的人会喜欢 TradingAgents，想"今晚下班前部署完明天早上看推送"的散户和工程师，可能更愿意上手 daily_stock_analysis。

它的另一个差异点是 Web 工作台。作者做了一个明暗双主题的网页 UI，可以贴图、传 Excel、粘贴股票代码批量导入，还内置了 11 个交易策略让你跟 Agent 对话。这部分对纯定时推送派意义不大，但对想交互式调试策略的人是加分项。

## 我的判断

先说我比较保留的那一面。

任何"AI 选股"工具的本质都是把人类的偏见换了个数据管道，并不会因为你接了大模型就突然能预测市场。LLM 在金融文本理解、数据归纳、决策建议结构化上确实有用，但它不会让你稳赚，也不会取代你自己的判断框架。

我认为这个项目的价值，根本不在"赚钱"这件事上。

它真正打动我的，是把"用 LLM 自动消化每日资讯"这件事跑通了一个完整闭环。哪怕你不炒股，把里面的 LLM 编排、多源数据兜底、GitHub Actions 定时调度这套架构拆出来，换成竞品价格监控、跨境电商选品、行业新闻摘要、独立站日报，都是一模一样的骨架。

国产独立开发者最缺的不是 idea，是这种"完整跑通可被复用的工程模板"。这个项目恰好补上了。

至于炒股本身，我个人的体感是，把它当成"每天早上的市场速读机"，比当成"自动决策机"健康得多。开盘前花三分钟扫一眼推送，知道你关心的票出了什么动静、市场情绪在哪一档，剩下的判断还得自己做。

它不是投资建议，是信息整理工。这个边界一定要分清。

## 你可以怎么动手

如果只想试一下，最低成本路径是这样。

Fork 仓库，去 DeepSeek 拿一个 API Key，在 Settings/Secrets 里配上 STOCK_LIST 和一个推送渠道（Telegram 最省事），把 GitHub Actions 打开，cron 用默认值。明天工作日 18:00 你就能收到第一份推送。

如果你是工程师，把这个项目当架构样本读一遍，重点看 LiteLLM 的统一封装、多数据源 fallback、prompt 怎么把行情和新闻结构化喂给模型。这三块抠出来，直接改造成你自己的领域 Agent。

最后留一个开放问题给你。

如果让你把这套架构搬到非金融场景，你第一个想用它做什么？欢迎留言，下一篇可能就写它。
