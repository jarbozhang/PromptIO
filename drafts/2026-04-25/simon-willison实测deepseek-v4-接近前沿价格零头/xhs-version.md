# Simon Willison 实测 DeepSeek V4，国产大模型这次跑出了"接近前沿+价格零头"

昨天 DeepSeek V4 双发上 OpenRouter 的时候，我手头只有官方几行 spec 和定价表。

今天 Simon Willison 把 Pro 和 Flash 都实测了一遍，标题原句是 almost on the frontier, a fraction of the price。接近前沿，价格只是零头。

我把他文章里的实测细节扒了一遍，发现昨天我下的"Flash 改写国产大模型价格底"这个判断，可能还低估了一点。

## Simon 拿什么测的

熟悉他的人都知道，每次有重要模型发布，他都会甩同一个 prompt，"生成一个 SVG，画一只鹈鹕骑自行车"。

听起来很无厘头，但比 benchmark 实在。鹈鹕骑车这件事训练集里几乎没有，模型必须从"鹈鹕长什么样""自行车长什么样""两个东西怎么组合"三个维度同时推理，再把空间关系翻译成 SVG 坐标。

Flash 跑出来的结果，Simon 原话是 excellent bicycle，框架和链条画得到位，鹈鹕翅膀直接搭在车把上。

Pro 反而翻车。自行车主体没问题，但辐条画歪了，鹈鹕身子过大，只画了一个翅膀。

挺有意思。在这个测试里，Pro 没有比 Flash 表现好。

## 为什么 Pro 反而输给 Flash

DeepSeek 自家技术报告里有一段话，V4-Pro 单 token 的 FLOPs 只有 V3.2 的 27%。

也就是说，Pro 走的是"用更少算力做更多推理"。MoE 激活参数往下压，靠架构和训练数据补回来。

这条路线在 benchmark 数字上漂亮，但在"凭空想象一只鹈鹕怎么骑车"这种没有标准答案的开放任务上，可能会暴露出"想象力变窄"。

Flash 反而因为定位明确，"我就是给你做小任务、做快速推理"，预期不高，跑出来的 SVG 反而让人意外。

我自己一直觉得，鹈鹕骑车这种测试比 MMLU 之类更能看出模型真实手感。MMLU 是闭卷考试，鹈鹕骑车是开卷创作。

## 真正的看点是开源权重

昨天我在文章末尾给读者留了个"等一周看权重"的尾巴。

Simon 把这事说实了。Pro 和 Flash 都是 **MIT 协议开源**。这个许可证比 V3 当年还宽松，商用、改、二次发布都不受限。

他自己也兴奋，原话是希望能在自己 128GB 的 MacBook 上跑量化版的 Flash，并且预测 Unsloth 团队应该很快会出量化版本。

13B 激活的 Flash，量化到 4-bit，理论上一台 64GB 内存的 Mac Studio 就能跑。如果 Unsloth 的 GGUF 出来，llama.cpp 这一票本地推理工具马上就能接。

国内玩家想象空间更大。一台单卡 4090，跑 INT4 量化的 V4 Flash，做长上下文 RAG 应用，电费可能比调 API 还便宜。

## 我的判断

第一，Pro 这一档现在还不到"立刻 all in"的时候。Simon 鹈鹕测试 Pro 翻车，自家技术报告也承认在硬指标上还有追赶空间。如果你做的是高难度推理、复杂 agent 链路，先在 OpenRouter 上双跑对比。

第二，Flash 才是这次发布真正的"行业重启键"。任何一个跑了一年 RAG、跑了一年 agent 中间步骤的团队，都应该今天就把 Flash 加进 A/B 测试。国产大模型这一轮把"小模型最便宜档"的地板又往下踩了一截。

第三，开源权重被严重低估。MIT 协议加 13B 激活，意味着 Flash 在国内会有一波"私有化部署"浪潮。金融、医疗、政务这些对数据合规敏感的行业，之前因为没有合适的开源大模型只能买私有云 API，现在可以彻底切到本地。

冷静一点说，鹈鹕画图这种主观测试不能代表全部，benchmark 还要等社区跑完。但定价加开源这两件事叠加，已经够了。

## 行动建议

一，把 Simon 的鹈鹕 prompt 抄一下，自己在 OpenRouter 上跑一遍 V4 Pro 和 V4 Flash。Generate an SVG of a pelican riding a bicycle。OpenRouter 国内可以直连。

二，去 Hugging Face 盯 deepseek-ai 官方账号，等 GGUF 量化版上线，本地能跑的门槛就到"一张 4090"或"一台 64GB Mac"这一档。

三，把团队里那些"反正只是做意图识别、做简单分类"的 cheap call 翻出来，先切到 Flash 跑。

昨天我说"价格战新底部"。Simon 今天用一只画歪了的鹈鹕告诉我，底部还在往下走。
