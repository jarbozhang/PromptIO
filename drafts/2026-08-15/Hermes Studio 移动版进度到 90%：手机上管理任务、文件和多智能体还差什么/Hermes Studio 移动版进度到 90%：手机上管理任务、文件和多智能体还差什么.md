# Hermes Studio 移动版进度到 90%：手机上管理任务、文件和多智能体还差什么

如果你让 Agent 跑过长期任务，大概遇到过这种尴尬。人已经离开电脑，任务却还在继续，想看运行状态、检查文件改动，或者及时叫停，只能等回到桌面再处理。

Hermes Studio App 公布的最新开发进度已经到 90%。它带来的关键变化，并不是把聊天窗口缩进手机，而是把会话、文件 Diff、定时任务、用量监控和多 Agent 协作一起搬到了移动设备。

我最关注的是，Agent 工作流终于有机会摆脱持续守在电脑前的操作方式。正式发布前，可以围绕几个真实场景准备验证，看看它能否成为长期任务的移动控制台。

## 离开电脑后，长期任务缺的是干预入口

电脑版 Agent 工具适合创建任务，却不天然适合持续盯守。一次 Workflow 可能要运行很久，定时任务也可能在人不在电脑旁时启动。

真正麻烦的通常不是任务没开始，而是中途发生变化。模型是否仍在推理，调用了什么工具，修改了哪些文件，Token 消耗是否异常，多 Agent 有没有跑偏，这些信息如果只能回到电脑上查看，自动化越长，人的不确定感反而越强。

所以我看这次 90% 进度，重点不是移动版界面完成了多少，而是监督和干预能力是否已经接近电脑版。

## 把电脑版能力压进手机，新增的不只是会话

公开进度列出的功能覆盖已经相当完整。

| 使用环节 | 当前支持的移动能力 |
| --- | --- |
| 任务沟通 | 基础会话、历史记录、搜索、模型切换 |
| 运行观察 | 思考过程、工具调用、运行状态展示 |
| 文件检查 | 工作区文件读取、修改、Diff 变更查看 |
| 多智能体协作 | 多 Agent 群聊、成员管理、@Agent 协作 |
| 自动化管理 | Workflow 查看、运行和可视化管理 |
| 长期任务 | 定时任务创建、执行记录、运行历史查看 |
| 能力配置 | Skill、MCP、记忆、模型和 Profile 管理 |
| 成本与性能 | 日志、Token 用量、技能用量和性能监控 |
| 连续使用 | 多设备切换与移动界面适配 |

这组能力放在一起，才构成了移动端 Agent 控制台。只提供会话，用户只能给指令。加入 Diff、日志、运行历史和用量监控后，用户才有机会判断任务正在做什么、做得是否合理，以及要不要介入。

## 哪些能力开始具备实际价值

文件 Diff 是我认为最关键的一项。手机屏幕不适合阅读整个代码库，却适合快速检查一次改动的范围，确认 Agent 有没有碰到不该修改的文件。

定时任务和 Workflow 管理解决的是另一类问题。用户可以在移动设备上查看任务有没有执行、历史记录是否连续，以及当前运行到了哪一步。对于周期性整理、资料处理或代码维护，这比单纯收到一条完成通知更有用。

多 Agent 群聊与 @Agent 协作，则把移动端从观察窗口推向协作入口。一个 Agent 负责检索，另一个处理文件，用户可以在同一任务里查看成员并进行定向沟通。它能否好用，还要看触控操作和复杂状态在小屏幕上的呈现是否足够清楚。

日志、Token 用量、技能用量和性能监控也不能被当成附属功能。长期运行的 Agent 一旦出现重复调用或异常消耗，手机端若能及时暴露这些信号，用户就不必等任务结束后才发现问题。

## 90% 之后，真正难的是稳定和取舍

Hermes Studio 团队提到，移动版能够快速接近电脑版，依赖现有接口设计。原有功能可以复用统一接口和数据结构，移动端把精力放在交互适配，而不是再搭一套独立系统。

这个思路对 Agent 应用很有启发。移动端不该复制一套新的执行逻辑，它更适合成为同一套任务系统的另一个入口。会话、文件、运行状态和配置在设备之间保持一致，用户切换设备时才不会丢失上下文。

剩下的 10% 反而可能决定产品能不能长期用。团队接下来要处理细节、修复问题，并测试不同设备的稳定性。手机和平板的屏幕尺寸、侧边栏、输入区域、弹窗和触控操作已经做过适配，但复杂 Workflow、大段 Diff、多 Agent 同时更新时的体验，仍值得在正式发布后重点观察。

## 正式发布后，我会优先验证四个场景

我不会先用一句“功能齐不齐”判断移动版，而会看四条场景链能否跑通。

第一条是电脑创建长期任务，切到手机后查看工具调用和运行状态，再返回电脑继续处理。第二条是定时任务自动执行后，在手机上检查记录、日志和 Token 用量。第三条是 Agent 修改文件后，只靠移动端 Diff 判断改动范围。第四条是多 Agent 协作过程中，用 @Agent 定向补充要求，并确认任务状态同步到另一台设备。

这四个场景分别检验连续性、可观测性、审查能力和协作能力。只要其中一条断开，手机端就更像功能展示页，而不是可靠的任务控制台。

Hermes Studio App 尚未正式发布，当前更合适的动作是记下自己的长期任务验证样例，等待官方提供可验证入口后逐项检查。对经常让 Agent 跑 Workflow、定时任务或多角色协作的人，这次更新值得关注。对只需要短对话的人，移动版的复杂管理能力未必是刚需。

我的判断很直接。Agent 要真正进入持续工作的阶段，关键不只是能自动执行，还要让人随时看得见、接得上、管得住。Hermes Studio 移动版正在补的，正是这块长期被桌面限制住的控制层。
