# Pixelle-Video 一夜涨 308 星，国产 AI 全自动短视频引擎是不是要把搬运号干掉了

我有个朋友是搬运号操盘手，每天的工作就是从 YouTube 翻一段 3 分钟的视频，剪成 30 秒的卡点，配个音，丢抖音。一天能产出 8 条左右。

昨晚我把 Pixelle-Video 这个仓库 clone 下来，跑了一个 demo，一个 prompt 进去，一段 30 秒的成片出来。我没剪辑，没找素材，没配音。

跑通的那一刻我在想，他可能要换个工作了。

## Pixelle-Video 到底在干嘛

凌晨刷 GitHub Trending，看到一个名字挺洋气的项目叫 Pixelle-Video，一夜涨了 308 颗星，标题写着"AI 全自动短视频引擎"。我点进去看了一眼 README，是中文写的。

这是个国产项目，组织名 AIDC-AI，README 没有明确写背景。但整个项目从文案、教程到示例，全是中文，明显主战场就是国内创作者。

它在做什么事呢，一句话讲完，你给一个话题，它给你一条成片。

中间的 pipeline 是这样，文案生成，配图规划，逐帧处理，视频合成。先用 LLM 写脚本，然后给每一句配 AI 生成的画面，用 TTS 合成解说，最后再加个背景音乐拼起来。

技术栈是 ComfyUI 打底。LLM 那一层是开放的，你可以接 GPT-4o，可以接通义千问，接 DeepSeek，甚至本地 Ollama。视频模型用的是 WAN 2.1，画面用 FLUX 或 SD。TTS 那一层支持 Edge-TTS 和 Index-TTS，能做声音克隆。

License 是 Apache 2.0，能商用。

这套组合的意思是，你想花钱就接 API 一晚上几十块跑完，你想白嫖就本地 Ollama 加本地 ComfyUI，0 元也能跑，前提是你的显卡顶得住。

## 我自己跑了一遍

说实话我是抱着"反正又是个套壳"的心态点进去的，结果它真的能跑。

我的环境是 4090 24G。clone 下来按 README 装依赖，第一个坑是 ComfyUI 的模型权重得自己下，FLUX 那一套大概 30 多个 G，挂着梯子也下了快一个小时。

第二个坑是 WAN 2.1 的视频生成那一步，显存吃得很狠，第一次跑 OOM 了，我把分辨率从 720P 降到 480P 才过。

第三个坑是 TTS，Edge-TTS 默认那个声音是台湾腔，我改成了 zh-CN-XiaoyiNeural 才正常。

第一个 demo 我让它做"今天吃什么犯难选择恐惧症"，跑了 23 分钟出了一段 28 秒的视频。

成片质量怎么说呢，能看，但远谈不上"以假乱真"。AI 配图风格统一这块做得不错，画面之间不会割裂。但人物动作那一段一看就是 AI，手指还是糊的，嘴型对不上 TTS。

如果你要的是"快速产出 100 条铺量给抖音矩阵号刷算法"，这个质量已经够了。如果你想做"精品号涨粉"，还得人工再过一遍。

## 横着比一比同行

国内剪映那边的"AI 自动剪辑"，本质是给你的素材自动打点配卡点，输入端还是你得有素材。Pixelle-Video 是连素材都不要，纯文字进去。这是两个赛道。

CapCut Pro 海外版有个"AI Script to Video"，我去年用过，画面是从素材库里搜的真实片段拼接。Pixelle 是 AI 现生的画面，风格化更强，真实感更弱。

HeyGen 上周刚发的 HyperFrames 是另一种打法，主推数字人口播加镜头切换，目标是做"专业感"短视频。Pixelle 这种是"信息流批量生产"。

Sora 和 Runway 是底层视频模型，自己得拼 pipeline。Pixelle 等于把 pipeline 帮你拼好了，但视频质量受 WAN 2.1 制约，比 Sora 差一截。

升一格再看，国外创作者 SaaS 路线走得很重，订阅 30 美元起步。国内开源路线走得很猛，Apache 2.0 直接拿走，自己部署。

如果你是个手头有显卡的独立开发者，Pixelle 这种省下的就是真金白银。

## 一个会得罪人的判断

我的判断是，短视频创作者最大的敌人不是同行，是 AI 全自动 pipeline。

你一天剪 8 条，Pixelle 一台 4090 一天能跑 60 条。你的内容比它精致 10 倍，但抖音的算法只看完播率和互动率，不看你画面里手指有几根。

更狠的是，Pixelle 这种开源项目跑通之后，意味着任何一个有点编程基础的人，都能搭一个"内容工厂"，1 个人 = 一个 MCN。

我也理解搬运号操盘手们的处境，他们是吃信息差和效率差吃饭的，Pixelle 把"效率差"这一块直接抹平了，剩下的只有"选题差"和"账号差"。

但坦率讲，就 Pixelle 现在这个完成度，还远不到"颠覆"。视频质量做不到广告级，TTS 还是机器味重，人物动作糊。它现在是"批量铺量号"的福音，不是"精品号"的替代品。

我认为它真正的价值是开了个头。当 WAN 2.1 升到 3.0，当 FLUX 升到下一代，当 ComfyUI 这套基础设施再迭代两轮，这个 pipeline 跑出来的东西，可能就跟你手剪的没差别了。

到那时候，搬运不再是个工种。

## 你现在能做什么

如果你手头有张 16G 以上显存的卡，今晚就可以 clone 下来跑一遍，体验一下"输入话题，输出成片"是什么感觉。即使不打算长期用，对短视频赛道的理解也会更新一档。

如果你没显卡，README 里写了 RunningHub 这种云方案，按次付费跑一次大概几块钱。

最值得做的事不是急着用它去铺号，而是去想，当生产端的成本被砍到 0，作为创作者你真正不可替代的那部分，到底是什么。

这个问题的答案，可能比 Pixelle 本身重要 100 倍。
