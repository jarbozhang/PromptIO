# 一天涨 604 星，这个 Python 小工具让我卸载了手机里 8 个 APP

昨天 GitHub Trending 首页第一，一个叫 TrendRadar 的中文项目一天涨了 604 颗星，总数冲到了 5.3 万。

我盯着这个数字愣了一下。

因为我自己 PromptIO 每天跑的那个抓中文热点的脚本，底层用的就是它。我用了快两个月，没意识到它已经火成这样。

先说结论，这是过去半年我见过最"中国味"的开源工具。不是翻译自英文的，不是套 LangChain 壳的，是一个普通人为了解决"信息太多又太分散"这件事，自己动手写出来的。

## 痛点很具体，具体到你一定中过招

你手机里是不是装了知乎、微博、B站、抖音、小红书、今日头条、百度、贴吧、澎湃？

每天早上打开一遍，一小时没了。关键是，90% 的热搜你都不关心。明星塌房、球队输赢、地方八卦，你真正在意的那几个关键词（比如"DeepSeek"、"Claude"、"英伟达"），淹没在信息流里。

TrendRadar 做的事情简单粗暴，它把 11 个中文平台的榜单拉下来，按你设定的关键词过一遍，只把命中的那部分推给你。

就这么一件事。但你想想看，市面上真没有人专门做这个。要么是"今日热榜"那种网站，你还得自己点进去看；要么是商用的舆情工具，动辄几万块一年。

## 它到底能抓什么

我翻了一下它最新的平台列表，数了数，11 个。知乎、微博、抖音、B站、百度热搜、今日头条、贴吧、澎湃新闻、凤凰网、华尔街见闻、财联社。

这个组合挺聪明的，科技+财经+泛娱乐+长内容，基本覆盖了中文互联网的信息源头。你要是做产品经理、做投资、做自媒体、做 AI 相关开发，这一套下来你就不用再装 APP 了。

我自己 PromptIO 项目里，每天凌晨用它跑一次，把所有平台的当日热点导出来，然后过一遍 30 多个 AI 关键词（DeepSeek、Kimi、Claude、昇腾、英伟达、大模型、智能体……），筛出来的东西直接喂给 Claude 做选题评分。

说实话刚开始我还担心重复率，结果意外地低。知乎讨论的往往是深度分析，微博是情绪爆点，贴吧是下沉市场的反应，三者叠加起来信息密度相当高。

## 部署有三种姿势，我推荐 Docker

官方给了三条路。

第一条是 GitHub Actions，纯云端免费跑。好处是零门槛，坏处是数据得配一个 S3 兼容的对象存储（比如 Cloudflare R2）才能持久化，对新手稍微绕。

第二条是本地 Python 直接跑。适合会写 Python 的人，灵活度最高，但你要自己管进程、管依赖。

第三条是 Docker 一键起，这是我用的。一行 docker compose up，容器里自带 web 界面、SQLite 数据库、定时任务调度。数据完全在你自己机器上，想怎么查怎么查。

我跑的时候大概是这样，把仓库 clone 下来，改一下 config 里的关键词列表，进 docker 目录 docker compose up -d，完事。整个过程五分钟。

一个小坑提醒一下，默认 web 端口是 8080，如果你机器上已经有东西占了这个端口（我第一次就撞了），改成 18080 或者别的就行。

## 关键词过滤是它的灵魂

这个功能是我觉得最值钱的。

基础用法就是写一个关键词数组，命中就保留。但它支持几个进阶语法，很骚。

`+` 前缀是"必须同时包含"。比如你设 `AI + 编程`，就只有同时提到 AI 和编程的条目会被留下。适合收敛过宽的词。

`!` 前缀是"排除"。比如 `AI ! 恋爱`，就能把那些"AI 女友 APP"之类的内容过滤掉。

`@` 加数字是"限量"。比如 `明星@3` 只保留前三条明星相关的。

`/pattern/` 直接写正则。

你就想想，一个普通用户会用到正则的开源工具，作者得多较真才会把这个口子留出来。

## 推送渠道 9 个，挑一个顺手的

企业微信、个人微信、飞书、钉钉、Telegram、邮件、ntfy、Bark、Slack，外加自定义 webhook（Discord / Matrix / IFTTT 都能接）。

我用的是 Telegram，因为机器人配起来最简单，十分钟搞定。如果你是团队场景，飞书或者钉钉接企业群也很顺。

它有三种推送模式，每日汇总（早晚各一次）、实时榜单（有就推）、增量新增（只推新冒出来的）。我用的是增量模式，一天下来十几条消息，刚刚好。

## 社区在聊什么

GitHub 上有个 issue 挺有意思，有人问能不能加小红书。作者的回复是"在做了，但小红书的反爬比较硬，稳定性没有其它平台好"。这个回复很诚实，比那些"下个版本就上"的画饼强多了。

X 上我看到一条讨论，有老外用 Google 翻译硬啃这个项目的中文文档，评论说"this is what I've been looking for for Chinese market intel"。海外做中国市场的人早就盯上它了。

V2EX 那边有人吐槽说 UI 不够精致，这个我同意，web 界面就是朴素的表格+筛选器，没啥花哨的东西。但对我来说无所谓，工具的本份是好用不是好看。

还有一个我比较喜欢的细节，v5 之后它加了 MCP 协议支持。你可以在 Claude Desktop 或者 Cursor 里直接问"今天 AI 相关的热搜有哪些"，它会走本地 MCP 服务把数据喂回来。这步棋挺前瞻的。

## 我的判断

说真的，这个项目能火成这样，不是因为技术有多高深，是因为它戳中了一个被严重低估的需求，**中文互联网信息分发效率太低**。

我的判断是，接下来一两年会冒出一批这种"把国内 N 个 APP 信息聚合成一个 dashboard"的工具。TrendRadar 是第一个把事情做明白的。

有一个我不太同意作者的地方，官方定位里把"AI 舆情监控"放在第一位，我觉得这反而限制了它的想象空间。它其实是一个**通用的中文信息滤镜**，谁都能用，不止是做舆情的。做产品调研、追热点、选题、甚至是炒股找题材，都好使。

要不要部署，我的建议很直接，符合下面任意一条就装。

第一，你每天花超过 30 分钟刷中文热搜类 APP。
第二，你的工作需要跟踪某些特定关键词（公司名、产品名、行业术语）。
第三，你手头有一台能 24 小时开着的电脑或者 NAS。

如果都不符合，你就当看个乐子，这个作者值得点个星。
