# 墨墨背单词一年 163，我装了这个 7.9k 星的开源替代品，浏览器打开就能用

周末我帮我表妹看了一眼她的考研规划。

打开她手机第一件事，墨墨背单词的弹窗，"扩容 17600 词上限，限时 163 元"。她说已经充过两次了，不充每天背不了几个。

我当场给她换了个方案。浏览器打开一个网址，选 "考研英语"，开始敲键盘。没有注册，没有弹窗，没有词汇上限。

这个东西叫 TypeWords，GitHub 7.9k 星，GPL-3.0 开源。

我陪她试了俩小时，回来就想写这篇。不是因为它多高科技，是因为它把一件特别朴素的事做到位了，**让"背单词"这件事回到它该有的样子，一个人和一组单词，中间没有商业插件**。

## 为什么是"打字"，不是"选择"

先说清楚它和墨墨、扇贝、百词斩最根本的区别。

主流背单词 APP 走的是"认读"路径。给你一个英文，底下四个中文选项，你点对了算过。这个模式最大的问题，你的大脑其实在做**辨认**，不在做**产出**。真考试写作文要用的时候，脑子里只剩一个模糊的印象，拼不出来。

TypeWords 走的是另一条路。屏幕上给你中文，你敲英文。或者给你英文，你跟着敲一遍。

这个差别在神经科学上有个说法叫主动回忆（active recall）。简单讲，你手指把单词敲出来那一下，大脑走的是**运动皮层 + 语言中枢**联动，比眼睛扫一遍留下的痕迹深得多。

我表妹第一次敲 perseverance，敲错三次。等她敲对那一刻，她自己说了一句，"这个词我好像记住了"。

这就是肌肉记忆。

## 模式切换很凶，够你玩一年

它一共四种模式，不是花架子，是真能用的。

跟打模式，英文在上中文在下，你照着敲。适合**第一次见面的生词**。

默写模式，只给中文，你凭记忆敲英文。适合**考前最后冲刺**。

复习模式，基于艾宾浩斯记忆曲线，系统自动安排今天该复习哪些。适合**每天固定任务**。

自由模式，完全手动，你想练哪本词书哪几个单词都行。适合**临时查缺补漏**。

词书这块是真拉满了。站点首页一句话，"50+ 内置词库"。我数了一下常用的，CET-4、CET-6、考研、雅思、托福、GRE、GMAT、SAT、专四专八，外加程序员英语、初高中教材、新概念，还能导入自定义词书。

我表妹那本扇贝里 30 块钱买的"考研红宝书"词单，在这里直接是免费内置的。

这就是开源的意思。

## AI 释义怎么接进来

这部分我得坦率讲，这是这篇文章里我最容易被读者质疑的地方。

TypeWords 的 README 原文没有直接把 "AI 释义" 写成主打功能。它的单词卡内置了音标、美英双发音、例句、短语、同义词、词根、词源、错题统计，这些都是离线数据。

那 "AI 联动" 是怎么回事？

两条路子。第一条，项目最近在 issue 区讨论过接 OpenAI 兼容接口做"深度例句生成"，你填自己的 API key 或者本地 Ollama 地址，遇到生词可以让 GPT-4 / Claude / Qwen 现编一个贴近你水平的例句。这个功能在社区 fork 里已经跑通了，主分支还在整合。

第二条，更实用的做法是**你自己接**。它是网页应用，你用浏览器 Tampermonkey 装个油猴脚本，右键某个单词调 OpenAI 出解释、出同义词、出场景对话，十分钟能写完一个脚本。

我自己试的思路更简单，敲到生词时切到另一个标签页问 Claude，"给我 perseverance 的三个使用场景，分别放到 IT 面试、考研作文、日常邮件里"。回来继续敲。

这个用法听着土，但它的哲学是对的。**工具负责打字记忆，AI 负责语境扩展，两个事分开做**，比把什么都塞进一个 APP 里体验更顺。

## 自部署，Docker 一行命令

这块我真的测了，不是抄文档。

网页版直接用 typewords.cc 就行，数据存在你浏览器的 IndexedDB 里，不上云，不要账号。

想自己跑一份？

```
docker pull zyronon/typewords:latest
docker run -d -p 3000:80 --name typewords zyronon/typewords:latest
```

两行，完事。

我在自己的 NAS 上 30 秒起服务，浏览器打开 http://nas-ip:3000，就是一份自己的 TypeWords。

一个小坑提醒，它默认是纯前端应用，数据在浏览器本地。你要换电脑，得在设置里**手动导出 JSON**，拷贝到新机器导入。作者明确写了，"可选配置自己的 Supabase 实例做跨端同步"。但大多数人不需要这步。

## 墨墨、扇贝、不背、Anki，到底谁替代谁

我把主流选手排一下队，每个带一句点评，你自己看。

**扇贝单词**，¥98/年普通会员，¥348/年大会员。优势是社区氛围好，有打卡有小组。劣势是广告密度高，近两年内容运营比学习功能铺得更猛。

**墨墨背单词**，词汇量上限制模式，扩容 8800 词 ¥88，17600 词 ¥163。智能复习曲线是真的强，但它**把学习上限当商品卖**，这个设计哲学我始终接受不了。

**不背单词**，免费为主。功能比较基础，适合轻量用户。

**Anki**，免费开源的老大哥。极度强大，极度难学。自定义卡片要写 HTML，同步要自建服务器或者付 ¥3xx/年买官方云。Anki 适合**研究型学习者**，不适合考研党。

**TypeWords**，免费，开源，0 订阅，浏览器直接用，自带 50+ 词书，可自部署。

最大的差别是，前四个都在**卖你一个封闭体系**，你的学习数据躺在别人的服务器上。TypeWords 把数据给你了，代码也给你了，你想加功能自己 fork 就是。

我的判断是，**大学生、考研党、考证党，你就应该用 TypeWords**。理由非常直接，你们要背的是四六级、考研、雅思这几本经典词书，TypeWords 全有；你们最讨厌的是付费弹窗和每日词量限制，TypeWords 全没有。

剩下那 10% 的高阶需求（比如 Anki 那种极度自定义、或者墨墨那种精细化曲线），你等真的遇到再说。

## 社区在聊什么

GitHub issue 区我扒了一圈，有几个信号挺有意思。

有人提需求加"小红书背单词"词书，作者回复"欢迎 PR"。这种回复我喜欢，不画饼，谁想要谁自己写。

阮一峰的周刊早就收录过这个项目，留言区有个评论让我印象深的，"现在才发现背单词的 APP 都在收智商税"。这句话刺耳但真实。

知乎上我看到一个考研二战的姑娘写了自己的用法，她把 TypeWords 当作"每天早上 15 分钟的唤醒仪式"，打开网页敲 20 个考研词，大脑就进入学习状态了。她说这个体验比以前用墨墨舒服，因为**没有"任务感"**。

V2EX 上有程序员讨论它的程序员英语词书，说"早上站会前敲两分钟比刷推文有用"。

小红书上考研党分享的最多的一张截图，是 TypeWords 的错题本，"错一百遍不怕，不掏钱就行"。

这句话戳到我了。

## 我的判断

说实话我自己的英语已经不靠这类工具了。我写这篇，是因为我发现**付费背单词 APP 的商业模式正在崩解**。

什么崩解？

它们过去的价值有三层，**词书版权、复习算法、社区氛围**。现在词书版权基本没壁垒，互联网上所有常用词书都是公开的；复习算法艾宾浩斯曲线是 19 世纪就写进论文的公开知识；只剩下社区氛围这块还有点护城河，但 Z 世代的社交早就不在 APP 里了。

所以这些年墨墨、扇贝不得不靠 **付费扩容**、**VIP 会员**、**广告** 撑估值。这些事做多了，用户就会开始找替代。

TypeWords 就是那个替代。

我的判断很直接，**未来 3 年，大学校园里"墨墨是标配"这件事会被打破**。取代它的未必是 TypeWords 这一个具体项目，但一定是这种**开源 + 免费 + 自部署**的组合。

## 今天你可以做什么

如果你或者你身边有考研、考四六级、考雅思托福的人，今天只做两件事。

第一，打开 https://typewords.cc，选一本词书，敲 15 分钟，感受一下"打字背单词"的肌肉记忆。

第二，如果觉得顺手，把 GitHub 仓库 https://github.com/zyronon/TypeWords 点个星，然后把这篇转给那个正在给墨墨交 163 扩容费的朋友。

就这两件事。

回到开头那个画面。我表妹现在每天早上的第一件事，不再是刷墨墨的扩容弹窗，是打开一个网页，敲十分钟单词。

有时候"学英语"这件事，就是一次敲击，一点进步。
