# 有人把对冲基金的底层架构开源了，GitHub 5 万星，年化 30.5%，我敢跑实盘吗？说实话还是不敢

昨晚刷 GitHub，看到一个叫 TradingAgents 的项目冲到 52.1k 星。

点进去一看，差点把咖啡喷在屏幕上。

这不是一个交易机器人，这是一整家对冲基金的组织架构。4 个 AI 分析师、看多看空两派研究员吵架、交易员拍板、风控一票否决，全套开源，一分钱不要。

推文里说年化 30.5%，最大回撤和夏普比率（Sharpe Ratio，衡量承担每单位风险拿到多少超额收益的指标）都比基准策略好看。

华尔街那套收 2% 管理费 + 20% 业绩分成的老规矩，被 Python 代码给端了。

## 这玩意儿到底长什么样

先说清楚结构，不然容易被"50k 星"几个字冲昏头。

TradingAgents 本质是一个基于 LangGraph 的多 Agent 编排系统，Python 99.8%，装起来就三行命令。

它把一个基金的决策流切成四层。

第一层是分析师团队，4 个 Agent 分工，基本面分析师扫财报，情绪分析师扫舆情，新闻分析师扫突发，技术分析师看 K 线。

第二层最有意思，看多研究员（Bull）和看空研究员（Bear）要在系统里辩论。这不是客气地"发表观点"，是真的互怼，Prompt 层面就被设计成要找对方逻辑漏洞。

第三层是交易员 Agent，综合上面两派的吵架结果，给出买卖方向。

第四层是风控和投资组合经理，可以直接否决交易员的决定。

你看，这套流程和一家真实对冲基金的内部开会流程，几乎是 1:1 复制。

## 模型选哪家，它全都要

这是让我最服气的一点。

TradingAgents 不锁死在某一家模型。支持列表里有 OpenAI GPT-5.4、Anthropic Claude 4.6、Google Gemini 3.1、xAI Grok 4、DeepSeek、Qwen（阿里 DashScope）、GLM（智谱）、OpenRouter，还有 Ollama 跑本地模型。

对中国用户意义很大。你完全可以把分析师全换成 DeepSeek-V3.5，研究员辩论用 Qwen，风控官上个 GLM。成本直接砍一个量级。

推文里 Huanusa 说的"实测 30.5%"配的是 GPT-5.4 + Claude 4.6，这俩是当前最贵的两款，跑一次全流程 token 开销很可观。我估了一下，一个完整的交易日决策跑下来，按当前 API 价格，单标的成本大概在 2 到 5 美元之间。如果你要覆盖一个 30 支股票的组合，每天光 LLM 费用就够喝一壶。

## 先把"实盘"这件事说破

我必须在这里得罪一部分人。

项目 README 里写得很清楚，这东西跑的是 **simulated exchange**，模拟交易所。订单"被发送到模拟交易所并执行"。

翻译成人话，这是 paper trading（模拟盘），不是真金白银打到券商账户。

所以那个 30.5% 年化，是回测 + 模拟盘的结果，不是实盘收益。

这件事在推文传播里基本被淡化了。你看到的版本都是"年化 30.5% 吊打华尔街"，没人提这是模拟环境。

我认为这是整件事里最大的信息差。不是说回测没用，回测当然有用。但回测能做到 30% 的策略，到实盘能活下来的，我见过的比例不超过两成。真实市场里有滑点、有流动性枯竭、有你下单就被 HFT 抢跑、有黑天鹅来的时候 API 直接断连。这些在模拟盘里一个都不会出现。

作者自己也写了免责声明，"不构成金融、投资或交易建议"。这句话不是走形式，是认真的。

## 那它到底有什么用

先别急着关页面。

我的判断是，TradingAgents 的真正价值不是"帮你赚钱"，而是两件事。

第一，它是目前能找到的最完整的"多 Agent 对抗辩论"工程样板。你要做任何需要多方博弈的 Agent 系统，比如法律文书对抗、医疗诊断会诊、产品方案评审，直接拿它的 LangGraph 编排抄作业，比从零设计省两周。

第二，它给出了一个可以验证自己投研思路的沙盒。你心里有个选股逻辑，与其纠结一周，不如让四个 Agent 跑一轮，看看看多看空两边能不能把你的盲点骂出来。把它当"廉价版投研委员会"用，这个价值远大于当"印钞机"用。

说实话我自己装了一遍，用 DeepSeek 跑了一只自选股的 demo，出来的报告确实比我随手翻研报写得有条理。但我看到它给出"买入"建议的那一刻，也就是笑了一下，关掉了。

我敢让它管我的钱吗？

说实话还是不敢。

不是技术不行，是我还没想清楚，当它把我账户打到 -30% 的那一天，我该怪它还是怪我自己。这个心理账户没算清楚之前，任何 AI 交易系统对我都只是玩具。

## 你可以今晚就动手的事

如果你想亲自试一下，路径很短。

`git clone` 官方仓库，`pip install .`，然后 `tradingagents` 起服务。配置里把模型换成 DeepSeek 或者你本地的 Ollama，选一个你熟的标的跑一遍。

重点看两份输出。一份是看多看空研究员的辩论记录，那是这个项目含金量最高的部分，你会发现自己平时做决策漏掉了多少维度。另一份是风控 Agent 的否决理由，经常会给你意想不到的提醒。

跑完别直接去开通实盘。

先把它的输出和你过去三个月的真实交易决策对照一下。如果它的判断和你差很多，问自己谁更对；如果它和你高度一致，那你更要警惕，AI 正在复制你的偏见。

开源把对冲基金的组织结构抄了过来。

但真正的 alpha 从来不在组织结构里，在于你愿不愿意相信那个在凌晨三点告诉你"这单别下"的风控。

现在这个风控是 AI。

你准备好听它的话了吗？
