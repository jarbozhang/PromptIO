# Mira Murati 的 Thinking Machines 终于交卷，AI 边听边说要怎么用

Mira Murati 从 OpenAI 出走、拿 20 亿美元种子轮成立 Thinking Machines Lab 之后，我等了快一年才看到她押的第一个方向。5 月 11 日她在 X 上甩出一篇博客，附带一个叫 TML-Interaction-Small 的模型，276B 总参、12B 激活的 MoE，从零训练，主打"边听边说边看"。

她给这一类系统起了个新名字，interaction model。本号要单独写它，原因有三个。

一，这是 Murati 离开 OpenAI 后第一次给出明确产品路线，方向直接绕开了"更大 LLM"这条卷烂的赛道。

二，技术取舍很硬，原生 200ms 时间片对齐的 audio+video+text 输入，直接替换掉传统语音管线里那颗 VAD（Voice Activity Detection）。过去一年所有在用 VAD 切片 + Whisper + LLM + TTS 拼装出来的"实时语音 agent"，技术底盘要重做。

三，对中国开发者特别相关。国内一大批做语音陪伴、面试陪练、外语口语、直播互动、客服 agent 的团队，目前主流就是上面那套四件套拼装。Murati 这次给出的是另一条路，模型本身就是连续时间感知的，不再需要工程层去伪造"对话节奏"。

## 它到底做了什么

interaction model 的设计前提是把"单线程对话"改成连续流，模型在 200ms 的时间片里同时处理音频、视频、文本三路输入，生成响应的同时仍在接收输入，full-duplex 全双工。技术上对应几个具体选择，

- encoder-free early fusion，和 Meta Chameleon 路线类似，底层就把多模态打成对齐到时间轴的统一 token 序列。
- time-aligned microturns，每 200ms 一个"微回合"，模型可以选择"说话/沉默/继续听/打断自己"。
- 从零训练，不是在文本 LLM 上嫁接语音头，而是预训练阶段就喂连续多模态数据。

参数规模 276B-A12B 不算大，正好是一个能上 H100/H200 单机推理的尺寸。响应延迟官方报 0.40 秒，已经接近人类正常对话间隔（人对人对话的中位间隔约 200ms）。

跑分方面，Thinking Machines 自家造了五个新 benchmark，TimeSpeak（按指定时刻开口）、CueSpeak（在合适时机开口）、RepCount-A（连续视觉计数）、ProactiveVideoQA（限时回答）、Charades（动作时序定位），都是测"何时开口"和"何时闭嘴"这件事。这些维度传统 LLM benchmark 完全测不出来。

## 我的判断

这事对中国实时语音 agent 团队是一个明确预告，不是即时威胁，但要现在就开始想清楚。

短期 3 到 6 个月，TML-Interaction-Small 只放 research preview，不开权重也不开 API。所以现在国内做语音陪伴、口语陪练、电话客服 agent 的，不用慌，你的四件套明年这时候都还能跑。

但中期 6 到 12 个月有两件事会发生。

第一，国产复刻一定会来。"原生时间感知多模态"是论文级别可以追的方向，不像 SOTA 大 LLM 需要 100k 卡，智谱、阶跃、MiniMax 里至少有一家会在年内发出 demo。MiniMax 的 abab 7 系列已经有相关投入，阶跃刚发的 Step-3 也提到了 streaming 方向。

第二，海外几家头部也在跟进各自的 turn-based realtime 路线，但他们的难度在于"已经卖出去的 Realtime API 怎么平滑迁移"，这反而是后发者的窗口。

## 行动建议

对国内做实时语音 agent 的开发者，这一波我的具体建议，

1. 业务层不要再深度耦合 VAD 时序。如果你的 agent 逻辑里写了"等用户停顿 800ms 才触发回复"，明年这套逻辑要全部重写。把"何时开口"这个决策当成黑盒接口预留。
2. 数据收集马上转向"带时间戳的连续多模态对话"。原来你只录文本对话或语音 turn，下一代模型训练需要的是连续音视频流加上模型在每个 200ms 做的决策。现在开始攒，半年后国产 interaction 模型出来你就有微调数据。
3. 看准窗口下注。如果你做的是面向 C 端的语音陪伴/口语陪练，2026 下半年大概率会出现一波"原生 interaction 模型"驱动的新产品。这是创业窗口，独立开发者用 API 套壳半年内能跑出 demo。
4. 不要押 Thinking Machines 第一方 API。20 亿种子轮也烧得起两年，但 Murati 团队历史风格是慢工出细活，公开 API 大概率 2026 年底。押开源复刻把握更大。

国内可以直接关注的国产 streaming/多模态线，MiniMax、智谱、阶跃，明年这个时候大概率有人交卷。

最后说一句对 Murati 本人的判断。她离开 OpenAI 的时候大家都在赌她会做"安全派 LLM"或者"个人 AI"，结果她押的是一个比 LLM 更上游的范式，人机交互的物理层。这个押注如果成立，未来五年的 AI 产品形态会比"对话框 + LLM"更像"打电话 + 视频通话"。她从 OpenAI 走出来后第一份答卷，方向感上很清晰。
