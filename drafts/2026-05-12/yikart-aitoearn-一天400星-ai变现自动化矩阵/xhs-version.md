# AiToEarn 单日 +427 星，国产开源 AI 创作者全链路工具

今天刷 GitHub Trending 看到一个叫 AiToEarn 的项目单日涨 427 星。点进去之前我以为又是一个套壳的 AI 写文案工具，结果发现它做的是创作者从内容生产到多平台分发再到结算的全链路工具。

仓库 slogan 写得很直接，Monetize, Publish, Engage, Create。我顺着 README 把功能扒了一遍，越看越觉得这是把创作者一天到晚要切换的那十几个 App 塞进了一个 Electron 桌面端，再用 Agent 去串。

## 它到底是什么

AiToEarn 是 yikart 团队开源的内容创作辅助平台，TypeScript 写的（92.6%），桌面端用 Electron，后端 MongoDB + Redis，Node 20.18，许可证 MIT。最新 release 是 3 月底的 v2.1.0。

国产开源里愿意把"全链路创作者工具"开源到这个完成度的不多，多数同类项目要么只做发布、要么只做内容生成。AiToEarn 把四件事拆成了四个 Agent 跑在同一个壳里。

- **Create Agent**, 内容创作辅助，接多家 AI 模型出图出视频
- **Publish Agent**, 一键分发到十几个平台，国内覆盖小红书、抖音、快手、B 站、视频号，海外覆盖 TikTok、YouTube、Facebook、Instagram、Threads、X、Pinterest、LinkedIn，带日历排期
- **Engage Agent**, 处理互动，回复用 AI 生成
- **Monetize Agent**, 内容创作者接广告主推广任务的撮合层，支持 CPS、CPE、CPM 三种结算

## 为什么是今天突然 +427 星

我去看了 commit 历史，过去一周提交频率不算异常，没有什么明星 PR。但 release 节奏挺密，26 个 release，主线 2592 个 commit，说明项目积累了一段时间，只是今天才被 GitHub Trending 推到中文开发者眼前。

最有意思的是它在 README 里直接把 OpenClaw 集成和 MCP 协议作为部署方式列了出来，跟 Docker Compose、源码部署平级。所以你可以在 Claude、Cursor 这类 Agent 客户端里直接调 AiToEarn 的能力，不一定要开它的 Electron 客户端。这条路在国产开源里算少见。

## 我对这个工具的定位

我得先把话说在前面。这类多账号分发 + 自动互动的工具，监管和平台都很敏感，**它是一个内容创作辅助工具，不是养号工具，把它当后者用会踩雷**。

我的判断是它真正适合的场景是这种，你已经在小红书或者抖音有一两个号在认真运营，每天的瓶颈不是想不出选题，而是切来切去手都酸了，封面、文案、排期、跨平台同步、回评论这些机械活吃掉你大半时间。这种场景下，把 AiToEarn 当成一个创作辅助 + 跨平台分发的本地工具，能把你从重复劳动里解放出来。

如果你想拿它去做同质化高频发布的玩法，平台风控早就升级到能识别了，工具再先进也没用，最后是号和工具一起没。

## 独立开发者可以怎么用

我对它最感兴趣的两块。

第一块是 Publish Agent 的多平台分发。国内做内容的人都知道，把同一段视频从抖音搬到 B 站再搬到视频号再搬到小红书，每个平台的尺寸、封面比例、标题规则、tag 规则都不一样，手工搬一次至少 20 分钟。AiToEarn 这一层如果跑得稳定，单这个功能就值得装来用。

第二块是 MCP 集成。这个对独立开发者意义更大。你写一个自动化工作流，比如用 Claude 把今天爬到的 GitHub Trending 整理成一篇短视频文案，配音、配图，分发到指定的几个平台，整条链路可以在 Claude Code 或者 Cursor 里跑完，不用切到另一个工具去点按钮。

我建议这样上手：

1. 先 clone 仓库本地跑，不要先用官网托管版（aitoearn.cn / aitoearn.ai），先确认开源版本能不能满足你的需求再决定要不要付费托管
2. 先只接一个平台，比如只接小红书或者只接 B 站，跑通从 AI 生成图文到一键发布这条最短路径，不要一上来就把十几个平台全接上
3. 互动那块（Engage Agent）要谨慎开，自动点赞、自动关注是平台风控的高敏感动作，建议先关，只用 AI 辅助生成回复内容，自己手动点发送
4. 如果你已经有 MCP 客户端的工作流，去看 README 里 MCP 协议那一段，把 AiToEarn 当成一个工具节点接进去，而不是当一个独立 App 用，这是它跟同类工具拉开差距的地方

## 一个值得留意的信号

我注意到这个项目把 OpenClaw 作为一种部署方式单独列出来，跟 Docker 平级。这其实是国产开源生态在过去半年的一个新趋势，项目方开始把 Agent 客户端当成另一种交付通道，而不只是命令行和容器。

往后看，可能会有越来越多 AiToEarn 这种业务型项目通过 MCP 直接进入 Agent 工作流，而不是要求用户先打开它自己的客户端。对独立开发者来说，这是把自己原本要做的一堆 UI 工作省掉的好机会。

工具本身能不能跑出量、能不能持续维护，三个月后再回头看。但今天值得装来玩一下，至少能看清这套 AI + 创作者工具链的国产开源到底走到了哪一步。
