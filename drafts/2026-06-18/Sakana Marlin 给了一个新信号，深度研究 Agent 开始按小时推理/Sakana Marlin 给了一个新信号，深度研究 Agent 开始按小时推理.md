# Sakana Marlin 给了一个新信号，深度研究 Agent 开始按小时推理

如果你现在还把深度研究 Agent 当成“回答更长的搜索助手”，很容易用错。

Sakana Marlin 这次让我在意的，不是它又能生成一份报告，而是它把推理时间尺度直接拉到了最长 8 小时。这个信号很明确，一部分 Agent 不再追求秒回，而是开始像研究员一样，把假设、网页导航、矛盾处理、报告和 slides 串成一个长任务。

我会把它当成一个选型提醒。不是所有问题都值得交给长推理 Agent，但有些任务继续让秒回助手硬答，反而是在浪费上下文和判断力。

## 先把任务分成秒回和长跑

hardmaru 对 Sakana Marlin 的描述很直接，它是 Sakana AI 的第一个商业产品，一个自主的 Ultra Deep Research agent，定位是 Virtual CSO。

这里的 CSO 可以理解成偏战略判断的研究角色。它不是只把网页内容摘出来，而是要形成假设，自己导航网页，处理互相冲突的信息，最后交付专家级策略报告和结构化 slides。

我看到这段介绍时，第一反应不是“它会不会替代搜索”。更关键的问题是，哪些任务需要这种长时间推理。

我的粗分是这样。

- 秒回助手适合，单点解释、代码片段、文案改写、已知资料摘要、低风险脑暴
- 长推理 Agent 适合，市场进入判断、竞品路线梳理、技术选型报告、复杂公司研究、需要 slides 的汇报材料
- 仍然不该交给 Agent，最终投资决策、法务结论、医学建议、没有可验证来源的个人判断

也就是说，Marlin 代表的不是“回答更慢”，而是“把慢变成工作流”。

## 把假设形成当成第一步交付

普通助手最常见的问题，是它一上来就给结论。读起来很顺，但你不知道它有没有想过别的可能。

Marlin 的描述里，我最看重的是 forms hypotheses。假设形成这件事很小，却决定了深度研究是不是靠谱。

比如你让一个 Agent 研究某个新市场。秒回助手通常会直接列市场规模、玩家、机会点。长推理 Agent 更应该先拆出几组假设，例如需求是真增长还是短期噪声，主要约束是分发、成本还是监管，现有玩家为什么没有解决。

这类任务的好交付，不该只有答案。它应该让你看到推理分叉。

我会要求它在报告里保留这些东西。

- 初始假设，为什么先这么判断
- 反证路径，哪些信息会推翻判断
- 矛盾来源，不同页面为什么说法不同
- 证据等级，官方材料、产品页面、二手转述分开处理
- 最终建议，和假设之间能对上

这里最容易踩坑。长推理不等于可信，跑 8 小时也可能只是把错误信息整理得更漂亮。真正要看的是，它有没有把冲突留下来，而不是把冲突磨平。

## 让网页导航服务于判断

Marlin 强调 navigates the web 和 resolves contradictions。这两句放在一起看，才是重点。

网页导航不是多开几个页面，也不是把搜索结果堆满。它应该服务于判断，尤其是当公开材料互相打架时，Agent 要知道继续查哪里，而不是选一个顺眼的版本。

我会把适合长推理 Agent 的任务压成这种格式。

- 我要做一个进入某行业的判断
- 已知信息可能互相冲突
- 需要给管理层或团队看，不只给我自己看
- 最终交付要包含报告和 slides
- 结论要能追溯到证据，而不是只给漂亮总结

这也是 Virtual CSO 这个定位有意思的地方。CSO 式任务不是“帮我查一下”，而是“帮我把一个战略问题研究到可以开会”。

如果你的任务只是问某个概念怎么理解，长推理 Agent 反而不划算。它擅长的是把多步不确定性收束成可讨论材料。

## 不要把所有复杂问题都丢进去

我的判断很简单，长推理 Agent 值得用在高价值、低频、需要交付的任务上。

如果一个任务没有明确决策对象，也没有明确交付形态，只是想“多了解一下”，它很容易变成一份看起来很厚的资料包。资料越厚，越容易让人误以为判断已经完成。

更稳的做法，是先给它一个很窄的问题。

- 不要问，帮我研究 AI 安全市场
- 改成，帮我判断某类团队在未来 6 个月是否值得做 AI 安全产品
- 不要问，某家公司怎么样
- 改成，帮我找出这家公司战略变化的 3 个可验证信号
- 不要问，生成一份行业报告
- 改成，生成一份可以拿去内部讨论的策略报告和 slides 大纲

这个改法很重要。长推理 Agent 的成本不只在时间，也在你读报告、核查来源、消化结论的时间。

## 下一步先验一个高摩擦任务

我不会一上来把关键项目全部交给 Marlin 这种长推理 Agent。更合理的入口，是拿一个你已经觉得麻烦、但结果可核查的任务做验证。

比如选一个竞品研究、技术路线判断、客户行业拆解，限定它交付一份策略报告和一份 slides 结构。然后你只检查三件事。

- 它有没有提出可反驳的假设
- 它有没有处理冲突信息
- 它的 slides 是否真的能帮你开会，而不是把报告切成几页

如果这三件事过不了，8 小时推理也只是更长的文本生成。

如果过得了，深度研究 Agent 的价值就很清楚了。它不是替你做最终判断，而是把你从“到处查资料”推进到“面对证据做选择”。
