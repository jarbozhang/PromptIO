# Codex 的图像 Agent 模式来了：用侧边栏批量改图，创作者终于不用反复抽卡

如果你经常改海报、产品图或社交媒体配图，最耗时间的通常不是生成第一张，而是后面那几轮局部调整。主体要保留，背景要换，尺寸要重排，某个元素还得擦掉，传统做法很容易变成整张图重新生成。

Codex 最近加入了一套专门面向图像 Agent 的交互方式。生成图片后，点击图片就能打开侧边栏预览，在同一个位置完成评论、擦除和调整尺寸，还可以多选图片交给 GPT 批量修改。

我更关心的不是“又多了几个按钮”，而是它把图像工作从反复抽卡，推向了围绕结果持续修改。下面用一次海报迭代的路径，把这套界面怎么用、什么时候值得用讲清楚。

## 选一个最小场景，把改图目标说窄

先不要拿整套品牌素材上手。选一张已经接近可用的活动海报，里面有明确主体、标题区域和一个需要调整的视觉元素。

例如，第一轮只处理右下角产品图。目标可以写成，保留主体、背景色和整体构图，只擦除右下角的旧道具，并把产品放大到更适合竖版画布的比例。

这类任务适合侧边栏，因为修改变量很少，前后差异容易判断。信息来自公开帖子和讨论线索，实际使用时仍应以当前 Codex 界面和官方说明为准。

## 沿着预览、评论、局部修改走一遍

生成结果后，点击图片进入侧边栏预览。这里的价值在于，图片从聊天流里的一个结果，变成了可以继续处理的工作对象。

我的建议是把评论写成“保留什么、只改什么、不要动什么”三段式，而不是一句“让它更好看”。例如，保留人物姿态和主色，只把背景中的杂物擦除，标题留白不要缩小。

需要处理局部时，用擦除动作锁定范围。范围越具体，越容易避免模型把整张海报重新解释一遍。调整尺寸则适合放在构图已经稳定之后，先确认主体位置，再决定横版、竖版或社交媒体比例。

如果手里有多张方向接近的图，可以多选后一起加入输入框，让 GPT 按同一条规则批量修改。这个流程更像一个小型设计 Agent，批量任务交给模型，人工只负责定义边界和验收结果。

## 用这张验收卡判断改动是否合格

- 主体有没有被误擦或变形
- 只要求改动的区域是否真的发生变化
- 没有要求修改的颜色、文字位置和构图是否保持稳定
- 调整尺寸后，主体是否仍然适合目标版式
- 多图批改时，不同图片的修改规则是否一致
- 结果是否比原图更接近交付，而不是只是换了一种风格

我认为这张卡比“看起来更漂亮”更可靠。图像 Agent 的优势不在于替你做审美决定，而在于把已经明确的修改意图，连续落实到多个版本上。

## 什么时候它比无限画布更顺手

无限画布适合同时管理素材、图层和复杂构图，纯提示词抽卡则适合快速探索方向。Codex 这套侧边栏路径处在两者之间，它不要求你先搭完整画布，也不把每次修改都变成重新生成。

公开讨论里，有人认为直接编辑输出比只在聊天里写提示词更适合迭代，也有人指出 Windows 版本的功能上线情况可能不同。还有一个现实限制，图像生成会消耗额度，所以批量修改前最好先把规则写得足够具体。

真正值得保留的操作习惯是，圈出区域，说明只改什么，声明其余元素不动，再对比前后图。这样做，局部修改才不会滑回“重新抽卡”。

我会把它优先放进海报改版、产品图清理和多尺寸适配这三类任务。下一次遇到一张七成完成、但还有几个局部问题的图片，可以直接按这条路径验证，而不是从空白提示词重新开始。
