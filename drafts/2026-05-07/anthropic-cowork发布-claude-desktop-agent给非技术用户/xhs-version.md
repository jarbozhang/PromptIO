# Anthropic 发了个 Cowork，让会计 HR 也能用 agent，国产工具今晚拼一个

1 月 12 日 Anthropic 在 macOS 上推了个新东西叫 Cowork。一句话，把过去给程序员用的 Claude Code 那套"给目标 agent 自己开文件自己干活"的模式，搬到了 HR 整理简历、会计处理发票、市场跑报销这些非技术任务上。

研究预览阶段，绑定 Claude Max 订阅。境外服务定价对国内读者参考意义有限，本文重点放在国产工具今晚怎么拼一个出来。

## Cowork 的种子是 Anthropic 自己看到的"非典型用户"

Cowork 不是从 0 设计的。Anthropic 工程师 Boris Cherny 给 VentureBeat 讲过一个细节，Claude Code 上线后，团队发现一群很奇怪的用户，他们不写代码，但用这个终端工具做别的事，做出行规划、做 PPT、清理邮箱、读发票生成报销表。

开发者工具被办公人群"误用"了，而且用得不算难受。Anthropic 的判断是，如果一个 CLI 工具都能被非工程师拿来跑日常，那把它包成桌面 GUI、加上文件读写权限、加上文件夹理解，能直接对到一个比开发者市场大十倍的人群。

更关键的，Cowork 这个产品本身一周半就做完了，工程师团队主要靠他们自己用 Claude Code 写。一个把 Claude Code 改造成办公 agent 的工具，是用 Claude Code 做出来的。

## 设计思路是"目录即上下文"

Cowork 给非技术用户的入口很克制，不是开放式对话框，而是围绕"打开一个文件夹，让 agent 在这个文件夹里干活"展开。

报销场景，把发票图片和 PDF 扔进文件夹，告诉它整理成 expense report，agent 自己读自己分类自己生成 Excel。邮件场景，连接邮箱让它清理 spam、归档 newsletter。市场场景，给一堆素材让它生成幻灯片。

不需要教用户什么是 prompt engineering，不需要教 RAG。把"你想干嘛"和"在哪些文件上干"两件事问清楚，剩下交给 agent。这跟 Microsoft Copilot 那条嵌入 Word/Excel 边栏的路径走的是相反方向，agent 是中心，文件和应用是 agent 操作的对象。

## 国产桌面 AI 助手已经有三家在跑

回看国内，对话式桌面 AI 不是新东西。豆包桌面版 2024 下半年上 Mac/Windows，主打全局浮窗。腾讯元宝桌面版 2025 年初推出，深度绑微信生态。Kimi 桌面客户端定位长文档分析。

这三家共同点是 agent 围绕"对话"展开，浮窗里跟它说话浮窗里给答案，要不要读电脑文件是有限勾选项。Cowork 一开始就把"文件操作权限"当默认能力，读文件夹下所有发票、改 Excel、生成 PDF，是 day-1 功能。

技术上国产大模型不缺工具调用和文件读写能力，差的是产品形态的决心。

## 不用等国产 Cowork，今晚自己拼一个

"目录即上下文"这个心智模型不用等国产大厂抄，桌面端开源工具拼一下能复刻七成效果。

第一步，桌面客户端用 Cherry Studio 或 LobeChat 桌面版。两者都开源、跨 Mac/Windows、内置文件读写，LobeChat 的 file artifact 能直接读 PDF/Excel。

第二步，模型层填 DeepSeek 官方 API key，或走硅基流动、OpenRouter 国内可用节点选 Kimi K2、Qwen3-Max，国内网络稳定且发票合规。

第三步，跑三个原版场景验证。把发票图片拖进对话让模型生成 Excel 报销表；把邮件导出成 mbox 让它归档；把素材文件夹丢给它生成幻灯片大纲。文件读写权限在客户端设置里手动开。

想更贴近 Claude Code 的 agent 形态，把 aider 接 DeepSeek，cd 到工作文件夹直接 `aider --model deepseek/deepseek-chat`，目录里文件自动进上下文边读边改，这就是国产版"目录即上下文"。

## 我的判断

效果上限肯定不如 Cowork 原版，但报销整理、邮件分类、PPT 草稿这种活，一晚上能跑通，零订阅成本。

下一波继续盯豆包、Kimi、元宝谁先把这套打包成正式产品。一个 Cowork-like 的国产产品只盯本地文件会错过最大入口，白领日常工作大量发生在企业微信、钉钉、飞书的云文档里，桌面文件夹的中心地位比北美低。先做云文档版本技术难度更高，但谁先做出来谁吃到下一波办公 AI 红利。

我自己最近在 Cherry Studio + DeepSeek 这套上跑发票整理，上限不高但够日常，等国产正式产品出来之前先用着。
