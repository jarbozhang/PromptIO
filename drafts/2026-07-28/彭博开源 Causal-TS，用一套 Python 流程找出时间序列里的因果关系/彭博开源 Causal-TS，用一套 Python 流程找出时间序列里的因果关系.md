# 彭博开源 Causal-TS，用一套 Python 流程找出时间序列里的因果关系

如果你手里有一组业务指标、设备传感器数据或金融时间序列，真正棘手的通常不是预测下一刻，而是判断一个变量的变化是否可能推动了另一个变量。

Causal-TS 给出了一条值得验证的 Python 路径。它能检测时间序列中的结构突变，再按不同阶段分别做因果发现，避免拿一套关系解释整段不断变化的数据。

我更看重它的工程完整度。变化点检测、因果发现、命令行入口、合成数据生成，以及可选的因果效应估计被接进了同一条流程，适合拿一个小问题快速验证。

## 选一个会发生结构变化的最小场景

我不会一上来塞入几十个变量。更合适的起点，是选择三到六条时间对齐、业务含义明确，而且可能经历过机制变化的序列。

例如设备监控可以放入温度、振动、电流和故障告警。业务分析可以使用流量、下单量、履约时长和退款率。金融研究则可以从价格、成交量和波动指标出发，但输出只能用于研究与复盘，不能直接转成收益承诺或实盘指令。

最小输入应满足这几项。

- 每个变量都有清楚的定义和采样频率
- 时间戳已经对齐，缺失值处理方式有记录
- 已知的版本发布、设备检修或规则调整被保留下来
- 目标不是证明预设结论，而是寻找需要进一步验证的候选关系

这一步看似朴素，却决定了后面发现的是可解释结构，还是数据清洗遗留的噪声。

## 把结构突变放在因果发现前面

Causal-TS 的关键设计，是先用可替换的变化点检测器寻找结构断点，再针对每个阶段使用独立参数运行因果发现。

这对非平稳数据很重要。假设一次设备检修改变了温度与振动的联动方式，或者一次业务规则调整改变了流量到订单的转化路径。若把调整前后的数据揉在一起，算法可能得到一条平均意义上存在、任何阶段都不够准确的关系。

我会把操作路径压成四个动作。

1. 准备按时间排列的多变量数据，并保留变量说明与事件记录。
2. 选择变化点检测器，让流程识别可能的结构断点。
3. 按发现的阶段分别运行因果发现，并为不同阶段设置参数。
4. 比较各阶段的候选因果图，再决定是否进入因果效应估计。

库内提供 CDNOTS、CDNOTS+、CEDAR 和 GRACE 四种专用算法，也封装了 GES、Granger、LASSO-VAR 与 LGES。它们共用统一的条件独立性检验层，并可通过 PyTorch 使用 GPU 加速。

工程接入方面，Causal-TS 提供命令行界面和合成数据生成器，也能选择连接 DoWhy，把流程从原始时间序列延伸到因果效应估计。项目可通过 pip 安装，测试覆盖 Python 3.10 至 3.12。

## 用阶段稳定性验收结果

跑出一张因果图不算完成。我会重点看关系能否通过三个层面的验收。

- 阶段内稳定性，同一阶段稍微调整时间窗口或参数后，关键边是否仍然出现
- 阶段间可解释性，关系的出现或消失能否对应设备检修、策略切换或环境变化
- 方法间一致性，不同发现算法是否给出方向接近的候选关系，分歧发生在哪里

合成数据生成器在这里很有用。可以先构造已知结构的数据，检查整条流程能否找回预设关系，再换成真实数据。这个动作不能证明真实场景里的结论正确，却能尽早暴露配置、数据格式和分析路径的问题。

我的验收标准不是图越密越好，而是每条关键边都能回答三个问题，它在哪个阶段成立，它对参数变化是否敏感，它还需要什么额外证据。

## 别把领先关系直接写成因果关系

时间上的先后、Granger 关系或统计相关性，都只能提供候选线索。隐藏共同原因、变量遗漏、采样频率不合适和结构突变，都可能让两条序列看起来存在方向关系。

例如温度升高先于设备告警，不等于降低温度一定能减少告警。负载上升可能同时推高温度和故障风险。若负载没有进入数据，温度就可能替共同原因背锅。

业务指标也一样。活动期间流量和订单同时上升，背后可能是预算、渠道与商品供给共同变化。仅凭时间序列里的同步或领先关系，就把流量写成订单增长的原因，落到决策上会很危险。

所以我会把 Causal-TS 的输出叫作候选因果结构。只有在变量覆盖合理、阶段划分可信、假设能够解释，并且效应估计或额外验证继续支持时，才把结论往因果判断推进。

## 检查四个常见坑

- 结构断点过多，检查噪声、异常点或检测器参数，过短阶段很难提供稳定证据
- 阶段完全没有变化，检查检测器是否漏掉已知事件，也要接受数据确实不支持分段的可能
- 因果图过密，回头处理变量尺度、滞后设置和条件独立性检验配置
- 算法结论互相冲突，不要挑一张最顺眼的图，应记录假设差异并缩小问题范围

我建议用一份小型合成数据和一份真实数据各跑一次。先确认流程能识别已知结构，再观察真实数据在结构突变前后出现了哪些关系变化。

真正值得带走的不是某一条漂亮的箭头，而是一条可复查的证据链。选定变量，识别阶段，分段发现，检查稳定性，再决定是否估计效应。
