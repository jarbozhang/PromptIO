# 乔木 NotebookLM Skill 把公众号和 PDF 变播客课件

今天 GitHub Trending 里有个中文内容团队很该看的项目，joeseesun/qiaomu-anything-to-notebooklm。

它的定位很直接，Claude Skill，把 WeChat 文章、网页、YouTube、PDF、Markdown、搜索查询这些材料整理给 NotebookLM，再生成 Podcast、PPT、MindMap、Quiz。

GitHub API 现在显示它 3513 stars、362 forks，MIT License。今天 trending 抓到日增 +561。

## 它解决的不是总结，是再生产

公众号作者最常见的浪费，是一篇深度文章写完只发一次。

最多再截几段放小红书，剪一版短视频口播脚本，然后就躺在历史消息里。

但 NotebookLM 本来就能把材料变成音频、问答、学习指南。卡点是中文内容散在公众号、PDF、飞书文档、网页和 Markdown 里。

乔木这个 Skill 做的事，就是先把这些入口收束起来，再交给 NotebookLM 生产。

它更像一个内容预处理工。

你给它原材料，它负责整理成 NotebookLM 能吃的输入；NotebookLM 负责变成播客、课件、思维导图和测试题。

## 三类人可以马上试

第一类，公众号作者。

过去半年写过 20 篇 AI 工具测评的人，可以把旧文整理成一个「AI 工具入门播客合集」。同一批材料再生成 PPT，就能拿去做分享。

第二类，课程运营。

老师讲完课，视频、讲义、答疑记录都在。过去要助教花几小时整理复习题和课程大纲。现在至少能把多源导入这一步自动化。

第三类，企业内部培训。

公司里一堆 PDF 制度、产品手册、销售话术。新人不愿意读，老人也懒得维护。转成 NotebookLM 问答和测验，资料库至少能被问起来。

## 为什么它会涨

因为这不是「又一个写作助手」。

真正有内容资产的人，手里已经有一堆旧文章、旧课件、旧文档。问题不是从 0 写 1，而是把已经写过的内容继续变成播客、课件、题库、导图。

Claude Skill 的好处，是把流程封起来。你不用记一堆命令，只要把固定流程交给 Skill。

今天是 NotebookLM，明天也可以是小红书排版、播客 shownotes、课程题库、飞书知识库清洗。

## 建议怎么试

不要一上来把全部内容库丢进去。

先拿 3 组材料小测，

1. 3 篇自己的公众号旧文，看能不能变成一个 NotebookLM 项目
2. 1 个 PDF 报告，生成播客和测验，重点看事实有没有跑偏
3. 一批 Markdown 笔记，看 MindMap 能不能抓住结构

如果你是内容团队负责人，我建议把它放在「文章发布后 24 小时」的流程里。

主文发完，马上生成播客、PPT、问答和小红书素材。同一篇文章不再只贡献一次流量。
