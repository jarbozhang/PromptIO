# K-Dense 135 个科研 Skill 开源 Claude Code 和 Codex 可以变科研助理

今天 GitHub 上一个很适合收藏的项目是 K-Dense-AI/scientific-agent-skills。

它开源了 135 个科研和分析 Skill，支持 Cursor、Claude Code、Codex。覆盖生物信息、药物发现、临床研究、材料科学、金融数据、科研写作，还有一批常用包和数据库流程。

我觉得重点不是“135 个提示词”。重点是 Skill 比普通 prompt 更像工作台。

普通 prompt 经常只是愿望，比如“帮我读论文”“帮我分析数据”。Skill 会把输入、步骤、工具、输出格式和检查项写清楚。科研任务非常适合这种拆法，因为很多动作本来就有流程，查库、读文献、整理证据、跑包、写报告、查引用。

如果你要试，我建议先做 3 个低风险任务。

1. 论文速读，输出问题、方法、数据、结论和局限。
2. 数据库检索计划，列出关键词和记录方式。
3. 分析脚本审阅，检查输入输出、随机种子、缺失值和图表。

不要让 AI 直接替你下科研结论。更稳的用法是让它做结构化助理，帮你把重复工作标准化。

K-Dense 的信号很清楚，Claude Code 和 Codex 不只是在写代码，它们开始变成桌面科研助手。
