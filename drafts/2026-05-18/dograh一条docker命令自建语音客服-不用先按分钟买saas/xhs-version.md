# Dograh 一条 Docker 命令自建语音客服 不用先按分钟买 SaaS

语音 AI 最容易被 demo 骗到。

点一下，AI 接电话，声音自然，好像马上能替代客服。但真放进业务，问题会变成延迟、打断、转人工、话术控制、数据落表和成本。

Dograh 这个开源项目值得看，因为它可以用一条 Docker 命令先跑起来。启动后打开本地页面，就能先做 Web Call 测试，不用一上来买按分钟计费的语音 SaaS。

我觉得它最适合三类场景。

1. 售前线索筛选，先收集姓名、需求、预算和时间。
2. 高频客服 FAQ，比如预约、退换货、订单状态、营业时间。
3. 回访和问卷，按固定问题收集反馈并写入表格。

语音 agent 的关键不是“回答一句话”，而是用户愿不愿意继续聊超过 30 秒。测试时要看三项数据，首句响应时间、被打断后能不能恢复、答不上来能不能转真人。

我的建议是先做一个很小的试点。准备 20 个真实问题，让同事模拟客户打 30 通电话，记录完成率、平均时长和尴尬点。

Dograh 不等于零成本，但它把验证门槛降下来了。中小团队可以先把流程跑通，再决定要不要接真实电话和生产流量。

---

本文不涉及境外软件访问教程，所有实操步骤均基于国内可合法访问的服务。
