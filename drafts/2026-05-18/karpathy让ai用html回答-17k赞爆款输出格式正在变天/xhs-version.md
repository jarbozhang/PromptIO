## 我亲测的瞬间

昨晚我问了一个每周都要问几遍的问题：

> "帮我对比 vLLM、SGLang、TensorRT-LLM 三个推理框架在 A100 上的取舍"

末尾加上那句魔法咒语。

结果它没像往常一样给我一坨 markdown 标题➕bullet。

而是吐了一段完整 HTML：
- 三列卡片布局
- 每列顶部框架名
- 下面四行小标签（吞吐 / 延迟 / 易用性 / 坑点）

我存成 .html，浏览器双击打开 —— **一张可以直接截屏发群的对比图** 🎯

## 这招最适合三类问题

✅ **解释概念**：X 是什么、X 和 Y 区别在哪 → 卡片+对比块，信息密度暴涨

✅ **做汇总 dashboard**：比如"这周 AI 圈发生了什么" → 仪表盘式输出，我现在的周报模板就是这样

✅ **可视化清单**：比如"做 RAG 选型该问自己的 10 个问题" → 自动分组、加序号、配视觉权重

❌ 不适合：写代码、纯创意文字、严格结构化数据 → markdown 或 json 更好

## Karpathy 的更大判断

技巧只是表象，他真正想说的是 👇

人脑约 1/3 皮层在处理视觉，是"10 车道的信息高速公路"。

所以 LLM 输出会顺着视觉带宽往上走：

1️⃣ raw text → 硬读累
2️⃣ markdown → 加粗+表格，眼睛轻松点（当前默认）
3️⃣ **HTML → 有布局有交互，正在成为新默认**
... 
n) 交互式生成视频/模拟 → 终局形态

我们现在用的"文本框+回车+滚动列表"，可能真的快到头了。

## 评论区有人捅破窗户纸

913 条回复里点赞最高那条说：

> "这就是 Claude 的 Artifacts 那么好用的原因，它把 HTML 渲染做成了产品内置功能"

确实。HTML 输出现在还只是"小技巧"，是因为大多数对话界面**默认不渲染 HTML**。

你得自己复制、存文件、开浏览器 —— 这个摩擦把 90% 用户挡在门外。

## 我的判断 💡

**这条推被严重低估了。** 它表面是 prompt 技巧，骨子里是 LLM 产品交互的下一站路标。

但我得泼一桶冷水 🧊：

- HTML 输出只对**信息密集型查询**有效，闲聊别用
- 国产 LLM 里，Kimi / 豆包 / 元宝 / DeepSeek 官方 app **还得手动复制出来开浏览器**，体验有断层
- 想要丝滑体验，目前最贴近的是 Claude Artifacts 那种原生 view

国产 AI 产品如果想追这波，**把 HTML 渲染做成下一个版本的标配** 就行了，没有技术壁垒，只看产品决心。

## 你今晚可以这样玩 🎮

**第一步**：打开你手边的 LLM（Kimi / 豆包 / 元宝 / DeepSeek 都行）

**第二步**：复制一个你这周问过的问题，末尾加 `structure your response as HTML`

**第三步**：把输出存成 .html 文件，浏览器双击打开 ✨

**进阶玩法**：试试让它输出"HTML slides"，每张 slide 一个 section 标签，加点 CSS，直接当汇报材料。
