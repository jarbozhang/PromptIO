# 飞书 CLI 过万星 200 个命令让 Agent 接进办公系统

国内办公 agent 真正的入口，可能不是聊天机器人，而是 CLI。

官方 larksuite/cli 现在已经过万星。补充源里写到，它覆盖 17 个业务域、200 多个命令、24 个 Agent Skills，可以用 npx @larksuite/cli@latest install 安装。

为什么重要。

企业数据不在“AI 助手欢迎页”里，而在 Docs、Sheets、Base、Calendar、Mail、Drive 和审批流里。agent 如果只能回答问题，价值有限。它要能读表、改任务、写文档、查日历、发消息，才算接进真实工作。

我最建议先试 3 个流程。

1. 会议后自动整理，抽行动项，写任务表，按负责人分发。
2. 销售线索清洗，从表格读线索，补标签，生成跟进建议。
3. 知识库维护，扫描过期文档、重复标题和缺 owner 页面。

这些任务输入清楚、输出可检查、风险可控，适合作为第一批试点。

但权限一定要小心。谁能让 agent 读客户表，谁能让 agent 发全员消息，谁能修改关键数据，都要有授权和审计。不要一上来给超级管理员权限。

飞书 CLI 的信号是，办公 AI 正在从“会总结”走向“能执行”。

---

本文不涉及境外软件访问教程，所有实操步骤均基于国内可合法访问的服务。
