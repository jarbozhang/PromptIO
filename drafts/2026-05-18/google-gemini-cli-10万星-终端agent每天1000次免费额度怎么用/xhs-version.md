# Google Gemini CLI 10 万星 终端 agent 每天 1000 次免费额度怎么用

Google Gemini CLI 已经 10 万多 star 了。

README 里最吸引人的点是免费档，个人 Google 账号每天 1000 次请求，60 requests/min，支持 Gemini 3 和 1M context，还能用 npx、npm 或 brew 安装。

AI 编程工具很多，但 Gemini CLI 的优势是便宜、顺手、在终端里就能用。

我不会把它当唯一主力。我更建议这样用。

1. 读仓库，总结目录结构、入口文件、测试命令和主要模块。
2. 写小脚本，处理日志、文件批量改名、Markdown 格式整理。
3. 改文档，补 README、安装步骤、CLI 帮助信息。
4. 做二次检查，看 diff 里的异常处理、边界条件和测试缺口。

last30days 里社区反馈很混合。有人觉得它在 Antigravity 终端里很好用，也有人抱怨稳定性和响应速度。所以更稳的位置是外围助手，而不是把整个项目交给它。

每天 1000 次额度可以这样分配。上午读项目，下午做批量小任务，晚上总结日志和测试失败。不要拿它漫无目的聊天。

高风险任务不要交给它，比如数据库迁移、权限、支付、生产配置和密钥文件。agent 说通过也不算通过，最后还是要跑项目测试。

---

本文不涉及境外软件访问教程，所有实操步骤均基于国内可合法访问的服务。
