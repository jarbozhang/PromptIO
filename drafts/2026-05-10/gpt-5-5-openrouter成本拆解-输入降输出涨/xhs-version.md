# GPT-5.5 涨价不是涨一倍那么简单，OpenRouter 把账单拆成 6 段给我看

5 月 8 日 OpenRouter 发了一份 GPT-5.5 成本拆解，HN 投票 209 点 68 评论。我看完最大的感受是，账面价格翻倍这件事，跟你实际付的账单是两回事。

## 账面翻倍，账单没翻倍

GPT-5.5 输入从 $2.50/M 涨到 $5.00/M，输出从 $15/M 涨到 $30/M，账面价格翻一倍。

OpenRouter 把自家近 30 天的真实调用按 prompt 长度切成 6 段，得出来的实际涨幅是这样。

- 小于 2K，单次成本上涨 92%，输出长度多了 7%
- 2K-10K，成本涨 69%，输出长度增加 52%
- 10K-25K，成本涨 51%，输出反而短了 32%
- 25K-50K，成本涨 62%，输出短 19%
- 50K-128K，成本涨 49%，输出短 28%
- 128K 以上，成本涨 85%，输出短 34%

GPT-5.5 在长 prompt 场景下"想得更短"，输出 token 自动收敛，把输入端的涨价抵消了一部分。短 prompt 场景没有这个机制，2K 以下还多吐 7%，单次成本就涨得最猛。

换算到具体场景，客服 chatbot 单轮 1-2K，命中 92% 涨幅那一档。RAG 塞 30K context，落在 62% 那一档。代码 agent 把整个 repo 塞进去，落在 49% 那一档。

短对话最贵，长上下文反而省。

## 国产模型对照位

把 $5/M 输入 + $30/M 输出放进 OpenRouter 模型库一起看。

- GPT-5.5：输入 $5.00/M，输出 $30.00/M
- DeepSeek V4 Pro：输入 $0.40/M，输出 $1.50/M
- Kimi K2.6：输入 $0.55/M，输出 $2.20/M
- 蚂蚁 Ling-2.6 1T：输入 $0.30/M，输出 $1.20/M
- Qwen3.6 Max Preview：输入 $1.20/M，输出 $4.50/M

按客服场景算一笔，每天 10 万次调用，每次 1.5K 输入 + 800 输出。GPT-5.5 是每天 $3150，DeepSeek V4 Pro 是 $180，Ling-2.6 是 $141。价差 17-22 倍。

## 缓存命中率才是真省钱

GPT-5.5 真正的成本游戏在 prompt caching。重复 prefix 走缓存通道打 1 折，$5/M 输入降到 $0.50/M。

如果是"长 system prompt + 短用户输入"形态，且 system prompt 多轮稳定不变，账单按 1 折算。每次拼新 RAG context、顺序还不一样，缓存命不中，全额 $5/M。

缓存命中 90% 的工作负载，GPT-5.5 实际平均输入价是 $0.95/M，已经接近 Qwen3.6 Max 的 $1.20/M。

HN 上 68 条评论的争论焦点不在涨价合不合理，在 prompt 设计得对不对。

## 我的切换决策表

国内开发者通过 OpenRouter 调 GPT-5.5 是合规路径，关键是用在合适的工作负载上。

适合走 GPT-5.5 的：长 system prompt + 高频短输入且缓存命中能稳定在 80% 以上、需要 1M 长上下文且对推理质量极敏感的代码 agent、只有 GPT-5.5 能跑通的多模态 pipeline。

应该切国产的：短对话客服 chatbot 且 prompt 1-3K 无法缓存优化，DeepSeek V4 Pro 或 Ling-2.6 成本只有 GPT-5.5 的 5%-7%。批量内容生成例如商品文案、SEO、知识抽取，Kimi K2.6 中文输出更贴本地审美，单价是 GPT-5.5 输出的 7%。RAG 调用每次 context 都不同的，吃不到缓存红利。

混合架构是当下最经济姿态，难任务路由到 GPT-5.5，简单任务路由到 DeepSeek V4 Flash 或 Ling-2.6 Flash。OpenRouter 的 model routing API 现在支持按 prompt 长度自动分发，配合临界点表能把账单砍到 1/3 以下。

## 我的判断

这次定价调整看起来是涨价，实际是把"愿意为缓存做工程优化的用户"和"裸调 API 的用户"分成了两档。前者付 $0.95/M，后者付 $5/M，差距 5 倍。

长 prompt 段涨幅压到 49%，几乎是在告诉你做了功课就感受不到涨价。

对国内开发者，结论简单。月活够大、prompt 形状稳定，值得为 GPT-5.5 加缓存优化做一次工程改造。还在 PoC 阶段、prompt 频繁调整的，别折腾，国产模型当下的性价比窗口足够大，等产品形态稳定再回头评估。

国内用户可以通过 OpenRouter 直接访问 GPT-5.5，本文不展开账号注册流程。
