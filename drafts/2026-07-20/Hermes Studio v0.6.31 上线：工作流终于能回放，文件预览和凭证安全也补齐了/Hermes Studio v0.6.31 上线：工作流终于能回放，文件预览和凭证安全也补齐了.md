# Hermes Studio v0.6.31 上线：工作流终于能回放，文件预览和凭证安全也补齐了

如果你正在用 Hermes Studio 搭工作流，这次更新最值得看的并不是功能数量，而是几处长期影响交付的障碍终于被处理了。

工作流现在能保存完整执行记录并回放历史路径，文件不用离开工作区就能预览，Provider 凭证也有了脱敏、连接测试和审计记录。对个人开发者来说，这些改动减少排错成本。对团队来说，它们让 Agent 流程更接近可以复核、可以交接的工程系统。

我会把 v0.6.31 看成一次补基础设施的版本。它没有只追求让 Agent 多做几个动作，而是在回答一个更现实的问题，流程出错以后，人能不能看懂、追溯并安全地修正。

## 把工作流从能运行推进到能解释

过去搭可视化工作流，一个常见障碍是条件表达能力不够。简单分支还能处理，遇到嵌套字段、多个状态组合或工具返回的结构化结果，判断逻辑就容易变得零散。

v0.6.31 为 Workflow 加入了结构化 JSON 条件。它适合处理工具输出、表单数据和 Agent 中间状态，不必把复杂对象强行压成一段文本再判断。

更关键的变化是完整执行记录与历史路径回放。一次流程走过哪些节点、在哪个条件发生分支、最终沿哪条路径结束，现在有了可追踪入口。

我认为，回放比新增一个节点类型更重要。Agent 工作流真正难维护的地方，往往不是第一次跑通，而是同一份流程面对不同输入时为何走出了不同结果。没有执行路径，排错依赖猜测。有了历史路径，问题才能落到具体节点和具体条件。

## 让生成文件留在同一个检查现场

Agent 能生成文件，不等于文件已经可以交付。过去如果流程产出 PDF、表格或演示文稿，使用者经常需要下载，再调用另一个应用检查，确认无误后才能继续。

新版本加入了更完整的文件预览能力，覆盖 HTML、PDF、DOCX、PPTX、XLSX、CSV、图片、Markdown 和源码文件。

这项更新适合三类任务。内容流程可以直接核对文档结构，数据流程可以检查 CSV 和表格结果，开发流程可以查看 Markdown 与源码文件。预览不会替代专业编辑器，但能把一次快速验收留在当前工作区，减少来回切换。

文件预览和路径回放放在同一个版本里，也透露出 Hermes Studio 对 Agent 应用的判断。流程完成并不等于任务完成，结果必须经过人的检查，过程也必须能够被还原。

## 把 Provider 配置变成可审计操作

Provider 编辑涉及凭证，过去只要界面展示、连接验证或修改记录处理得不完整，就可能给团队协作留下风险。

v0.6.31 新增了凭证脱敏、连接测试和审计记录。脱敏减少凭证在界面中直接暴露的机会，连接测试让配置问题更早被发现，审计记录则为变更追踪提供依据。

我的判断很直接。只要 Hermes Studio 开始被多人使用，这组安全能力的优先级就不低于工作流功能。团队需要知道配置是否有效，也需要知道配置何时发生过变化，但不需要让每个参与者看到完整凭证。

## 验证跨回合任务是否真的回来了

这次更新还补强了对话和委派任务。单聊、群聊现在支持消息引用，Delegate Task 在跨回合及应用重启后仍能可靠返回。

消息引用解决的是上下文指向问题。群聊里同时存在多个问题时，引用能明确当前回答对应哪条消息。跨回合返回则关系到长任务的可信度，尤其是需要等待工具执行、文件处理或子任务完成的场景。

版本说明还提到历史会话、Workspace Diff、模型切换和 Reasoning Effort 的体验优化。桌面端统一了暗色视觉，更新流程得到完善，并修复了 macOS 麦克风权限等问题。此外，新版本支持自定义 runtime 目录，给运行环境和文件位置的管理留下了更多空间。

## 升级后优先验证三个真实场景

这不是一份需要逐项打勾的功能清单。升级后，我更建议拿三个真实任务判断改动是否解决了你的障碍。

**复杂分支场景**

给工作流输入一份包含嵌套字段的 JSON 数据，让它根据两个以上条件选择不同路径。运行后检查执行记录能否说明分支依据，并尝试回放历史路径。

**多格式交付场景**

让同一流程产出一份文档、一份表格和一张图片，在工作区内分别预览。重点不是文件能否打开，而是使用者能否快速发现结构、字段或排版问题。

**凭证与长任务场景**

编辑一个 Provider 配置，观察凭证展示、连接测试和审计记录。随后启动 Delegate Task，跨一个对话回合继续操作，并在重启后确认结果是否能够返回。

适合尽快验证这版的人，是已经在维护多分支 Workflow、需要检查多种文件产物，或开始让多人共享 Provider 配置的使用者。如果当前只运行很短的单轮任务，这次升级带来的变化可能没有那么显眼。

但只要流程开始变长，问题就会从能不能跑转向出了问题能不能追。v0.6.31 最有价值的地方，正是让执行路径、交付文件和敏感配置逐渐进入同一套可验证链路。
