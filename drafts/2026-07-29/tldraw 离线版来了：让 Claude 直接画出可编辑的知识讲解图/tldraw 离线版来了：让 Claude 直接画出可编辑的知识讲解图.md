# tldraw 离线版来了：让 Claude 直接画出可编辑的知识讲解图

如果你经常制作课程配图、技术讲解图或手绘演示，最费时间的往往不是想内容，而是摆放元素、连接箭头，再反复调整遮挡和顺序。

tldraw 离线版 App 加入 Agent Skill 后，Claude 或 Codex 可以直接参与画布创作。它们负责生成图形、文字和连线，人仍然可以在画布中移动、删除和修改每个元素。

这让知识图不再是一次性图片。以勾股定理为例，可以把任务拆成内容生成、脚本检查和人工修订三段，最终留下的是一张可继续编辑的讲解画布。

## 从一道勾股定理开始画

场景很具体，一位内容创作者要做一张勾股定理讲解图。画面需要有直角三角形、三条边的标记、三个正方形，以及说明面积关系的文字和连线。

如果直接让图像模型生成成品，构图可能很漂亮，但边长标签、公式位置或箭头方向一旦出错，修改通常会牵动整张图。可编辑画布走的是另一条路径，Claude 或 Codex 先把内容转换成独立元素，再交给 tldraw 呈现。

这里的关键交付物不是一张图，而是一组仍能操作的对象。三角形可以移动，公式可以改写，箭头可以重新连接，讲解顺序也能继续调整。

## 让 Claude 进入画布流程

原帖给出的安装入口是 tldraw App 内的 `Develop → Install Agent Skills`。安装 Skill 后，可以把绘图任务交给 Claude 或 Codex，但提示词需要描述教学目标，而不只是说一句“画勾股定理”。

一个更清楚的任务可以包含这些约束。

- 画出一个直角三角形，并明确直角位置
- 用 a、b、c 标记三条边，c 对应斜边
- 分别在三条边外侧放置正方形
- 用连线表现两个小正方形面积之和与大正方形的关系
- 按定义、图形关系、公式结论安排阅读顺序
- 所有元素保持独立，方便后续移动和改写

Agent Skill 在这一步承担的是画布操作层。它把语言指令转成元素和连线，让创作者不用从空白画布逐个拖拽，但内容是否准确、构图是否清楚，仍然需要后续检查。

## 用脚本拦住三类返工

原帖提到 tldraw 支持脚本，讨论中进一步提出了一条适合知识讲解图的路线，让 Skill 生成元素和连线，再用脚本检查遮挡、越界和阅读顺序。

遮挡检查关注公式、标签和图形是否互相覆盖。越界检查负责发现落在画布可视范围之外的对象。阅读顺序检查则要确认视线能从题目条件自然走到图形关系，再落到公式结论。

这三项检查不能代替教学判断，却能提前找出机械错误。对需要多轮修改的内容而言，脚本的价值也不是替人审美，而是减少每次改稿都要重新寻找同一类问题。

## 在可编辑画布里完成最后一轮

脚本通过后，创作者回到画布做人工修订。可能需要拉开两个标签的距离，缩短一条跨越图形的箭头，或者把面积关系拆成两个连续画面。

一张可交付的勾股定理讲解图，可以用下面这组标准验收。

- 不看正文也能识别直角和斜边
- a、b、c 与对应边没有歧义
- 三个正方形的归属清楚
- 连线不会穿过关键文字
- 阅读路径能自然到达 `a² + b² = c²`
- 每个对象仍可单独编辑，没有被压成一张静态图片

讨论中还有人提出把绘制过程录成手绘讲解视频。这个方向值得继续验证，因为画布中的对象和出现顺序已经被保留下来，后续可以围绕逐步呈现设计演示，而不是直接播放一张完成图。

## 把经验带到下一张知识图

这个案例真正可复用的部分，是把生成与交付分开。Claude 或 Codex 负责铺出第一版结构，脚本负责检查机械问题，人负责教学表达和视觉取舍。

我的判断是，可编辑性比一次生成得足够漂亮更重要。知识内容经常需要改公式、换例子、调节奏，只要交付物还是画布对象，修改就不会变成整图重做。

可以先选一道只有一个核心关系的题目，按“元素生成、脚本检查、人工修订”跑完一轮。完成后保留画布文件和检查规则，再把同一套流程迁移到流程图、概念关系图或课程讲义。
