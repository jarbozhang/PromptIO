# 一张 4090 跑了一晚 47 首 AI 歌，BGM 自由了

昨晚我把家里那台 4090 开了一整晚，跑出 47 首歌，0 元，不限量，电费除外

跑的是刚冲上 GitHub Trending 的 fspecii/ace-step-ui，单日 +237 星 ⭐ 套在 ACE-Step 1.5 模型上面跑，3.5B 参数，Apache 2.0 协议，benchmark 在 Suno v4.5 和 v5 之间

之前我做 B 站二创，想要一段"国风电子"过渡，订阅版连续 6 次跑偏，Credits 烧完那种感觉真的难受 😩 所以我决定自己跑本地

## 🎹 硬件门槛

- 4GB VRAM 也能跑（不开 Thinking Mode）
- 8GB VRAM 起步舒服
- 12GB 以上可以开 LLM 增强

实测速度（一首 1 分钟的歌）

- 4090，27 步 1.74 秒，60 步 3.84 秒
- 3090，27 步 4.7 秒
- MacBook M2 Max，27 步 26 秒，60 步 58 秒

我自己 4090 跑一首 3 分半的完整歌（带人声、伴奏、歌词）60 步只要 14 秒 ⚡

家里有 3060 12G 或更高显卡，本地路线就成立

## 🚀 最小启动命令

```
cd /path/to/ACE-Step-1.5
uv run acestep --port 8001 --enable-api --backend pt
```

Windows 有便携包，下载解压双击 .bat 即可。模型权重从 Hugging Face 自动拉，3.5B 大概 7-8 GB

我从 git clone 到出第一首歌大概 25 分钟，绝大部分时间在下模型

## 🎬 实际能干啥

**B 站背景音乐** prompt 写"lo-fi hip hop, jazz piano, rainy night, 90 BPM"，60 步出来直接铺底，没人听得出来不是商用音乐库买的

**抖音原创音** 这是最值的 💰 抖音对原创音有流量加成，但你不可能每条视频自己做曲。我跑了一个 15 秒电子 hook，无人声，循环上传，系统判定原创音通过。一晚跑 30 段不同风格不重样

**小红书 vlog 配乐** 热门曲版权风险高，很容易被静音。本地生成的不存在版权问题，模型 Apache 2.0 商用没问题。我做了几段"晨间咖啡馆"风格的轻爵士，3 分钟一首，配 vlog 刚好

模型支持 19 种语言，中文也在前 10 名。我写过一首"夜班司机，城市霓虹"，人声咬字大概 7 分，副歌挺像样

## 🤔 和 Suno 各走各的路

讲清楚，本地版本和 Suno 走的不是同一条路

- Suno v5 闭源、托管、做了产品化打磨（Stem 分轨、风格混合、续写），流行人声的颗粒度更稳
- ACE-Step 1.5 + ace-step-ui 优势是另一面，不限量、不联网、可商用、可改、可训 LoRA

如果你月用十几次，Suno 订阅更轻松；但只要你做内容做得勤，B 站每周三条、抖音每天一条、小红书 vlog 系列号，本地路一个月就回本一张二手 3060 的钱

而且本地这条路没有版权水印、没有公司服务器留底、没有"账号被封怎么办"
