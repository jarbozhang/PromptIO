# 我用一张 4090 跑了一晚 ACE-Step UI，做 B 站 BGM 比 Suno 订阅划算太多

昨晚我把家里那台带 4090 的机器开了一晚，跑出来 47 首歌，一分钱没花，不限量，电费除外。

跑的是 5 月 5 日刚冲上 GitHub Trending 的 fspecii/ace-step-ui，单日 +237 星。它本身不是模型，是一个 Spotify 风格的前端，套在 ACE-Step 1.5 上面跑。模型是 1 月份 ace-step 团队开源的，3.5B 参数，Apache 2.0，benchmark 在 Suno v4.5 和 v5 之间。

之前我一直懒得碰本地音乐生成。Suno 月费 10 美刀，我做 B 站视频 BGM 一个月也就用十几次，凑合够。但上周做一条二创视频被卡了，想要一段"国风电子"的过渡，Suno 给我连续生成 6 次都跑偏，Credits 烧完那种感觉很难受，你明明知道再试两次就能命中，但要等下个月。

那我就想，本地路线现在到底跑得动吗。

## 硬件门槛我替你踩过了

ACE-Step 模型本体要求 8GB VRAM 起步（5 月初那次更新优化过），上限不高。ace-step-ui 这个前端最低 4GB VRAM 也能跑（不开 Thinking Mode），12GB 以上能开 LLM 增强模式。

模型官方给的速度表很狠，

- 4090 生成 1 分钟音乐，27 步只要 1.74 秒，60 步 3.84 秒
- A100 27 步 2.2 秒
- 3090 27 步 4.7 秒
- MacBook M2 Max 27 步 26.43 秒，60 步 58 秒

我自己跑下来 4090 大致对得上。一首 3 分半的完整歌（带人声、伴奏、歌词），27 步 7 秒出，60 步 14 秒出。M2 Max 那台同事的我也试了一下，60 步差不多 3 分钟一首，比 Suno 订阅排队还快一点点。

也就是说，**家里有一张 3060 12G 或更高显卡，本地路线就成立**。再低一点 8G 卡 27 步也能跑，只是不要开 LLM 增强。

## 最小启动命令

整个安装路径在 Linux/Mac 上是这样的，

```
cd /path/to/ACE-Step-1.5
uv run acestep --port 8001 --enable-api --backend pt --server-name 127.0.0.1
```

Windows 有便携包，下载解压后双击 `.bat`。模型权重首次启动会自动从 Hugging Face 拉，3.5B 大概 7-8 GB。前端那边 `npm install && npm run dev` 起一个端口，连后端 8001 就能用了。

我整个流程从 git clone 到出第一首歌，用了大概 25 分钟，绝大部分时间是模型权重下载。

## 实际能做什么

我列下我跑出来的几个用得上的场景。

**B 站背景音乐**。直接写 prompt "lo-fi hip hop, jazz piano, rainy night, 90 BPM"，给一段歌词或者留空让模型自己写，60 步出来的质量我直接拿来给一条剪辑视频铺底，没人听得出来不是商用音乐库买的。

**抖音原创音**。这是最值的。抖音对原创音有流量加成，但你不可能每条视频自己做曲。我跑了一个 15 秒电子 hook，勾选"无人声"，循环出来直接传上去，系统判定原创音通过。一晚跑 30 段不同风格不重样。

**小红书 vlog 配乐**。小红书的 BGM 版权风险其实挺高的，热门曲很容易被静音。本地生成的不存在版权问题，模型 Apache 2.0 商用没问题。我做了几段"晨间咖啡馆"风格的轻爵士，3 分钟一首，配 vlog 刚好。

模型支持 19 种语言，前 10 种表现最好，包含中文。我试着写了首中文民谣 prompt"夜班司机，城市霓虹"，人声咬字大约能打 7 分，副歌挺像样。比一年前我试过的 MusicGen 那种"中文糊成一团"强了一个量级。

## 社区在跑什么

Reddit 上 r/aicuriosity 有人写过一篇标题挺夸张的帖子，"开源 AI 音乐生成首次冲到商用品质，MacBook Air 都跑得动"。这个有点夸大，MacBook Air 跑 60 步要等很久，但 M 系 Pro/Max 是真的能跑。

更有意思的是 r/AMDGPU 那个帖子，有人在 RX 7900 XT 上把 ROCm 7.2 + ACE-Step 跑通了，patch 了 4 个库，还训了一个 8 首歌的 LoRA。这条线说明 N 卡之外也能玩，但不要自己当第一个吃螃蟹的人，等 issue 区稳定。

**LoRA 训练**这个事 fspecii 的 README 没明确写，但模型仓库支持，已经有人跑通。意思是你可以喂自己几十首特定风格的歌进去，让模型学你的"声纹"或"曲风"，这对独立音乐人是个很大的口子。

## 跟 Suno 不是同一种东西

我得讲清楚，本地版本跟 Suno 走的不是一条路。

Suno 现在 v5，闭源、托管、模型规模据传更大，单从某些品类的生成质量看，确实有差距，尤其是流行人声的颗粒度和混音平衡。Suno 还做了很多产品化打磨，比如 Stem 分轨、风格混合、续写。

ACE-Step 1.5 + ace-step-ui 的优势是另一面，**不限量、不联网、可商用、可改、可训 LoRA**。如果你是月用十几次的休闲党，Suno 订阅可能更轻松；但只要你做内容做得勤一点，B 站每周三条、抖音每天一条、小红书 vlog 系列号，本地这条路一个月就回本一张二手 3060 的钱。

而且本地这条路有个隐性价值，你做的歌没有版权水印、没有公司服务器留底、没有"账号被封怎么办"。

## 行动建议

我今天写完这篇就把那 47 首跑出来的歌挑了 12 首存进剪映素材库，后面每个视频随手就能用。

如果你是做内容的，这周就可以做的事，

1. 检查一下显卡 VRAM，8GB 起步够用，12GB 舒服
2. clone fspecii/ace-step-ui，跟着 README 起服务
3. 跑 5-10 个不同风格的 prompt，挑能用的进素材库
4. 跑一个晚上你就有了一个**永远不会耗尽的免版权音乐库**

我的判断是，独立创作者那批人接下来一年会有一批跳出 Suno 订阅模型的。不是因为 Suno 不好，是因为本地这条线第一次做到了"显卡够 + 一个好看的前端"就能用，门槛掉到了普通玩家可以承受的位置。
