# 600 亿美元，马斯克把 Cursor 买回家，这不是 AI 编程的胜利

SpaceX 昨天宣布，要么花 600 亿美元把 Cursor 收了，要么付 100 亿违约金。

600 亿是 SpaceX 的报价，100 亿是 SpaceX 如果反悔要给 Cursor 的分手费。

一个做火箭的公司，为了一个做 AI 编程 IDE 的初创公司，愿意付 100 亿美元的违约金。这个数字本身就够离谱了。

我第一反应是，Cursor 估值怎么突然跳到 600 亿。第二反应是，SpaceX 来凑什么热闹。看了一圈信息才反应过来，这根本不是一笔"买工具"的交易，这是马斯克在给他的 SpaceX/xAI/X 三位一体讲 IPO 故事。

## 先把这事儿讲清楚

The Verge 的原话，SpaceX 有一个 IPO 在路上，而 IPO 这家公司是 SpaceX、xAI、X 三家合并后的"combo platter"。马斯克要在上市前把资产攒厚。

xAI 手里有 Grok，但 Grok 在编程这件事上打不过 Claude 和 GPT。这不是我说的，是 TechCrunch 自己写的，原文是"Neither Cursor nor xAI has proprietary models that can match the leading offerings from Anthropic and OpenAI"。

翻译一下，Cursor 再牛，它也是 Anthropic 和 OpenAI 的套壳。xAI 自家模型又不够强。两个都有短板的公司凑一起，短板并没有消失，只是变成了一家公司的短板。

那马斯克图什么。

图的是 IPO 的叙事里多一个"AI 编程平台"的标签。上市路演的时候不能只说"我们有火箭、有社交网络、有一个聊天机器人"，还得说"我们有全球最火的 AI IDE"。

Cursor 作价 600 亿，xAI 前阵子的估值是几百亿，SpaceX 是几千亿。把这三个数字堆在一起，上市市值的锚点就立起来了。

这笔交易的结构才是最精妙的。600 亿收购或者 100 亿违约金，意思是"我不一定真买，但我锁定了你"。Cursor 未来一年不能卖给别人，也不能拒绝 SpaceX 给它的任何指令，不然 600 亿不要了，你们自己随便折腾。

100 亿违约金是留给 Cursor 的最坏情况保险。

## 中国开发者要慌吗

坦率讲，短期不用慌。

Cursor 现在的体验之所以能打，是因为它背后挂的是 Claude Sonnet 和 GPT。中国用户用 Cursor，用的其实是 Anthropic 和 OpenAI 的模型能力。国内用户绕一下网络就能用得很爽。

但中期我是真的觉得有点担心。

如果 SpaceX 真把 Cursor 收了，xAI 的商业诉求会立刻变成"让 Cursor 用户迁移到 Grok"。这是必然的，不然 600 亿花的没意义。你想想看，马斯克掏 600 亿，最后你在 Cursor 里还是用着 Anthropic 的模型，Anthropic 收走大部分利润，这故事讲不通。

所以模型默认值一定会换，而且会用尽各种手段让你换，免费额度、速率限制、新功能独占。

到那时候问题就来了。Grok 的编程能力，在我自己的粗浅测试里，离 Claude Sonnet 还差一截。不是差一点，是差一截。让一个用惯了 Claude 在 Cursor 里跑的人切到 Grok，体感就是"昨天还能一把写好，今天要来回改五轮"。

中国用户还要多一层麻烦，Grok 在国内访问、计费、账号都是另一套体系。原来一个 OpenRouter 就能覆盖的事情，未来可能要再配一套 xAI 的 key。

## 这笔买卖的另一面

The Verge 在同一篇里还顺手扔了两个细节。

一个是 Sergey Brin 亲自下场命令 Google 组了一支"strike team"，专门让 Google 的 agentic AI 追上来。

另一个是去年 Sam Altman 在 OpenAI 内部喊了"code red"，然后把 Sora 先按住，集中火力做 ChatGPT 超级应用和 Codex。

把这三条线放在一起你就看懂这盘棋了。

Google 创始人回归一线敲桌子。OpenAI CEO 喊红色警报压住自家明星产品。马斯克直接花 600 亿买下赛道里最红的 IDE。

三个巨头都在用最极端的方式回应同一件事，AI 编程是下一轮入口级别的战场，谁守不住谁出局。

这就是为什么我说 600 亿收购 Cursor 这事，报道里都在聊"AI 编程赢了"，我觉得不是。

赢的不是 AI 编程，赢的是三个互相威慑的巨头之间的军备竞赛。Cursor 这种独立公司，在这种级别的资金面前连议价空间都没有，要么卖、要么被边缘化。

我的判断是，独立 AI 编程工具这条路基本走到头了。不是因为产品不好，是因为你躲不开模型大厂。你做得越好，你越是在替大厂打工，最后要么被收、要么被替代。

Windsurf 之前被 OpenAI 盯上就是前奏。Cursor 今天是 SpaceX，明天可能还有别的。

## 社区怎么看

我刷了一圈 X 和 HN 的初步反应。

最集中的吐槽是估值。Cursor 去年融资的时候估值大概在百亿出头，一年不到翻到 600 亿，很多人觉得这是马斯克式"先报一个耸人听闻的数字"。

第二类声音是担心模型中立性。Cursor 之前的卖点之一就是"你可以选 Claude、GPT、Gemini"，是一个不绑定模型的 IDE。被 xAI 收了之后，这个中立性就没了。

也有人替 Cursor 团队高兴。之前 Cursor 估值一路猛涨但收入的增长跟不上估值的增长，团队套现压力很大。600 亿现金，或者至少 100 亿违约金兜底，对创始人来说是稳稳的胜利。

## 所以现在该做什么

短期我的建议是两件事。

第一，如果你重度依赖 Cursor，把你的 .cursorrules、prompts、workflow 全部备份到一个 git 仓库里。工具迁移的成本从来不在 IDE 本身，在你围绕它建立的习惯里。

第二，花一个下午试一下替代品。Claude Code、Zed、Windsurf、Continue 都值得摸一遍。不是说马上要换，是让自己手里至少有三个能用的武器，而不是一棵树上吊死。

至于 600 亿这个数字，它跟你没关系。它是马斯克讲给 IPO 投资人听的故事。你真正要关心的是，半年后你打开 Cursor 的时候，默认模型是不是还是 Claude Sonnet。

如果不是了，那 100 亿违约金，可能就是 Cursor 最后的体面。
