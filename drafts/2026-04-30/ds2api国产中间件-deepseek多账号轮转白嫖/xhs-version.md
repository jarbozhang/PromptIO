# ds2api 一夜涨 465 星，一个 DeepSeek 协议中间件冲上 GitHub Trending

一夜 +465 星，AGPL 协议，Go 写的，2.9k stars，752 forks。

我打开 GitHub Trending 第一眼看到 ds2api 的时候是这么个画面，今天一天就冲掉同榜大半数项目。我盯着它看了二十分钟，越看越觉得这个 stars 曲线本身比项目本身更值得说。

## 它是个什么东西

名字就说完一半了，"DeepSeek to API"。

DeepSeek 大家都在用。chat.deepseek.com 网页版、客户端、手机 app 是个人入口；platform.deepseek.com 是按 token 计费的开发者 API，跑 agent 一不留神就几块钱出去。

ds2api 做的事，是把网页那一侧的协议包成 OpenAI / Claude / Gemini 三种主流 API 的样子。它的接口分三套，OpenAI 那套 `/v1/chat/completions` 齐了，Claude 那套放在 `/anthropic/v1/messages`，Gemini 也补齐了 `streamGenerateContent`。

部署上 Linux/Darwin/Windows 二进制全给了，Docker compose 默认 6011 端口，Vercel 和 Zeabur 也支持一键。

我看完这套部署全家桶，第一反应是作者非常清楚目标用户画像，懒人开发者，不想搞运维。

## 我没有把它跑起来，而是想说三件事

第一，作者自己在 README 里写得很清楚，"仅供学习、研究、个人实验和内部验证使用"，"请勿用于违反服务条款的场景"。这句话我读了两遍，作者把免责写到位了，也是因为他知道这种中间件在合规上是灰区。

第二，账号风险是真实存在的。任何非自然的访问模式哪天 DeepSeek 想收紧风控，账号就是说封就封，没地方申诉。

第三，稳定性是个未知数。DeepSeek 任何一次升级，ds2api 都得跟进。开源仓库的 issue 区会出现一波"突然不能用了"的报告。这种东西跑不了生产。

所以我个人的态度是，看热闹可以，star 收藏可以，但**不建议任何人把它部署在自己机器上跑日常工作**。真要试也只能在隔离环境里看一眼链路是怎么打通的，别拿主账号去试。

## 真正值得看的，是这条 stars 曲线

ds2api 的 stars 数飙这么快，根本不是因为它技术上多惊艳。逆向中间件这种东西不是第一次出现。

它戳中的是一种情绪，国产模型的官方 API 计费虽然已经比海外便宜一个数量级，但在 agent 时代依然贵得让个人开发者肉疼。DeepSeek 把网页端做得太好了，免费无限聊，反而让付费 API 的体感落差变大。

这条曲线告诉我两件事。

一是，国内开发者对 agent 时代 token 计费的焦虑是真实的、巨大的、还没被满足的。谁能把"高性价比 agent 推理"这件事在合规路径上解决好，就有红利。OpenRouter 国内可访问镜像、国产模型的 batch 折扣、扣子这类免 token 平台，都在朝这个方向走。

二是，DeepSeek 自己应该认真考虑给个人开发者出一个低价 API tier。哪怕带每日上限、带速率限制，也是给真正在做小工具、做个人项目的开发者一个合规出路。否则这种项目会一个接一个冒出来，封一个再来一个。

## 小红书友情提醒

ds2api 这种项目长期不可持续，我个人判断它最终会进入越来越难用、用户慢慢散掉的循环。

更重要的是，**我强烈建议你优先用 DeepSeek 官方付费 API**，platform.deepseek.com 的定价在国产模型里已经非常友好，跑个人 agent 任务一天几块钱也就一杯奶茶钱，换来的是稳定性和合规性，这个钱花得值。

本文只做现象解读，不教任何人部署、不引导任何人去走灰区，纯粹是把一个 GitHub Trending 上的真实流量现象拆给你看。技术好奇心可以有，操作上请走合规路径。
