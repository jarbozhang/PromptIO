# 一个开源的闲鱼 AI 客服助手一夜涨星，副业党的沟通效率工具来了

我昨晚刷 GitHub Trending，看到一个叫 XianyuAutoAgent 的项目挂在 Python 榜，今天 +48 stars，累计 7.3k。

它一句话简介，专为闲鱼平台打造的 AI 客服自动化助手，7×24 值守，多专家协同，上下文感知对话。

我点进去看了五分钟，立刻觉得得马上写出来。

因为闲鱼这个生态，是中国 AI 副业党最大的"私域沟通场"。挂二手手机、二手键盘、原单球鞋的卖家，每天最痛的就是凌晨一点钟有人来问价，不回复掉权重，回复了睡不着。这个项目把这个痛点直接接管了。

而且它是国产 LLM 跑国内电商场景，默认通义千问，配置很轻量。落地门槛低。

## 这个 agent 到底干了什么

我把 README 整个读了一遍，骨架其实就三层。

**第一层是意图分类。** 用户发来一句话，先过一个 classify prompt，判断是价格咨询、技术咨询、无效消息还是一般问询。作者把分类规则写得很细，价格相关词走价格 agent，规格相关词（型号、Type-C）走技术 agent，识别到 prompt injection 直接进 no_reply 不回。

**第二层是专家路由。** 价格沟通单独一个 agent，技术问题单独一个 agent，闲聊和物流走 default。每个 agent 有自己的 prompt 文件，互不干扰。

**第三层是上下文记忆。** 一个 context_manager.py 把历史对话拼进 LLM 输入，所以买家半小时前问过的话，agent 现在还记得。这点在闲鱼场景里特别关键，因为买家最常见的就是隔几个小时回来再问一次。

## 它的 prompt 写法，最值得抄的几条

我去翻了它的 prompts 目录，里面四个文件，classify、default、price、tech 各一个。

最值得学的是它对回复风格的硬约束。

**句子控制在 10 字以内，总回复不超 40 字。** 这一句直接把 LLM 那种"您好亲爱的顾客"的客服腔给掐死了。闲鱼买家最反感长句，看到 100 字回复直接划走。

**用"全新""可小刀"这种行业用词。** 不是"价格可商量"，是"小刀"。AI 一开口说"小刀"，对面会下意识觉得"这卖家是个老手"。

**沟通节奏分阶梯，不是一次到底。** 让买家觉得有空间，又不让卖家亏到底线以下。

**确认意向后立刻引导下单。** 一句"价妥可下单，立即发出"，把对话从沟通模式切到成交模式。这是整个 agent 最值钱的设计，因为大量人工卖家在买家点头之后还在自我感动地多说两句，结果买家又跑去看下一家了。

## 社区里在讨论什么

我翻了 GitHub issue 区，吵得最凶的是两类问题。

**一类是 cookies 怎么稳定。** 这个项目目前还是网页端登录，复制 cookies 字符串到 .env。issue 区里有人提到大概一周左右要重新登一次，遇到风控会更频繁。这是这套方案目前最大的脆弱点。

**另一类是模型选型。** 默认通义千问，但有人反馈说自己换成 DeepSeek-V3 后中文情绪识别更贴近"闲鱼这个语境"。我没亲自验证，方向值得试。配置就是改一行 MODEL_BASE_URL 和 MODEL_NAME 的事。

知乎上闲鱼老玩家提到一个隐忧，AI 客服回得太"标准"，反而会被买家识破。一个真实卖家偶尔会打错字、会半夜不回。AI 永远在线、永远礼貌、永远 10 字以内，这本身就是一种"机器味"。项目作者也注意到了，README 里有个 SIMULATE_HUMAN_TYPING 的开关，模拟人类打字延迟。但我觉得这远远不够。

## 我的判断

**第一个判断，这套架构的真正价值不在闲鱼，而在更广的私域沟通场景。** 把 prompts 目录里的几个文件改一改，它就是淘宝客服 agent、私信沟通 agent、社群里的咨询 agent。意图分类、专家路由、上下文记忆这三件套，是国产 LLM 在中文电商场景里第一次被组装得这么干净。

**第二个判断，全自动托管不可取，平台风控会盯上你。** 一个号 7×24 在线、回复速度永远 2 秒、每条话术都精准卡 40 字以内，平台风控模型扫一眼就知道这是机器人。轻则限流。所以我的建议是，把它当"辅助"用，不要全量托管。深夜挂上、白天关掉，留一些"人味儿"的破绽。

## 行动建议

如果你真在闲鱼做副业，今晚就 git clone 一份本地跑起来，先观察它怎么处理你最常被问的那几个商品。

把 prompts/price_prompt_example.txt 改成你自己的话术风格（仅供学习参考），让 agent 替你跑三天，每天人工 review 一次对话日志。

不要全托管。AI 是助手，不是替身。

如果你不做闲鱼，但做任何"私域沟通"的生意，把它的 classify_prompt 那套意图分类思路抄走。这是这个项目里最不显眼、但复用性最强的部分。

回到我开头那个画面。凌晨一点的咨询消息，从此不会再吵醒你。

但你也得问自己一个问题，当连"和买家沟通"这件事都被外包给 AI 之后，你这个卖家，到底还在卖什么。
