# Jeff Dean 创办 Discovery Loop，小团队如何把实验周期从周压到小时

Jeff Dean 与 Sanjay Ghemawat、Oriol Vinyals、Quoc Le 共同创办 Discovery Loop，真正值得技术团队关注的，不只是一家新公司的出现，而是它选择自动化的对象。

他们要推进的不是某个单点模型，而是机器学习、科学与工程中的发现过程。对正在做模型评测、性能优化或产品实验的小团队来说，这个方向给出了一条更具体的启发，把人反复推动的实验流程，改造成能够持续运转的验证闭环。

短期内，你未必需要一套庞大的研究系统。更现实的起点，是让一个问题能够自动产生假设、触发实验、接受评估，再把结果送回下一轮。实验周期能否从周缩短到小时，关键往往不在模型更聪明，而在反馈有没有真正闭合。

## 把注意力从自动执行移到自动发现

现有研发自动化大多停留在执行层。工程师确定任务，系统负责写代码、提交训练作业或运行测试。它能省掉操作时间，却没有改变实验如何被选择。

Discovery Loop 公布的使命更进一步，要自动化机器学习、科学和工程，从而加速发现与进步。这里值得关注的小变化，是自动化的单位正在从一次任务转向一轮发现。

一次任务有明确终点，例如跑完评测、修改参数、生成报告。一轮发现则必须回答更难的问题，结果是否支持原假设，失败属于偶然波动还是方向错误，下一次实验应该改变哪个变量。

Agent 应用如果只会调用工具，仍然是更灵活的脚本。只有当评估结果能够改变下一轮动作，它才开始具备实验系统的形态。

## 让五个环节接成同一条反馈链

一个可运行的实验循环，可以缩小为五个环节，问题、假设、实验、评估和反馈。这里不是在复述 Discovery Loop 尚未公布的产品方案，而是把其使命转成小团队可以验证的工程结构。

问题必须足够窄。不要写成“提升模型效果”，而要落到“长文本问答中，引用遗漏主要发生在哪类输入”。问题越模糊，系统越容易生成大量无法比较的实验。

假设需要留下可证伪条件。比如调整检索数量可能提高证据覆盖率，但也可能增加无关上下文。系统不仅要提出修改，还要写清什么结果能支持它，什么结果会推翻它。

实验要控制变量，并记录代码版本、数据集、参数和运行环境。否则同一指标发生变化时，团队无法确认改动来自策略、数据还是环境漂移。

评估不能只看一个总分。模型任务可能同时涉及正确率、延迟、成本与稳定性，产品实验还要观察用户行为和异常路径。单指标优化很容易把问题挤到另一个角落。

反馈则负责决定下一轮是保留、回退还是换方向。没有这个决策出口，评测报告只是终点文件，不是循环的一部分。

## 从一个高频实验压缩验证时间

小团队不适合一开始就追求全自动研究。系统一旦同时拥有改代码、调参数、选择数据和判断结果的权力，失败原因会迅速变得不可追踪。

更稳妥的做法，是挑选一个已经重复发生、验收条件清楚的场景。例如模型版本更新后的回归评测、接口延迟优化，或者提示词变更后的固定样本测试。这类任务有历史基线，也容易发现自动判断是否失真。

可以保留人工提出问题，让系统负责生成有限数量的假设、运行隔离实验并汇总证据。到评估环节设置明确门槛，只有指标改善且没有触发回归项，结果才进入下一轮。

实验周期从周压到小时，并不要求每一步都交给 Agent。更常见的收益来自等待被消除，任务可以连续排队，失败能够自动归档，相同环境能够重复创建，结果出来后不必等人手动搬运。

## 给循环装上停止条件

自动循环最危险的地方不是停止，而是不知道为什么继续。指标设计有偏差时，系统会非常勤奋地优化错误目标。实验成本缺少上限时，一次局部改进也可能换来不可接受的资源消耗。

因此，每轮都需要预算、最大尝试次数、回退点和人工复核条件。涉及数据变更、生产发布或目标函数调整时，决策权仍应留在人手里。自动化负责扩大可验证实验的吞吐量，不负责替团队定义什么才算进步。

这也是当前值得观察 Discovery Loop 的原因。四位创始人共同工作了十四年至三十年，参与建设过广泛使用的产品、基础设施和 AI 模型。如今他们把注意力放到发现流程，反映出一个清晰判断，下一阶段的竞争不只是谁能完成一次复杂任务，还包括谁能更快获得可靠反馈，并据此开始下一轮。

## 用一次模型回归建立闭环

读者可以从现有评测脚本里选一个重复任务，把输入版本、假设、改动、指标和结论写进同一份实验记录，再让下一轮任务读取这份记录。先验证系统能否稳定复现旧结果，再允许它提出新的参数或代码修改。

我的判断是，自动实验循环不会先以“全自动科学家”的形态进入多数团队。它会先藏在模型评测、性能优化和产品实验里，把原本散落在聊天记录、脚本和表格中的判断连起来。

真正的门槛也不是生成更多实验，而是让系统知道什么证据足以继续，什么失败必须停下。先把一个回归任务闭合，比同时启动十个无法解释的实验更接近 Discovery Loop 所指向的方向。
