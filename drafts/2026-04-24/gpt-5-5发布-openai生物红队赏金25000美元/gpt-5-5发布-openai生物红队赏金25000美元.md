# GPT-5.5 昨天深夜悄悄上线了，OpenAI 同步开了个 2.5 万美元的生物病毒越狱赏金

昨天深夜我刷 OpenAI 博客，差点被吓一跳。

GPT-5.5 上线了，官方一句话自夸，smartest model yet，更快、更能干、专门为编程、研究、数据分析这种复杂任务打造。

这不算稀奇。稀奇的是隔壁同时出现的另一篇博客，标题是 GPT-5.5 Bio Bug Bounty。翻译过来，生物安全越狱悬赏。单个漏洞最高 $25,000。

一边是 OpenAI 新旗舰发布，一边是 OpenAI 自己掏钱，请全世界红队来砸这个新旗舰的生物病毒护栏。这两篇博客是同一天发的。

我盯着这两个链接看了一会儿，心里冒出来一句话，这才是 2026 年 AI 公司发模型该有的样子。

## 先把事情讲清楚

GPT-5.5 本体没什么悬念，沿着 GPT-5 系列往上堆。OpenAI 给的官方描述很短，就是更聪明、更快、更能干，专攻编程、研究、数据分析跨工具的复杂任务。同时放出了 System Card，这是 OpenAI 从 GPT-4 开始养成的习惯，模型发布当天同步公开一份系统卡，里面写模型的能力、风险、评测、红队结果。

真正有意思的是第二篇博客，Bio Bug Bounty。

这个词拆开看，Bio 是生物安全，Bug Bounty 是漏洞悬赏。合起来，就是 OpenAI 公开征集 GPT-5.5 在生物安全场景里的"通用越狱"（universal jailbreak）。什么叫通用越狱，简单说就是能用同一套 prompt 骗过模型拒绝机制、让它吐出它本不该吐的东西的那种攻击。比如病原体合成路径、增强致病性的改造建议。

单个有效越狱，最高赏金 $25,000。

这就把一个原本关在公司内部红队团队里的事情，翻到了台面上。以前模型发布之前，OpenAI 内部红队、外部合作伙伴会做几轮生物武器相关的对抗测试。这次不一样了，OpenAI 把这件事变成了众包。

## 为什么单独给 Bio 开赏金，不给别的

这是我自己琢磨出来的一个角度，不一定对。

OpenAI 的赏金项目之前就有，但那是针对 API 和基础设施的常规漏洞，跟模型能力无关。这次是第一次专门针对 Bio safety 开一个悬赏。

为什么是 Bio，不是网络攻击、不是 CSAM、不是恶意代码。

我的判断是，生物安全这块是整个 frontier AI 监管里最敏感、也最容易被用来做政治游说的方向。美国那边一直在讨论前沿模型在生物武器方向的"非平凡 uplift"，也就是模型会不会让一个业余人员具备原本需要博士团队才有的能力。如果真的被证实有这种 uplift，那整个行业的监管走向就变了。

OpenAI 把这件事摆到阳光下，是在做两件事。一件是真的想知道 GPT-5.5 的护栏有没有系统性漏洞，另一件是向监管机构、向公众证明，我们不是在藏着掖着。

这是典型的"把风险变成透明度来对冲政治风险"。

## 对中国开发者，这事的分量在哪

坦率讲，GPT-5.5 本身对大部分中国开发者的直接影响有限。API 访问、账号、支付这些老问题一个都没解决。能用上的还是那批有境外资源的人。

但 Bio Bug Bounty 这件事的信号价值，中国 AI 圈真的该重视。

第一，这是一个新的红队商业模式的雏形。单个漏洞 $25,000 ，对国内很多搞安全的研究者、prompt injection 爱好者来说，是一笔实打实的现金。我认识的一些做 AI safety 方向的朋友，以前靠发 paper、靠学校经费活着。现在多了一个路子，去打国际厂商的赏金榜。这个门槛不需要博士学历，只需要你会设计对抗 prompt。

第二，国内模型厂商迟早要面对同样的问题。DeepSeek、通义、Kimi、豆包、元宝，现在的能力追赶得差不多了。下一步的差异化，不在"谁更聪明"，而在"谁的护栏更扎实、谁能通过监管"。我预计一年内就会有国产大厂学着开一个类似的中文 Bug Bounty。真到那时候，谁先把红队社区养起来，谁占优势。

第三，Bio safety 本身就是个全球性议题。不管你在哪个国家做模型，只要想走向国际，这道坎必过。现在国内的安全评测还停留在拒答率、敏感词这种粗糙维度，跟 OpenAI 这种"生物武器通用越狱"级别的评测完全不是一个量级。

我是真的觉得，这次 OpenAI 顺手抬高了整个行业的安全基线。

## 一个让我有点不舒服的地方

说实话，我对这件事的感受是复杂的。

一方面我觉得 OpenAI 干得漂亮，把内部红队公开化，让整个社会参与监督，这比闭门自查强一百倍。

另一方面我也有点担心。当"通用越狱"变成公开悬赏目标，相当于把"怎么把 GPT-5.5 搞成生物武器助手"这个问题变成了一个 $25,000 的题目。参与者里有白帽，也可能有灰帽。漏洞提交之后，从发现到修复之间有个时间窗口。这个窗口里，攻击方法会不会被转手卖到别的地方。

当然 OpenAI 肯定有 NDA、有披露流程。但现实是，一旦方法论公开，哪怕只公开到"我们修复了一个 universal jailbreak"，别人就会顺着这条线去复现。攻击这种事，知道能做到，比知道怎么做到更重要。

这不是否定这个项目，而是说，公开红队这条路，天然带着一个剃刀边缘。

## 你能做点什么

如果你是做 AI 安全方向的，去看 OpenAI 的 Bio Bug Bounty 页面，注册提交通道，把规则摸清楚。这可能是今年 AI safety 方向最快的变现路径之一。

如果你是做模型产品的，去翻 GPT-5.5 的 System Card，看他们怎么量化一个模型的 bio risk、怎么设计评测集。国内绝大部分厂商的安全 System Card 还是空白，这是可以抄作业的。

如果你只是个普通 AI 用户，那就记住一件事，当一家公司愿意为自己产品的漏洞掏真金白银的时候，它的产品大概率比那些只会发 PR 稿的产品更值得信任。

回到开头那个画面，两篇博客同一天发，一篇叫"最聪明的模型来了"，一篇叫"请来砸它"。

真正的自信，不是宣称"我最强"，是敢把自己放到大家手里让大家砸。
