## 原帖详情

我发现中推居然没多少人发这个。

吴恩达 @AndrewYNg  刚刚开源了 OpenWorker，一个本地运行、模型无关的 AI 同事。

你只需要给它一个最终目标，比如准备客户简报、整理日历、起草报告、处理 Slack 告警。

它会自己拆解任务、读取文件、调用工具，最后直接交付文档、消息或者日历更新。

遇到发送消息、修改日程这类关键操作，它会先停下来向你确认。

OpenWorker 目前支持 Mac，Windows 即将推出。用户可以自带 API Key，接入 GPT、Claude、Gemini、Kimi、GLM、DeepSeek 等模型，也可以通过 Ollama 完全本地运行。

除了用户主动选择的模型服务和外部集成，数据默认留在自己的设备上。

吴恩达这个项目真正值得关注的地方，是它把现在 Agent 产品最重要的几件事放到了一起：

本地优先、模型可替换、跨工具执行、产物交付，以及关键操作的审批机制。

其实和我们在 @lobehub 正在做的方向很接近，但两者的侧重点不太一样。

OpenWorker 更像一个运行在个人电脑里的「单兵型 AI 同事」，重点是本地执行、工具连接、隐私保护和关键操作审批。

LobeHub 更像一个可以组织不同 Agent 协作的工作台。执行类需求会进入 Task，由不同能力的 Agent 分工完成，用户可以查看过程、调整任务、介入执行并验收最终结果。

简单来说：

OpenWorker 想把一个 AI 同事放进你的电脑。

LobeHub 想让不同的 AI Agent 能够组队、分工、协作和交付，逐渐形成一套真正可运行的 AI Agent工作组织。

它们背后的判断其实是一致的：

模型本身会不断升级，也可以随时替换。真正需要长期沉淀的，是 Agent Harness、任务系统、工具连接、权限控制、上下文管理、过程验证和最终交付体验。

下一阶段的 Agent 竞争，已经不再是谁更会聊天。

而是谁能更稳定地把一件复杂的工作做完。
