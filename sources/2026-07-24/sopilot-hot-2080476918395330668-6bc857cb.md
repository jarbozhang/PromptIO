Clone 了项目看了一遍，又让 Codex 和 Cursor 各看了一遍，坦白讲，没看到有特别不一样的地方：

这也是现在自己做 Agent 的必备架构了，如果你在学习 Agent 架构和工程，这倒是一个比较规整的项目。
