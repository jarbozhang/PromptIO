- 无锡日报称，5月15日 AI 算力企业弘信电子联手无锡高新区打造江苏省内首个华为昇腾 384 超节点算力集群，签约落户无锡；首批将部署 4 台华为昇腾 384 超节点服务器。
- 财联社摘要列出三点：首批 4 台昇腾 384 超节点服务器；Token 工厂领域已涌现独角兽公司；机构认为国内 Token 工厂将快速发展。
- 原文解释 Token 是大模型处理信息的最小单位，具备可计量、可定价、可交易特征，是 AI 服务计费、结算基础单位。
- Token 工厂被定义为以大规模 GPU 算力集群为底座，整合电力、液冷、高速网络和大模型推理优化技术，工业化、标准化量产 AI Token 的新型算力基础设施。
- 文章对比传统算力租赁按卡时/机柜计费，Token 工厂按智能单元计费，核心从卖算力时间转向卖推理产出。
- 文中称中金测算自建算力情景下 Token 工厂理论毛利率可达 60%；也提到 Fireworks AI 作为按 Token 计费和模型微调服务的参考标杆。
- 文章列举运营商和互联网大厂动作：中国电信宁夏百亿级 Token 工厂集采、中国移动 Token 套餐和 Token 运营生态联盟、阿里 ATH 事业群、腾讯 Token Hub、字节火山引擎、百度智能云 MaaS 升级 Token 工厂。
