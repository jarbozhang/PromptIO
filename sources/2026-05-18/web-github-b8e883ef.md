- GitHub API: 15102 stars, 2589 forks, JavaScript, created 2023-05-09, pushed 2026-05-17, homepage https://muapi.ai/open-generative-ai.
- README positions it as free open-source AI image/video/cinema/lip-sync studio, with hosted version and desktop installers for macOS, Windows, Linux.
- Supports 200+ image/video models including Flux, Kling, Sora, Veo, Seedream, Wan and lip-sync models through Muapi, plus desktop local engines.
- Desktop local engines: bundled sd.cpp for local image models and BYO Wan2GP server for video/large image models. README says local mode can run image models from app UI and point to Wan2GP server for Wan 2.2/Hunyuan/LTX.
- README also links Generative-Media-Skills for Claude Code/Codex agents to drive image/video generation pipelines from terminal.
