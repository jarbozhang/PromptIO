- GitHub API: 13226 stars, 1138 forks, Rust, GPL-3.0, created 2026-02-18, pushed 2026-05-17. README status says early beta.
- README says OpenHuman is open-source agentic assistant for daily life with UI-first desktop experience, desktop mascot, Google Meet participant, memory over weeks and background thinking.
- Integrations: 118+ third-party integrations with one-click OAuth across Gmail, Notion, GitHub, Slack, Stripe, Calendar, Drive, Linear, Jira and others. Auto-fetch every 20 minutes into memory tree.
- Memory Tree + Obsidian Wiki: local-first knowledge base, canonicalized into <=3k-token Markdown chunks, scored, folded into hierarchical summary trees in SQLite and Obsidian-compatible vault.
- Batteries included: web search, web fetch scraper, coder tools, native voice, model routing, optional Ollama local AI.
- TokenJuice compression claims up to 80% cost and latency reduction by compressing tool calls, scrape results, email bodies and search payloads before LLM use.
