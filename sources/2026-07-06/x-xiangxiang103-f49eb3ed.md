Hermes Agent 的联网能力原地起飞了 🚀

Nous Research 刚发了更新：Hermes Agent 的网页读取能力直接提速 60 倍，成本降到 1/49。

原理不复杂——做了两件事：
- 抓取后端直接传干净内容给 Agent，砍掉了多余的加工环节
- 大页面存本地按需分页读取，不一次全塞进上下文

结果就是：同样的质量，时间变零头，成本变零头的零头。

说实话这个方向很聪明。AI Agent 联网能力一直是瓶颈——不是读不动，是读得太笨。要么整页硬塞烧 token，要么截断丢信息。按需分页读这个思路，早该有人做了。
