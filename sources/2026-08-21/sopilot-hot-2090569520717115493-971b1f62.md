## 原帖详情

刚刚，Anthropic 把一个拖了快两年的功能终于扶正了。

Claude的 Computer Use 功能正式宣布上线。。

Computer Use 其实早在 2024 年 10 月就发布了。

当时 Claude 3.5 Sonnet 已经可以看屏幕、移动鼠标、点击和输入文字，但 Anthropic 一直把它放在 public beta。

直到今天，Computer Use 才正式进入 Claude Platform 的生产可用阶段。

新版 Computer Use 最大的变化，是 Claude 一轮可以连续执行多个电脑操作。

以前点一下、输入一下、截个图，可能都要重新调用一次模型。

现在 click、type、key、screenshot 等操作可以连续完成，减少大量模型往返，Agent 跑长任务的速度和成本都会下降。

Anthropic 还第一次上线了独立的 Browser Use Tool。

Claude 除了看网页截图，现在还能直接读取网页结构，找到具体的输入框、按钮和页面元素。网页稍微改个布局，Agent 不至于立刻变成一个找不到鼠标该点哪的老头。

同时一起正式上线的还有：

Skills API：可以把公司的 SOP、脚本、模板做成 Skill，上传、版本管理，然后在不同 Agent 任务里反复调用。

Files API：文件上传一次，之后直接通过 ID 反复使用；这次还加入自动过期，限流提高 5 倍，每个组织提供 1TB 存储。

Computer Use 负责操作软件，Browser Use 负责网页，Skills 负责 SOP，Files 负责文件。

Claude 的 Agent 开始越来越像一个完整的企业级生产Agent了。
