## 原帖详情

Anthropic 现在的处境非常尴尬。

一方面它的 Q2 营收已经超过 @OpenAI  ，但Claude的用户势头却开始被 ChatGPT 压过去了。

特别是最近明显能感觉到，越来越多的人选择停止 @claudeai  的订阅，转向 ChatGPT 了。

原因基本也都差不多。

Opus 5 太啰嗦，Fable 5 烧额度太快。

再加上 Anthropic 各种不做人操作，很多原来 Claude 的重度用户，工作流正在一点点搬到 ChatGPT。

与此同时，OpenAI 的用户增长已经快竖起来了。

今年 1 月还只有 20 万周活，现在 ChatGPT Work + Codex 已经到了 2000 万周活。

当然， @AnthropicAI   短期营收可能完全没事。

它现在越来越多的钱已经来自 API、大客户、云渠道和企业版，Claude 个人订阅未必还是主要收入来源。

但长期我觉得这里有个挺大的隐患。

Agent 本身就是一个非常强的企业获客入口。

一个开发者先开始用 ChatGPT，接下来是整个团队的代码库、Memory、Skill、工作流、Agent 都围绕 ChatGPT 搭起来，最后企业采购基本就是顺着员工已经形成的习惯往下走。

Claude 当初其实也是用 Claude Code这么帮 Anthropic 打进大量企业的。

现在 OpenAI 正在反过来走这条路。

而且 OpenAI 手里还有一个最恐怖的东西：接近 10 亿 ChatGPT 用户的分发入口。

ARK 算了一下，目前这 2000 万 Agent 用户，相当于整个 ChatGPT 用户池大概只有 2% 的渗透率。

如果这条曲线继续往上冲，真正麻烦的可能还在后面。

所以接下来我最想看的，就是两条曲线：

Anthropic 领先的营收曲线。

OpenAI 正在疯狂增长的 Agent 用户曲线。

哪条最后会把另一条拽过去。

这可能比下一次 Benchmark 谁高两分有意思多了。
