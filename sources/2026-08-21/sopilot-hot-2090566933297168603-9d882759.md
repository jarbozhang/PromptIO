## 原帖详情

刚刚，ChatGPT开始接管你的私人通信了。

OpenAI 正式上线 Apple Messages 插件，目前已经接入 ChatGPT Work 和 Codex 桌面端。

接入以后，ChatGPT 可以直接在 Mac 上：

搜索历史消息、总结聊天记录、找出需要跟进的人和事、起草回复，甚至直接替你发送消息。

官方演示里最典型的用法是：

“帮我找出昨天 Messages 里有哪些事情需要继续跟进。”

然后 ChatGPT 会直接翻你的聊天记录，把遗漏的事情和需要回复的人整理出来。

OpenAI 表示，这个插件主要在本地 Mac 上运行，不会先把你的所有 Messages 全部上传、建立一份完整索引。

不过发消息这种操作还是比较敏感，官方建议保留发送前确认，别直接永久授权自动发送。

这个更新我觉得比过去很多更新都重要，过去 ChatGPT 接的是 Gmail、日历、文件，本质上都还是工作数据。

Messages 不一样。

这里面是你每天和朋友、家人、同事真正发生的对话，也是一个人最完整的私人 Context 之一（甚至还有营销信息）。

当 AI 能读懂这些聊天记录，还能判断“谁该回、什么事没做、应该怎么回”，Personal Agent 又往前走了一大步。

以后人类最常见的工作流可能是：

你负责聊天，AI 负责记得。

然后还能提醒你，你忘了什么。

让我想起了之前那一堆外挂大脑🤣
