Claude Code 现在内置 Claude Design 了，今天试用了下，很好用，比在网站上用方便多了，和本地项目打通了，不用来回切换了。

用的时候很简单 /design + 你要设计的内容 就可以。

如果你用 Claude Code 的话，不再需要用 baoyu-design（https://t.co/8zkHcKkI7h） 这种 skill，直接用内置的 /design 最好用。

如果你还没有把 Claude Design 用起来，一定要试试。
