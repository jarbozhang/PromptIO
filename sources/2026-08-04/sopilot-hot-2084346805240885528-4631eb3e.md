## 原帖详情

我把之前 fork 的 Grok Build 正式整理成一個獨立專案了：

Medley — Grok Build 的多 Provider 社群版。

它保留原本完整的終端 Coding Agent、TUI、檔案編輯、Shell、MCP、Skills 和長任務能力，但不再只能綁定 xAI。

現在可以使用：

- 原本的 xAI 登入
- 透過相容的 Codex OAuth 流程登入 ChatGPT 帳號
- OpenAI-compatible API
- Chat Completions、Responses、Messages endpoint
- Ollama、LM Studio、llama.cpp、vLLM 等無金鑰本地模型

這次做的也不只是讓使用者修改 "base_url"。

不同 Provider 的憑證會分開保存；缺少憑證的模型會直接標成不可用；切換不同驗證類型前會提醒；請求送到第三方或本地端點時，也會移除 xAI 的身分 Header，避免把原本的 Session 資訊一起帶出去。

Medley 使用獨立的 "medley" 指令和 "~/.medley"，可以跟官方 Grok Build 同時安裝，不會共用同一份狀態與憑證。

內建自動更新也故意關閉，避免更新後被官方 Grok Build binary 直接覆蓋回去。

medley
medley login --provider openai-codex

目前提供 macOS 與 Linux Release；Windows 暫時需要自行從原始碼編譯。

這不是 xAI 或 OpenAI 的官方產品，Codex 相容層也不代表官方承諾長期穩定。
