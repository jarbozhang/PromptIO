## 原帖详情

兄弟们这中转 API 价格，真的看得我有点怀疑人生。

朋友最近搞了个小平台，主打中转 + 代充 GPT，说是薄利多销，一个月能有几万进账。

我一开始完全不信。

然后自己进去试了下：

https://t.co/4rlGoEFU6c

结果最离谱的是价格。

1.5U 直接当 100U 用。

这个比例你说不心动是假的，尤其是平时 API 调得多的人，看到这种价格真的会愣一下。

后台也不是那种毛坯站。

仪表盘能直接看余额、API Key、今日请求、Token 用量，还有各个平台的消耗拆分。

OpenAI 那边甚至显示到 1198 刀+。

客服响应也挺快，至少我试的时候不是那种发消息石沉大海的状态。

不过我建议别一上来就猛冲。

这种中转平台，先小额测。

看稳定性、看响应速度、看模型可用情况，再决定要不要长期用。

便宜是真的便宜。

但 API 这东西，最怕的不是贵，是你正用着它突然抽风。

反正我先丢这了。

有高频调用需求的可以自己测一下，别听谁吹，自己跑一轮最实在。
