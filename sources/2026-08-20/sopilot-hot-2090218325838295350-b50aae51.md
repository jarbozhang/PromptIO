## 原帖详情

DeepSeek Harness正在迅速发展🔥

8 月 19 日，DeepSeek Harness 合入了一次新的多模态更新：

feat(llm-deepseek): support multimodal requests

这次更新给DSH装上了眼睛，把图片这个正式接进了 Agent 的 Context 和 Tool Loop 里。

现在你可以让 DSH：

「看看这个页面截图哪里有问题」

它现在可以直接调用 read_image这个工具读取工作区里的 PNG、JPEG、WebP、GIF。

读取之后，图片不会被 OCR 成一段文本，也不会只返回一个文件路径。

DSH 会把图片保存进自己的 Attachment Store，然后生成一个真正的 ImageBlock，塞进 Tool Result。

下一轮模型请求时，这张图片会直接进入模型上下文。

现在 DSH 可以处理的各种图片输入。

长任务里的图片 Context 也考虑到了。

DSH 默认限制一次请求累计 20 MiB 的图片 payload，图片越来越多以后，会优先把最老的图片从请求里 offload 掉，避免一个跑了几十轮的 Agent 最后被截图把请求体撑爆。

用过Coding Agent的朋友们肯定懂这个能力有重要。

也很有意思，昨天群友还在思考怎么给DSH安个眼睛。

结果人家已经搞定了😂

照这个速度下去，DSH 真有点一天一个样。
