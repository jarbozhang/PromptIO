## 原帖详情

我看存储熄火之后不少小伙伴调仓到软件股了（SaaS之类的）。我工作生涯的前5年都在看to b市场投软件公司。我的观点是软件公司会在未来被AI榨干至少80%的价值，越偏向平台生态型的，壁垒相对越强，剩余价值也越多，比如电商类的shopify还有内容创作平台还好一些；越偏向工具性的，壁垒相对越弱，价值也越少。

其实你需要想通一个逻辑，短期内（至少目前是），anthropic吃掉的蛋糕大部分是SaaS的市场，openai吃掉的是个人搜索的市场，grok吃掉的是图片生成的市场。

我是不会去逆着趋势买软件股的，就像我到今天也没真正搞懂为什么段神要买茅台。

- **Alpha哥AI投资日记 🌴 📈 (@AlphaguyTrading)**：我觉得 SaaS 还是得分开看，不能一棍子打死。

比如 Shopify，严格来说它现在已经不算一个典型的 SaaS 了。最新一个季度，大约 78% 的收入都来自和商家交易额相关的收入，包括支付手续费、交易相关收费这些，真正靠订阅月费赚的钱只有 22% 左右。 所以 AI 把写文案、上架，客服这些 SaaS 功能越来越商品化，其实是可以提高整个 GMV 的，只要商家还在 Shopify 上卖东西、收款，它照样能跟着 GMV 赚钱。

SAP 这种也不一样。企业的财务、供应链、采购、人事这些核心系统都跑在上面，大企业的迁移成本非常高。AI 更可能先增强 SAP，就各种 AI workflow API 嵌到 SAP 的软件里面，而不是直接把 SAP 替代掉。

真正危险的反而是大量中小型工具 SaaS：没有交易闭环，没有独家数据，也不是企业的核心系统，本质上就是一个 UI + workflow。以前一个小功能就能每个月收你几十上百美金，以后一个 Agent 可能直接把五六个 SaaS 的工作一起做掉。

我认同 AI 会干掉大量 SaaS 的价值，最后还是要看这个软件到底靠什么赚钱，有没有交易、数据、生态和迁移成本这些真正的壁垒。
