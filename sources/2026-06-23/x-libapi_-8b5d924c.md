Hermes Studio v0.6.18 版本更新 

支持新发布的 Hermes Agent 0.17.0 runtime。

除此之外，v0.6.18 还做了不少关键升级：

MCP 拆分为 api、devices、use 工具集，职责更清晰

新增 session、model、chat-run、ops 相关操作

聊天和群聊历史更可靠，UI 历史与模型上下文分离

run failed 不再覆盖已有助手回复，reasoning 回放更一致
MCU 设备反馈更清楚，工具调用优先显示，ONLINE/IP 长文本支持滚动

支持自定义 HTTP TTS / STT 端点，并加入音频转码

新增消息 fork 操作和持久化 fork 标记

Windows PATH 注册支持 Unicode

补齐移动端 PWA 元数据，并修复多项 profile/auth 恢复问题
