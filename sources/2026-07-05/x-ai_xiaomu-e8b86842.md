公布答案：
为什么我的 Claude Code 到现在还活着。

核心逻辑是：
让账号的登录环境尽量干净、稳定、一致。

主要做了 3 件事：
1. 先看住宅 IP 纯净度，别用多人机场； 
2. 使用指纹浏览器：我用的是 AdsPower：
https://t.co/EItjSxBPxO
单独建 Profile，把指纹、代理、Cookie、登录环境隔离开；
3. 处理 Anthropic 相关验证邮件时，尽量使用非大陆IP；

很多人只盯着账号本身，但真正容易出问题的，往往是网络环境反复切换。
