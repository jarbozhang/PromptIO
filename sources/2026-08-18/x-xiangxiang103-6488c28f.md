DeepSeek Harness 刚开源没几天，社区已经开始疯狂搭积木了。

这两天翻了一圈 GitHub，如果你也想研究 DSH，这 7 个项目值得重点关注，我按重要程度排了一下：

1、DeepSeek Harness

DeepSeek 官方项目，也是整个 DSH 生态的根。核心理念是「Everything is a Plugin」，模型、工具、Sandbox、Session，甚至 Agent Loop 都可以插件化替换。
https://t.co/LLEQKGXJDm

2、Awesome DSH Plugin

目前比较值得收藏的 DSH 插件索引，社区各种插件都开始往这里聚集。想知道大家正在拿 DSH 折腾什么，从这里逛最快。
https://t.co/qmmpZs5YJf

3、dsh-market

社区做的 DSH 插件市场，可以直接搜索、浏览和安装插件，目前目录已经收录 300+ 插件。这个项目很值得关注，因为插件市场很可能决定 DSH 生态能不能真正做起来。
https://t.co/BRMcG4XXLT

4、Cordis

它不是普通的周边项目，而是 DSH 底层非常关键的插件框架。想真正搞懂 DeepSeek 为什么敢喊「Everything is a Plugin」，Cordis 这一层绕不开。
https://t.co/LLEQKGXJDm

5、Awesome DeepSeek Harness

更偏整个 DSH 生态的导航项目，不只是插件，还在持续整理工具、基础设施、桌面端等社区项目。想长期追踪 DSH 生态，可以直接收藏。
https://t.co/nIGyBkdAhw

6、DeepSeek Harness Desktop

社区已经开始尝试给 DSH 做真正的桌面端，把 Node.js、命令行这些东西藏起来，让 Harness 更接近一个开箱即用的 Agent 应用。目前还比较早期，但这个方向很值得关注。

7、dsh-web-lan-access

解决的问题非常直接：让本机运行的 DSH Web UI 可以通过局域网访问。电脑负责跑 Agent，手机、平板、其他电脑都可以连过去操作。
https://t.co/33UogxeCQN

简单总结一下：

DeepSeek Harness 现在最值得关注的，可能已经不只是 Harness 本身，而是它正在形成的生态。

官方把模型、工具、Sandbox、Session、Agent Loop 尽可能插件化，然后社区开始补插件市场、桌面端、远程访问和各种 Agent 能力。

话说安装了dsh-web-lan-access这个项目，是不是我的Airtap云手机可以Web直连DSH了啊🧐
