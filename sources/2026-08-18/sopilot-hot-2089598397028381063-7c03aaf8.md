## 原帖详情

今天早上 Bloomberg 报道，Anthropic 截至 7 月底的年化收入 Run Rate 超过 650 亿美元，Reuters 随后也确认了这一数字。

今天港股的大模型公司已经率先出现了很明显的反应。智谱盘中一度跌近 17%，MiniMax 也一度跌超 13%。

单看同比当然很夸张：去年底还只有约 90 亿美元。但如果一直在跟踪 Anthropic 最近几个月的数据，就会发现增长斜率明显下来了。5 月初 Anthropic 的 Run Rate 已经达到 470 亿美元，此后接近三个月，到 7 月底只增加了约 180 亿。相比之下，此前从 4 月初的 300 亿涨到 5 月初的 470 亿，一个月左右就增加了 170 亿。

而此前市场的预期明显要高得多。第三方数据甚至一度估到接近 800 亿美元，David Sacks 上周五还在 All-In Podcast 里说 Anthropic “已经超过 800 亿，而且看起来没有放缓”，甚至开始讨论明年底做到 4000—5000 亿美元 ARR。

所以 650 亿这个数字出来以后，我觉得今天市场开始重新思考一件事：Coding 这轮最陡的增长曲线，是不是已经过去了？

不过我暂时不会因此直接转向 AI Bear。因为 Anthropic 增速下降，并不等于 AI 使用量下降。就算 Claude 的份额下降，OpenAI、Google以及越来越多开源模型的 Token 使用量仍然可能继续高速增长。 

真正值得担心的是另一种情况：

Token使用量继续爆炸，但越来越多 Token 跑在更便宜的小模型和开源模型上；OpenAI、Anthropic 的收入增速同时下降；企业开始大规模做模型智能 Routing、压低推理成本；与此同时 hyperscaler 的 Capex 增速也开始拐头。

如果发生这种组合，就说明一个更麻烦的问题：

AI 使用量可能仍然在高速增长，但每单位智能愿意付的钱，以及每单位智能需要消耗的算力，下降得比使用量增长还快。那才会真正动摇 NVIDIA、HBM、服务器、数据中心和电力这一整条 AI Capex 逻辑。

所以我现在对 Anthropic 这个 650 亿美元数据的理解还是：黄色预警灯，不是红灯。

接下来真正需要回答的问题是：

Coding 之后，下一个 Claude Code 在哪里？

如果未来半年真的出现一个 Coding 级别的新场景，比如能够长期可靠运行的 autonomous agent 开始大规模进入金融、法律、咨询、科研和企业运营，AI Bull Case 继续。

如果找不到，而模型公司收入开始集体降速，那今天 Anthropic 的 650 亿，回头看可能就是第一个比较清晰的黄灯预警信号。
