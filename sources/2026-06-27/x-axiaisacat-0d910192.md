很多 React 组件库，第一眼都像后台系统。

zelda-hyrule-ui 反着来：
它把《旷野之息》那种游戏 UI，做成了一套 React 组件。

血条、精力轮、任务面板、地图标记、对话框、商店界面，都能直接拿来用。

最有意思的是，它还给 AI 写了使用文档。

你把链接丢给 Cursor，让它按这个风格继续做页面，不容易跑成普通 SaaS 味。

这类项目挺适合游戏化工具、学习 App、打卡产品。

UI 一换，产品气质马上就不一样了。
