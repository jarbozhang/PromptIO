Hermes studio 新版本v0.6.31 已上线 👾

这个版本支持 自定义runtime 目录

本次更新共合并 25 个 PR，重点升级：

• Workflow 支持结构化 JSON 条件、完整执行记录与历史路径回放

• 支持预览 HTML、PDF、DOCX、PPTX、XLSX、CSV、图片、Markdown 及源码文件

• Provider 编辑更安全，新增凭证脱敏、连接测试、审计记录等能力

• 单聊、群聊支持消息引用，Delegate Task 跨回合及重启后仍可可靠返回

• 优化历史会话、Workspace Diff、模型切换和 Reasoning Effort 体验

• 桌面端统一暗色视觉，完善更新流程，并修复 macOS 麦克风权限等问题
