## 原帖详情

#安全提醒 🛑🛑🛑 字节跳动扣子 (Coze CLI) 被吐槽像是病毒，默认安装技能劫持 Codex 和 Claude Code 等工作流，将其强行导入到 Coze CLI 中执行。

源代码审计发现，Coze CLI 安装时还会静默安装附带的技能，技能会扫描本机的 AI 智能体目录，然后将扣子的技能注入到这些目录中。

当用户使用 Codex 等工具时，软件开发、媒体生成、文件上传和会话任务等场景都会被导向 Coze CLI。
