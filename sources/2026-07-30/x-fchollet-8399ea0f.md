Really interesting concept -- instead of optimizing against static benchmarks or internally generated reward models, agents are evaluated through real economic interactions. Using an external market as part of the reward signal changes the optimization problem in a fundamental way.

That doesn’t eliminate reward hacking, but it grounds learning in feedback generated outside the system itself. Whether this produces more capable agents over time is an interesting hypothesis.
