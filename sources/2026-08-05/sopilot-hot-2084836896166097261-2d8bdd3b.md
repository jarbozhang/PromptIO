## 原帖详情

Pika有意思，他们开始搞多模态模型的 Token Club，推出了一个会员服务叫 Pika API Club。

里面包含了几乎所有的图像、视频、LLM模型服务，而且都有不同程度的折扣。

比如 Seedance 2.0、MiniMax H3、可灵（Kling），还有 GPT-Image-2.0 等都有。

完全可以充了以后，打包个 Skills 给那个Codex或者其他 Agent 接入，以后就可以一键调用所有的这种视频和音频 API 模型
