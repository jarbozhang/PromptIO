经常用 Codex、Claude Code 做网页自动化？试试 ego-lite。

不是 Playwright 那种另开浏览器，而是你和 Agent 共用一个浏览器：各干各的，互不抢标签页。登录态、Cookie、扩展直接继承，不用反复登录。

每个 Agent 有独立 Spaces，支持并行跑多个任务。用 JS 调用，复杂任务最高快 2.5 倍，Token 更少。支持 Codex、Claude Code、Cursor 等。

目前 Mac 可用，Win/Linux 在规划。适合操作需要登录的后台、CRM、社媒等。
