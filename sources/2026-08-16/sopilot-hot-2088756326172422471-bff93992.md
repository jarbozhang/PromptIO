## 原帖详情

这就像我朋友问我，Infra是否觉得自己会被 Agent 取代。很遗憾我一直如此认为，不会。

Agent 是且仅仅是人类智力劳动的放大器，“顶尖工程师用头部 Agent 写出顶级代码，垃圾工程师用同一 Agent 写出灾难代码”。

就像我同事 BBuf，顶级的 kernel 专家，Claude 当然写 kernel 比他快，但是要为了什么 workload 写 kernel，大体的计划和方向是什么，仍旧是需要人类工程师来决定的。
