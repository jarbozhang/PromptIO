## 原帖详情

发现一个挺怪的现象：GPT-5.6 Sol 官方标称 1.05M context，Codex 也确实有 model_context_window 这个配置项。

我把它设成 1,050,000，甚至用 CLI 强制覆盖，重新开任务后运行时记录依然是 258,400。配置能正常解析，就是不生效。

看起来当前 Codex/ChatGPT 通道还是把窗口限制在约 272K，1.05M 只是 API 规格。订阅改 config 并不能白嫖 1M。
