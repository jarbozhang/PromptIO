我一开始其实没搞懂A社目的是啥，因为检测的是Claude Code 使用第三方provider，这有啥？

后来才意识到A社真聪明啊，通过修改系统提示词里日期格式，和A社自己的日志比对，就能精准的识别中转站IP和账号，A社只要你本地配置的第三方URL但是请求又打回到A社，那必然是中转站啊。从而可以批量封禁中转站。

同样很多公司不管是为了蒸馏还是使用Claude模型，肯定不能给每人发个账号吧，也其实用的都是自建中转站方案。即使后面是AWS，也能被精准识别。

最后因为是注入提示词，也没有任何的网络上传活动，不容易被发现。即使你企业里的claude code 是在内网环境下，只要模型请求最终打回A社，就会被发现。
