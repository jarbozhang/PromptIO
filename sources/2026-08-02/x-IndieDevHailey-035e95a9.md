腾讯开源了一套 Agent 长期记忆系统：TencentDB Agent Memory。

它会把对话、文档、代码和工作经验，整理成可检索的记忆。以后换会话、换 Agent，也不用反复喂背景和重新理解项目，需要什么再精准调用。

既能省 Token、减少重复沟通，也能让不同 Agent 继承同一套经验。

就是让 Agent 干过的活不白干，越用越懂你的项目。
