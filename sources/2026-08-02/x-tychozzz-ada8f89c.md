前阵子我淘宝上买的美区苹果 ID 不能用了，一直没办法更新 ChatGPT 的最新版本，而我常用的港区苹果 ID 下载不了 ChatGPT。

感觉还是得自己注册一个更靠谱。这两天我抽时间实测了一遍最新的 Apple ID 注册流程，过程中的坑还挺多的，给大家分享一下。

首先必须得把 VPN 梯子关掉，并且需要手动把电脑上的网页代理相关的配置全部关掉，否则一会出现“无法验证电子邮件地址”的错误。

除此之外，我建议最好连接手机热点、通过 iCloud 的官网完成注册。

注册过程中选择国家为美国，手机号可以直接填写 +86，不需要海外手机号。

如果你要注册香港、台湾、日本、新加坡的苹果 ID，也是相同的操作流程，非常简单。注册视频教程我放到评论区了。
