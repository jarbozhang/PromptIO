最近最划算的一笔钱，是每月 $10.90 的一台洛杉矶 VPS。

之前一直用机场。大部分时候没问题。但偶尔出问题就很烦人。。每隔几天卡一次，你分不清是模型慢、是 API 抽风，还是自己的线路。于是切节点、重试，手里那条思路就丢了。

这事儿放在 agent 上更要命。网页慢只是烦人。一个跑了 14 分钟的任务断在这儿，是整段作废，而且你不知道它停在哪一步。

后来买了 DMIT 的 https://t.co/S0UHPB2mZf.TINY，CN2 GIA。脚本用的 mack-a/v2ray-agent，协议定在 Trojan + TLS，纯粹是被 Surge 逼的：它不支持 VLESS/Reality，一圈下来能用的只剩 Trojan 和 VMess。顺手挂了个 Cloudflare 子域名签真证书，以后换 IP 只改一条 A 记录。

1 个小时装完，过程让 Claude Code 写成了 runbook，下一台基本是复制粘贴。

本来有台 CN2 GIA 的搬瓦工，忘了续费被关掉。绕一圈又回来了。

也可能只是我之前那家机场不行。但都花 $200 一个月了，卡在这 $11 上属实没必要。
