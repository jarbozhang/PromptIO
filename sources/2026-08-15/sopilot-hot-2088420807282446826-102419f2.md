🚨独家爆料：DeepSeek-V4-Pro疑似存在不同版本🔍

过去一天内，中国社区一直在流传一个非常离谱的说法：

DeepSeek V4 Pro 的 API 背后，可能藏着三个不同的模型。

有人发现，同样调用 deepseek-v4-pro，换 IP、重新开会话之后，模型会出现三种截然不同的「思维链指纹」。

一种大量出现 Let me，能力接近此前的 V4 Pro Preview；

一种经常以 The user wants me 开头，更像 V4 Flash；

还有一种大量使用 we，能力明显更强。

最诡异的是，第三种「神版 V4 Pro」，作者称自己是在 DeepSeek Harness Minimal 模式里抽出来的。

而且同一个会话一旦命中某种行为，后续基本会保持稳定。

于是社区开始怀疑：

DeepSeek 是不是偷偷在一个 API 后面路由了三个模型？

但我们继续顺着 DeepSeek Harness 的源码往下挖之后，事情出现了一个更有意思的解释。

fix(preset): align minimal agent with RL composition

意思非常直接：

让 Minimal Agent 与 RL 训练时使用的 Agent Composition 对齐。

DeepSeek 随附的工程文档甚至直接写道：

The minimal preset owns the complete RL agent composition

官方在里面明确规定，Minimal 要固定一整套东西：

极简 system prompt；

persistent Bash；

指定的 str_replace_editor；

RL 使用的 compaction policy；

并且禁止 Harness identity、Web 提示以及其他工具说明继续污染 system prompt。

换句话说：

DSH Minimal 很可能根本不是 Standard 的“阉割版”。

它真正的作用，是尽可能还原 DeepSeek 在训练 V4 Pro Agent RL 时，模型实际见过的环境。
