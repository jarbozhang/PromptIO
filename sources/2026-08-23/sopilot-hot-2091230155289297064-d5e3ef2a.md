## 原帖详情

🚨警告：Anthropic疑似暗改了Claude Code里的模型能力。

如果你这周感觉 Fable 5 突然变蠢了，可能真不是错觉。

有用户发现，Claude Code 2.1.237 之后，界面明明显示 Fable 5 正在跑 high effort，实际模型却自报自己的 reasoning effort 只有 10/100。

更离谱的是，10 这个数字之前对应的正是 low。

他一开始还以为是自己的代码和应用坏了，折腾了一下午，最后直接去抓实际请求，才发现问题可能出在 Claude Code / 服务端这边。

而且整个更新日志里，一个字都没提。

目前社区怀疑，Anthropic 可能正在对部分用户做 effort 的 A/B Test，或者调整了 high 对应的实际推理预算，所以不是所有人都会遇到。

这里需要指出：单纯问模型「你现在 reasoning effort 是多少」不能算实锤，模型完全可能胡说。

现在更值得看的，是后续有没有人抓到实际 API 请求参数，以及 Anthropic 会不会回应。

但如果你最近刚好有这种感觉：

Fable 5 还是那个 Fable 5，high 也还是写着 high，但写代码明显开始犯蠢。

那你可能不是一个人。

现在大家买 high，服务器到底给了多少 high，开始有点说不清了。

真服了，Codex砍额度，Claude Code砍智力。。。
