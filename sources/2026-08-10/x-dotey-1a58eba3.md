我在开发项目是，第一版本会先用 Claude Design 设计好 UI 原型/设计，打磨好后放到本地，配合 Baoyu-Design Skill 去维护，每次开发新功能前，不是先去实现功能，而是先修改本地的原型，原型修改确认好了后再去修改功能。

后来直接把规则放到了 Agents.md/claude.md 里面，只要说修改或者增加什么功能，默认会先帮我修改原型。所以到现在为止，原型和实际功能都是保持一致的。

这带来的好处是可以先低成本通过原型验证产品设计和 UI 设计。

另一个好处就是 Claude Design 产出物是 React 代码和结构化的 json 数据，通过 git diff 很清晰的能看到版本变更历史，功能确定了后，agent 参考diff结果代码实现会相对比较容易。
