开源大杀器：Anthropic 发布金融专属 Claude 全套工具链🔥

Anthropic 亲自下场开源「Claude for Financial Services」，把专为金融打造的智能代理、插件和真实数据连接器全部开放！

亮点一览：
- 12+ 完整 Agents：Pitch Agent 一键生成专业 Pitch Deck；Market Researcher 自动做行业+竞品分析；GL Reconciler 自动对账找问题；KYC Screener 智能筛查风险；还有财报审阅、模型构建、估值审阅等，覆盖投行、PE、研究全场景。
- 实用 Slash 命令：/comps、/dcf、/lbo 等，Excel 审计、PPT 检查秒完成。
- 11+ 真实数据连接器：直连 FactSet、PitchBook、LSEG 等，实时拉数据，告别手动复制。

支持一键安装、API 自动化，深度集成 Microsoft 365，完全开源 Apache 2.0，可随意定制。
