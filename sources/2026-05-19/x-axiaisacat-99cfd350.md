AI 做游戏，终于不是只会出概念图了。

`Agent Game Forge` 是一个本地优先的 2D 游戏 IDE：接 Codex CLI 或 Claude Code，让 Agent 生成精灵图、视差背景、碰撞框、陷阱、道具和关卡布局。

你还能在可视化编辑器里拖拽微调，然后直接 Play。

默认导出 vanilla JS + Canvas，推到 GitHub Pages 就能跑。Godot / Unity 在路线图。

AI coding agent 最该落地的地方，可能就是游戏原型。
