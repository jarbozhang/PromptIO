装上这个插件之后，Claude Code 的使用体验完全不一样了。

Anthropic  quietly 推出了一款官方插件，名字叫 claude-code-setup，直接把 Claude Code 从“还不错”升级成了真正能用的 AI 开发环境。

它会自动扫描你的项目，然后给出对应的推荐。

包括各种 hooks、skills、MCP 服务、子代理，还有自动化配置。

接着一步步帮你把所有东西都配置到位。

现在大部分人都还在纯原生使用 Claude Code。

这也是他们觉得用起来很乱、不顺手的原因。

它真正的威力，其实体现在配套的整个生态上。

安装指令很简单：

/plugin install claude-code-setup@claude-plugins-official

建议先收藏起来，免得之后想用的时候找不到。
