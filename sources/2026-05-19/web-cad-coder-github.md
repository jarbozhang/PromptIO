CAD-Coder generates CAD code from image input. The README describes it as a fine-tuned open-source vision-language foundation model that outputs CadQuery Python code.

Key facts from README:

- The GenCAD-Code dataset contains 163k image and CadQuery Python script pairs.
- The trained CAD-Coder model is available on Hugging Face.
- Inference generates model responses, then runs CadQuery Python scripts in a separate CAD environment to create the CAD output.
- The setup currently requires separate LLaVA and cad_iou environments because of dependency conflicts.
- The repository links to a paper, dataset, and inference instructions.
