Agent Game Forge is an open-source desktop IDE for building 2D games with an AI coding agent. The README describes it as local-first and bring-your-own-agent: Codex CLI or Claude Code can drive the project, and users can bring their own image generation provider or use Codex CLI image generation.

Key facts from README:

- Current default output is vanilla JavaScript plus Canvas, designed to run in any browser.
- Godot 4 and Unity engine targets are on the roadmap.
- The workflow includes sprites, parallax backgrounds, physics, hazards, pickups, scene layouts, and a visual editor for drag-tweaking agent output.
- Quick start requires Node 20+, npm 10+, and Codex CLI or Claude Code.
- Local services launch a daemon on localhost:7621 and web UI on localhost:7620.
- The settings panel exposes agent choice, API keys, and image generation defaults.
- The README says project files stay on local disk and keys stay on the user's machine.
