之前分享过Taste-Skill，让 AI 生成的 UI 不再一眼看起来像 AI 生成。

然后我又看到了跟它比较类似的一个工具：Hallmark，是一个 AI coding assistant 的设计 skill。

安装后，它会给 Claude Code / Cursor / Codex 一套非常明确的设计规则：如何选结构、如何搭配字体、如何限制颜色、如何避免模板化布局、如何审计 AI slop。

简单说，Hallmark 是一个面向网页设计的 AI 分析工具。

给它一个网站，它会从视觉设计、排版、布局、配色、组件、交互感受等角度，分析这个页面的优点和问题，关注的是页面的“观感”和“设计质量”。
