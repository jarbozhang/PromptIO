亿万富翁 Jack Dorsey 开源的神级项目 Bitchat ，简直是现代黑科技！😱

完全不需要互联网，用蓝牙就能收发 #Bitcoin + 聊天！！！

- 飞机上、演唱会、地铁、荒郊野外、断网灾区……信号全无也能实时通讯 + 转账

- 蓝牙 Mesh 多跳网络：最高7跳自动中继，几百米范围瞬间形成地下通讯网

- 内置 Cashu eCash：真正离线比特币转账，对方手机都不用联网就能收到

- Dual Transport 双引擎：附近蓝牙极致隐蔽，远距离自动切换 Nostr 全球中继

- 极致反监控设计：无账号、无手机号、无任何持久身份，每次换地方就是全新临时ID，Noise Protocol + NIP-17 双重加密

- 地理位置频道：自动生成 block neighborhood city 小区群、城市群，位置即频道

- IRC 黑暗风格：/slap /msg /who 命令全在，一键三连擦除所有数据，紧急情况瞬间蒸发

完全开源 + Public Domain（公共领域），想改就改！
GitHub 25.8k+ Stars 还在狂飙

这玩意儿要是彻底火了……
以后真出大事、断网、被监控的时候，别人都成了哑巴，你却能悄无声息地在黑暗中聊天、转账、联系同伴……😨
