82.5k stars，18个技能，专治AI写代码翻车！

TypeScript 大神 Matt Pocock（前 Vercel 工程师，教 TS 讲得最清楚的那个人）把他每天用 Claude 的真实工作方法开源了！

痛点就四个：
沟通不对齐 → 产出不是你想要的
术语不统一 → 输出冗长得像废话
缺反馈循环 → 代码永远不工作
代码熵增 → 越来越乱

他的技能库每个都精准拆解一个痛点：
/grill-me：深度拷问需求，像审讯官一样把你每个想法问清楚
/tdd：强制红绿重构，先写失败测试再写代码，稳稳的
/caveman：把 token 消耗砍 75%，聊天超简洁
/improve-codebase-architecture：定期给代码库做保养，越写越干净

背后是《The Pragmatic Programmer》+ DDD + XP 几十年工程经验的提炼。

一行安装：
npx skills@latest add mattpocock/skills

选一下技能，跑个 setup 配置就行。
推荐先试 /grill-with-docs，你会发现 AI 终于懂你在说什么了。
