## 原帖详情

昨天写 DeepSeek Harness 负责人崔添翼 @tianyi 履历那条帖子后，当事人自己来评论区纠正了我一个判断。

我原本把量化系统和 Agent Harness 做了一些类比，他回复说：

「其实量化系统和 Agent 没啥特别相似相像的，只是同样是潜在很复杂的软件系统而已。」

后来想了下，这句话确实更准确。

最近看 Harness 这一层，很多关键问题其实都很「传统」：状态怎么管理、副作用怎么处理、依赖怎么维护、执行怎么追踪、失败后怎么恢复。

模型可以不断变强，但要让 Agent 真正长时间、可靠地运行，最后还是绕不开这些复杂的软件系统问题。

所以 DeepSeek 这次把 Harness 和 Cordis 放出来后，我现在想继续看的也有这一层：

当 Agent 开始跑更长的任务，系统工程会不会重新成为最核心的竞争力之一？
