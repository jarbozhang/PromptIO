## 原帖详情

🚨突发，Shopify CEO Tobi Lütke 公开向 Anthropic 施压！

Tobi称 如果 Claude Code 继续拒绝读取 AGENTS.md 和 .agents/skills，他正在考虑直接在 Shopify 内部禁用 Claude Code。

Tobi 给出的原因很现实。

现在一个工程团队里，大家可能同时用 Codex、Cursor、Claude Code 等不同 Coding Agent。

越来越多工具开始读取统一的 AGENTS.md，团队可以把项目规范、测试方式、开发约定和 Agent 指令放在一个地方。

但 Claude Code 目前主要依赖自己的 CLAUDE.md 和 .claude/skills。

结果就是，同一个代码仓库，不同 Agent 可能读到两套完全不同的规则。

Tobi 把这种情况直接称为 split brain（脑裂）。

对于个人开发者，多维护一个文件可能没什么。

但对 Shopify 这种大量工程师同时使用 AI Coding 工具的公司，这意味着团队需要长期同步两套 Agent Context，一旦不同步，Agent 的行为就可能出现偏差。

所以这件事看起来只是一个 Markdown 文件之争，背后其实是 Coding Agent 正在进入企业之后必然遇到的问题。

Agent 的项目配置、Skills 和 Context，到底应该属于某一家模型公司，还是成为所有 Agent 都能读取的公共标准？

现在 Shopify 已经开始用公司级采购权给出自己的答案了。

Claude Code 模型再强，企业也不会愿意为了一个工具长期维护一套平行的工程规范。

PS：有没有人写个插件自动把claude.md转成agents.md
