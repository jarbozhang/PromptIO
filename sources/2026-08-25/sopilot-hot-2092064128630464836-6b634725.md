## 原帖详情

🚨突发：Codex 被曝存在严重Bug。

今天早上陆续收到身边多位朋友的反馈，他们的 Codex 都出现了 Session 历史记录丢失的问题，而且 Mac、Windows 两端都有人中招。

具体表现包括：

- 最近几轮甚至大段历史记录直接消失
- 反复回到之前的历史对话
- 消失的记录过几个小时甚至一天后可能重新出现
- 刷新之后又可能再次消失
- 部分 Mac 用户还遇到了聊天窗口闪退，客户端几乎无法正常使用

从目前的反馈来看，数据似乎并没有真的被删除，更像是历史记录的同步 / 索引 / 加载出现异常，导致 Session 间歇性读取不到最新状态。

这对 Coding Agent 来说影响其实挺严重。

Codex 很多任务本身就依赖长时间 Session 连续工作，一旦中间几十轮 Context 突然消失，Agent 就可能直接回到几个小时前的状态，整个工作流都会被打断。

如果你这两天发现 Codex 突然丢消息，大概率不是个例。

建议暂时不要把关键开发进度只留在 Codex Session 里，重要修改及时 commit。

PS：也可以和我一样用 @lobehub  来控制Codex的CLI，就不会遇到这个问题
