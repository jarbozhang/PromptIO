## 原帖详情

最近做了一些 @pidotdev  package：
- pi-monitor，减少噪音的 monitor 工具，方便长时间做一些 loop；
- pi-memory，harness 层的记忆工具，防止信息偏移；
- pi-utils，一些实用工具的集合，比如让 pi 知道同目录有哪些运行的 session；
- pi-btw，类似 claude 的 btw，但是支持多轮对话；
- pi-vision，给文本模型增加多模态能力；
- pi-recap，类似 claude 的 recap；
- pi-agent-teams，支持 heartbeat 和使用 prompt 设置模型的 agent teams，目前已经实现自主调度多个 teammate 分工协同，并且由于 pi 可以自主注入提示词，所以设定会比 claude / codex 更激进；
- pi-git-agent，git-agent 的套壳，因为在 harness 层所有更稳定。
