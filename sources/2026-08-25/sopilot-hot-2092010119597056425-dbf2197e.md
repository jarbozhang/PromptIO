## 原帖详情

Codex 产品负责人 Tibo 第一次描绘了他理想中的Agent：

真正的 AI Agent，不应该还需要用户自己维护 Skills、Memory 和 Sub-agents。

他提到，现在很多 Codex 和其他 Coding Agent 的高级用户，已经习惯自己管理 skill files、配置 memory、组织 sub-agents。

但这些东西本质上都很难长期维护。

Skills 会越来越多，Memory 不可能永远记住所有东西，Sub-agents 多了以后，你甚至还得自己管理一张 Agent 网络。

这其实是在把本来应该由 AI 解决的问题，重新丢回给人。

@thsottiaux  认为，真正理想的 Agent 应该是它深度理解你，知道你的目标、每天在做什么，也理解你的团队。

然后主动做事、主动帮你推进工作，同时尽可能不让你感受到背后的 Skills、Memory、Sub-agent 这些复杂结构。

另一个很有意思的判断是，未来限制 Agent 的可能反而会是我们的电脑。

今天的 Laptop 是按照人类的工作速度设计的，人一次操作几个应用、敲一点代码。

但未来一个足够强的模型，可能同时处理 100 个打开的应用 都没有问题。

到那个时候，Agent 需要的计算和资源，已经远远超过一台个人电脑能够提供的范围。

Agent 的终局不是一个更复杂的 Coding Tool，而是一套你几乎感知不到内部结构、却一直在替你工作的计算系统。
