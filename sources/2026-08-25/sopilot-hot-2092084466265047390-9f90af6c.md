## 原帖详情

独立游戏开发者的神器来了

发现一个能直接生成完整游戏的开源项目，在 GitHub 已经斩获 5k+star

它叫 Godogen，告诉它你要什么类型的游戏，它会自动完成架构设计、美术生成、代码编写、引擎截图和视觉质检的全流程，最终交付一个结构清晰、可直接运行的完整游戏项目

内置视觉质检循环，会从运行中的游戏引擎捕获截图，自主识别并修复渲染问题，不用人工盯着改

支持 Godot 4、Bevy、Babylon.js 三个主流引擎

通过 Claude Code 或 Codex 驱动，包含 850 多个 GDScript 类定制的语言参考和懒加载 API 文档，普通硬件就能跑
