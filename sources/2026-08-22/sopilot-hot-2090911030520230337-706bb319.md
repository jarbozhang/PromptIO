## 原帖详情

📒建议收藏：Anthropic 的工程师 Thariq Shihipar，刚刚分享了一个他们Claude Code团队内部最近经常使用的 Skill：ELI5。

这个 Skill 干的事情很简单：

输入/eli5 <你想搞懂的东西>

然后Claude 会假设你对这个话题完全不了解，然后生成一个带大量图片、流程图和少量文字的 HTML 页面，直接把它给你讲明白。

@trq212  自己经常这么用：

/eli5 这个模块是怎么工作的

/eli5 我们为什么做这个技术权衡

/eli5 是什么导致了这次事故

比如一个原本要看代码、文档才能搞明白的系统工作流程，Claude 直接给画成了一张完整的可视化教程。

我感觉这个 Skill 对读陌生代码库特别狠。

一个项目到底怎么跑的、某个模块为什么这么设计、一次线上事故是怎么发生的，都可以直接让 Claude 重新画一遍。

甚至拿来做新人 onboarding 都很合适。

Thariq表示，Anthropic 目前还在讨论，要不要把 ELI5 做成官方插件。

现在社区版已经可以直接安装：

claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install eli5@claude-community

以后看不懂的东西，可能真不用硬啃了。

直接/eli5 给你画明白🫡
