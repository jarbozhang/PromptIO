## 原帖详情

WOW，Vercel 开始给网站做 Agent SEO 了！

刚刚，Vercel Developers 推出了一个叫 https://t.co/WH28yFaQ17 的工具，专门测试你的网站到底有多适合被 AI Agent 使用。

它会对网站跑 100 多项检查，最后给出一个 Agent Readiness Score。

目前官方展示的一批网站里：

Ora：98 / 100
Vercel：90 / 100
Stripe：80 / 100
OpenAI：72 / 100
GitHub：72 / 100
Linear：64 / 100
Anthropic：62 / 100

检查范围包括 Agent 能不能发现和读取网页、网站有没有结构化接口，以及 API、OAuth、MCP、GraphQL 等能力。

最实用的是，检查出问题以后，它可以直接生成修复 Prompt，丢给 Coding Agent 改。

甚至还做了 CLI：
npx is-agentic <domain>

以及公开 API 和 MCP Server。

以前做网站天天盯 SEO、Lighthouse、移动端适配。

现在 Vercel 又塞进来一个新指标：

你的网站，AI 到底会不会用。

如果以后搜索、购物、订票、SaaS 操作越来越多直接由 Agent 完成，网站可能真的得开始专门给机器人做 UX 了。
