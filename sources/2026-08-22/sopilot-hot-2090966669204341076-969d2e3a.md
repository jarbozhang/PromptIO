## 原帖详情

卧槽！同花顺官方下场了——A 股数据服务正式开源，一个 API Key 全搞定，AI Agent、量化、开发全支持！

以前做 A 股量化，数据来源永远是块心病：爬虫怕封、第三方数据贵、Tushare 免费额度不够用。

现在同花顺自己把数据服务开源了，实时行情、财务报表、估值、涨跌停池、龙虎榜、集合竞价——全市场数据一个 Key 打通。

覆盖的能力很全：

1️⃣ 实时行情、历史 K 线、财务报表、估值快照
2️⃣ 集合竞价、涨停/炸板、龙虎榜、热榜等特色数据
3️⃣ 指数、板块、公募基金资料与净值
4️⃣ 支持 REST API、Python SDK、CLI、本地 DuckDB
5️⃣ 重点：原生支持 MCP + Agent Skill，Claude / Cursor 直接用自然语言查数

最狠的是对 AI Agent 的适配。npx skills add 一条命令装 Skill，之后你直接跟 Claude 说"查询贵州茅台最新行情并分析均线趋势"，它自己就知道该调 API 还是 MCP 还是 CLI。

A 股量化党最大的痛点——数据——这次被官方自己解决了。收藏它，你会感谢我的。
