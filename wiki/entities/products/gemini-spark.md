# Gemini Spark

[[google|Google]] 在 I/O 2026 上把原 Gemini app 升级而成的 24/7 常驻 agent 形态产品，第一站直接塞进 [[gmail|Gmail]]，做"邮箱常驻 agent"。

## 定位

1. **24/7 常驻 agent** — 不再是对话式助理，而是后台持续工作的 always-on agent
2. **Gmail 第一站** — 与 [[gmail|Gmail]] 深度集成，把邮箱当成第一类 agent 工作场景
3. **Gemini 品牌下的 agent 子线** — 与 [[gemini-3-5-flash|Gemini 3.5 Flash]]"模型转 agents"的路线呼应

## 关键事实

- **维护方** — [[google|Google]]
- **前身** — Gemini app（消费端聊天形态）
- **发布** — 2026-05-20 I/O 2026
- **首发场景** — [[gmail|Gmail]] 24/7 agent
