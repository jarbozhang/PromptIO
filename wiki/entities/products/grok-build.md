# Grok Build 0.1

[[xai|xAI]] 2026-05-21 发布的编程专用模型，[[grok|Grok]] 系列第一个明确以编程为定位的档位。

## 关键参数

- **上下文长度** — 256,000 tokens
- **定价** — $1 / 1M input tokens，$2 / 1M output tokens
- **定位** — 编程专用，对标 [[codex|Codex]] / [[claude-code|Claude Code]] 后端模型

## 为什么重要

价格只有 Codex 的 1/5，把 AI 编程价格战的底部又拉低一档。xAI 通过这款模型从对话模型阵营切入编程模型阵营，给 Cursor / Windsurf / Trae 类前端工具提供了一个明显便宜的 backend 选项。中文 AI 编程读者首次拿到"换个 backend 就便宜 5 倍"的具体方案。

## 近期关键动态

- **发布上线** (2026-05-21) — 256K context + $1/$2 per 1M tokens 首发
