# Stainless

SDK、CLI、文档和 MCP server 自动生成平台。2026-05 被 [[anthropic|Anthropic]] 收购。

## 定位

Stainless 的价值不在终端用户界面，而在把 API spec 转成稳定 SDK、CLI、文档和 agent 可调用的工具接口。

## 近期动态

- **Anthropic 收购 Stainless** (2026-05-19 入题) — Anthropic 官方称 Stainless 从 API 早期开始支撑每一个 Anthropic SDK。收购后 Stainless 更像 Claude 平台的 SDK/MCP 工具生产线。
