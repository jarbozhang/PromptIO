# Hermes Agent

[[nousresearch|NousResearch]] 维护的开源持久成长 agent，GitHub 12 万星。强调"和你一起长大"的长期记忆 / 持续成长路线，2026-04-28 接入 [[openclaw-ecosystem|openclaw 生态]]，从独立 agent 走向"宿主 + agent"组合形态。

## 定位

1. **持久成长 agent** — 长期记忆 / 持续学习是核心卖点，不是一次性对话也不是单 session agent
2. **12 万星量级** — 开源 agent 品类头部
3. **接入 openclaw 生态** — 与 [[openclaw\|openclaw]] 宿主结合，复用 openclaw 365k 星跨平台分发 + Hermes Agent 12 万星持久记忆能力

## 关键事实

- **12 万 GitHub 星** — 持久成长 agent 类目头部
