# CAD-Coder

基于 GenCAD-Code 数据集训练的图像到 CadQuery Python code 生成模型。

## 关键事实

- GenCAD-Code 数据集包含 16.3 万组图像与 CadQuery Python script pairs
- 模型输出 CadQuery Python code
- 推理后需要在 CAD 环境里执行脚本生成 CAD 输出
