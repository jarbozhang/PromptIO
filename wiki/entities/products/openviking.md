# OpenViking

[[volcengine|火山引擎]]于 2026-05-20 开源的 agent 文件系统项目，目标是给 AI agent 装一个"可读可写可索引"的文件系统当长期大脑，并显式声明专为 [[openclaw|openclaw]] 优化。

## 定位

1. **agent 文件系统范式** — 把 agent 长期记忆 / 中间产物 / 知识库统一管理在一套文件系统抽象下
2. **专为 openclaw 优化** — 与 [[openclaw|openclaw]] 365k+ 星跨平台 agent 宿主深度协同，进入 [[openclaw-ecosystem|openclaw 生态]]
3. **国产 + 开源** — 字节火山引擎开源，对标海外 agent memory / agent file system 方案

## 关键事实

- **发布方** — [[volcengine|火山引擎]] / [[bytedance|字节跳动]]
- **开源** — 2026-05-20 公开仓库
- **生态合作** — 与 [[openclaw|openclaw]] 形成"宿主 + agent 文件系统"组合
