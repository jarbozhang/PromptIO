# Agent Game Forge

本地优先的 2D 游戏 IDE，接入 Codex CLI 或 Claude Code，让 agent 生成可玩游戏原型。

## 定位

Agent Game Forge 不是只生成概念图，而是让 agent 生成精灵图、背景、碰撞框、陷阱、道具、关卡布局和基础逻辑，再由人用可视化编辑器微调。

## 关键特性

- 本地优先，项目文件留在本地磁盘
- 支持 Codex CLI / Claude Code
- 默认导出 vanilla JS + Canvas
- Godot / Unity 在路线图
