# VibeVoice

Microsoft 2026-04-28 开源的语音 AI 项目，自我标榜 "Frontier Voice AI"，GitHub 一天涨 757 颗星。是 Microsoft 第一次以"前沿"姿态进入 TTS / 语音 AI 主线，对标 OpenAI Voice / ElevenLabs / 国产 VoxCPM 阵营。

## 定位

1. **TTS / 语音生成主线** — 以 "Frontier Voice AI" 自我定位
2. **Microsoft 自研语音 AI** — Microsoft 在语音方向第一次以独立开源项目形式发牌
3. **多模态边界扩张** — 与现有 [[multimodal\|多模态]] 主线交叉，向语音侧延伸

## 关键事实

- **2026-04-28** — 项目开源放出，GitHub 一日 757 星
- **标语** — "Frontier Voice AI"，对标行业前沿语音模型
- **维护方** — [[microsoft\|Microsoft]]
