# Sana

NVlabs/Sana 是 NVIDIA 开源的高效图像和视频生成框架。2026-05-18 入题时，补充源记录其 README 主张 4K 生图、4-bit 量化、8GB 显存、SANA-Sprint、SANA-Video、LongSANA 和 SANA-WM。

## 定位

Sana 面向高分辨率图像、视频和 world model 的效率路线。对创作者来说，它的关键不是替代审美，而是降低本地草图和视频探索的显存与迭代成本。
