# Qwen3.7 Max

[[alibaba|阿里]] 通义千问家族新一代旗舰模型，2026-05-21 上 [[openrouter|OpenRouter]] 首发，定位 agent 工作流，1M context + 白菜价。

## 关键参数

- **上下文长度** — 1,000,000 tokens（100 万）
- **定价** — $2.5 / 1M input tokens，$7.5 / 1M output tokens
- **定位** — agent 优先（不是 chat 优先），长上下文调用 + 工具链友好
- **出海渠道** — [[openrouter|OpenRouter]] 首发

## 为什么重要

国产万亿档第一次走出"对标 chat 模型"路径，明确以 agent 工作流为核心定位。1M context + $2.5/$7.5 价位让国产万亿档在"长上下文 + 低成本 + agent 优先"三个维度同时形成压制，给中文 agent 开发者直接换上 Qwen3.7 Max 跑长任务提供新选项。

## 近期关键动态

- **出海首发 OpenRouter** (2026-05-21) — 一上来就走 OpenRouter，加固阿里"国产模型出海首选渠道"路径
