# hydropix translate

hydropix 开源的命令行工具，用 LLM 翻译整本书。核心卖点是断点续传 + 不限文件大小 + 兼容多种后端（[[openrouter\|OpenRouter]] / Ollama / 主流 LLM API），国内开发者可直接接 Ollama 走本地推理路线。

## 定位

1. **整本书翻译工具** — 非段落级，可吃整本电子书
2. **断点续传** — 长任务中途失败可恢复，不重头再来
3. **多后端兼容** — OpenRouter / Ollama / 主流 LLM API
4. **国内可用** — 接 Ollama 本地推理，避开境外 API 调用门槛
