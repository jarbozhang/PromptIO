# FinceptTerminal

开源金融数据终端，定位是替代彭博终端（Bloomberg Terminal，订阅约 25000 美元/年）。2026-04-22 一天涨 2548 个 GitHub stars，为当日开源生态焦点之一。

## 定位

彭博终端是金融从业者的标配但定价高，长期没有开源平替能做到体验接近。FinceptTerminal 试图以开源形式提供金融数据 + 终端 UI + 扩展能力，短期内更像个"开源社区版彭博参考实现"，离生产可用仍有差距，但是国内量化/投研团队搭建私有终端的起点。
