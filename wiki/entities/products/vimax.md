# ViMax

[[hkuds|港大 HKUDS]] 开源的多 agent 视频生成框架，2026-05-21 一夜出圈，国产学界视频 agent 首次入题。

## 定位

ViMax 把视频生成拆成"导演 / 编剧 / 分镜 / 制作"多个 agent 协作流程，给一个 prompt 自动生成完整视频。和单模型一次出片（Veo / Seedance / Runway）的路径不同，ViMax 是 agent 协作范式在 AI 视频上的首次落地。

## 关键能力

- **多 agent 协作** — 导演 agent / 编剧 agent / 分镜 agent / 制作 agent 分工
- **一键当导演** — 一个 prompt 自动跑完整视频生产流程
- **开源** — 完整复现路径，中文开发者可直接跑

## 为什么重要

国产学界 agent 矩阵 + AI 视频赛道交叉点。给中文创作者一个明确的"自己跑视频 agent"开源方案，不依赖闭源 SaaS（HeyGen / Runway）。和 [[seedance-2-0|Seedance 2.0]] 长视频成本账叙事拼起来，AI 视频从"单条 demo"进入"多 agent 流程化生产"。
