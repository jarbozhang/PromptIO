# Gemini API

Google Gemini 服务端 API，面向开发者提供 Gemini 模型调用、长任务、文件和工具相关能力。

## 近期动态

- **Flex / Priority inference tiers** (2026-05-19 入题) — Google 新增 Flex 和 Priority 两个推理服务档，用来把低成本后台任务和低延迟在线请求拆开。
- **Webhooks for long-running jobs** (2026-05-19 入题) — Gemini API 支持事件驱动 Webhooks，长任务完成后推送通知，减少轮询。
