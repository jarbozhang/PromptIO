# OpenSRE

Tracer-Cloud 2026-04-25 开源的 AI Agent for SRE 框架，把 AI Agent 正式带进 SRE 运维这条赛道。是 PromptIO 知识库首次覆盖的 **DevOps/SRE 运维** 主题代表项目。

## 定位

1. **AI Agent for SRE** — 故障定位 / 告警分诊 / 根因分析 / 自动修复建议
2. **开源** — 对照传统 SRE 商业工具（PagerDuty / Datadog / New Relic）
3. **可嵌入既有运维栈** — 与现有监控/告警系统协同

## 注意

OpenSRE 的意义不在于"另一个开源 Agent 框架"，而在于把 SRE 这个长期被传统 SaaS（PagerDuty/Datadog）占据的赛道首次开放出 AI Agent 化的开源选项。后续跟踪点：1) 国产 SRE 团队（字节/阿里/腾讯）是否跟进类似开源；2) 与 Claude Code / Codex 等编程 Agent 的协同（事故 → 修 PR）；3) 实战团队的复盘案例。
