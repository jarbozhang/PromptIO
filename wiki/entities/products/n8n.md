# n8n

工作流自动化平台，支持可视化编排、400+ integrations、自托管和 AI 节点。适合把模型调用放进可审计的业务流程里，而不是让 agent 自由发挥。

## 定位

1. **自动化工作流平台** — 触发器、数据整理、模型调用和通知输出在同一条 workflow 里编排
2. **AI 工作流落地层** — 比纯 agent 框架更适合把重复任务做成可验收交付
3. **MCP / API 连接器** — 可作为 agent 工具和传统系统之间的连接层
