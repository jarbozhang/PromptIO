# Dograh

dograh-hq/dograh 是开源自托管语音 agent 平台。2026-05-18 入题时，仓库约 1670 stars、370 forks，BSD-2 License，README 提供一条 Docker 命令启动本地 Web Call 测试。

## 定位

Dograh 面向语音客服、线索筛选、回访和问卷场景。它的价值在于先自托管验证对话流程，再决定是否接入真实电话和按分钟计费的语音 SaaS。
