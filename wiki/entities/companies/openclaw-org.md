# openclaw

openclaw 项目方/组织，TypeScript 圈最大跨平台个人 AI 助手 [[openclaw|openclaw]] 的维护方，同步维护 clawhub / clawdbot / moltbot 等周边项目，是 [[openclaw-ecosystem|openclaw 生态]] 的核心组织节点。

## 关键产品线

- **[[openclaw|openclaw]]** — TypeScript 圈最大跨平台个人 AI 助手，GitHub 365k 星
- **clawhub** — openclaw 生态的扩展/插件集散点（4/23 [[last30days-skill|Last30Days Skill]] 文章中首次被提及）
- **clawdbot** — openclaw 生态自动化机器人组件
- **moltbot** — openclaw 生态实验性 agent 组件

## 近期动态

- **365k 星里程碑 + 4 月安全事件** (2026-04-28) — openclaw 站上 TypeScript 圈个人 AI 助手最大盘的同时，4 月发生扩展面 / 供应链相关安全事件，组织侧需要面对"高扩展性 vs 安全边界"长期取舍
