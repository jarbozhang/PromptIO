# HKUDS / 港大数据科学组

香港大学 Data Science Lab（HKUDS），近一年在 GitHub 上密集开源 agent 项目，已成为国产学界 agent 产出最强的研究组之一。

## 为什么重要

HKUDS 走的是"工程级开源 + 跑得起来 demo"路线，发布节奏快、文档完整、能直接被中文开发者复现。AI-Trader（5/10 入题）和 ViMax（5/21 入题）两条线已经形成"金融 agent + 视频 agent"的学界 agent 矩阵，对照硅谷学界（Stanford NLP / CMU LTI）路径是中文社区难得的可比锚点。

## 关键开源产品

- **[[vimax|ViMax]]** — 2026-05-21 出圈，多 agent 视频生成（导演 / 编剧 / 分镜 / 制作），国产学界视频 agent 首次
- **AI-Trader** — 100% 全自动 agent-native 量化交易，2026-05-10 已收 646 星

## 近期关键动态

- **ViMax 视频 agent 一夜出圈** (2026-05-21) — 一个 prompt 当导演，编剧 / 分镜 / 制作全自动跑通，HKUDS 把视频生成做成多 agent 协作范式
- **AI-Trader 646 星** (2026-05-10) — 100% 全自动 agent-native 量化交易，SKILL.md 协议
