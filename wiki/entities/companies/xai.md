# xAI

[[elon-musk|Elon Musk]] 旗下 AI 公司，[[grok|Grok]] 系列模型开发方。2026-05-21 推出 [[grok-build|Grok Build 0.1]] 编程模型，正式把战线扩到 AI 编程价格战。

## 为什么重要

xAI 是 [[openai|OpenAI]] / [[anthropic|Anthropic]] 之外少数能持续推出前沿模型的厂商之一，且在算力侧拥有 Colossus 集群（自有 GPU 数 22 万+）。2026 年 xAI 战略明显从纯对话模型扩张到编程 / agent / 长上下文领域，价格策略也明显走"低于头部"的攻势路线。

## 关键产品线

- **[[grok|Grok]]** — 旗舰对话模型系列，4.3 已上 OpenRouter 1M context
- **[[grok-build|Grok Build 0.1]]** — 2026-05-21 发布的编程专用模型，256K context，$1/$2 per 1M tokens
- **Colossus 1 / 2** — 自有算力集群，Colossus 1 已转手租给 Anthropic

## 近期关键动态

- **Grok Build 0.1 编程模型发布** (2026-05-21) — 256K context，价格只有 [[codex|Codex]] 的 1/5，xAI 战线扩到 AI 编程
- **Grok 4.3 上 OpenRouter 1M context** (2026-05-01) — xAI 长上下文出海，瞄准 agent 开发者
- **Musk 当庭承认蒸馏 OpenAI 模型** (2026-05-01) — Grok 训练数据来源被庭审记录捅穿
- **Anthropic 租 Colossus 1 算力** (2026-05-10) — Musk 把 xAI 旧算力转租 Anthropic，被解读为 xAI 训练已经搬到 Colossus 2
