# 阿里 / Alibaba

国产 AI 生态核心厂商之一，自研通义千问 Qwen 系列 + 钉钉 AI + 蚂蚁生态共同构成阿里 AI 矩阵。2026-04-27 Qwen3.6 全家桶 5 个模型一口气上 OpenRouter，从 27B Dense 到 1T Max Preview 全档位铺出海，把 Qwen 从单点旗舰扩展到全栈出海。

## 关键产品线

- **通义千问 (Qwen) 全家桶** — 见 [[qwen-family|Qwen Family]]，4/27 5 个模型一口气上 OpenRouter
- **[[qwen-3-6-27b|Qwen3.6-27B]]** — 2026-04-24 发布，27B Dense 旗舰级编程能力，本地显卡党首选
- **Qwen 1T Max Preview** — 4/27 全家桶里的最大档万亿模型，对标 GPT-5.5/Claude 旗舰
- **Qwen 多模态档** — Vision/Video，多模态 + 编程 + 通用全档位铺开
- **Qwen3.6-35B** — 此前主力版本，Simon Willison 笔记本实测胜过 Claude Opus 4.7
- **钉钉** — AI 会议纪要 / 文档自动化
- **Datawhale self-llm** — 教程生态（独立组织，但与 Qwen 紧密联动）

## 近期动态

- **Qwen3.7 Max 上 OpenRouter，1M context + agent 优先 + 白菜价** (2026-05-21) — 阿里 [[qwen-3-7-max|Qwen3.7 Max]] 直接走出海首发，100 万 token 上下文 + $2.5/$7.5 per 1M tokens，定位 agent 工作流，国产万亿档进入"长 context + agent + 低价"新阶段
- **Qwen3.6 全家桶 5 个模型上 OpenRouter** (2026-04-27) — 27B Dense / Coder / Vision / Video / 1T Max Preview 一次性铺出海，国产模型从单点出海升级到全档位出海，OpenRouter 国产模型生态进一步压实
- **Qwen3.6-27B 编程模型发布** (2026-04-24) — 27B Dense 参数量做出旗舰级编程能力，本地显卡党有福，对标 DeepSeek 等国产 MoE 路线
- **Qwen3.6-35B 本地图片生成测试** (2026-04-18) — Simon Willison 笔记本实测超 Claude Opus 4.7
- **钉钉禁员工写文档靠 AI 整理** (2026-04-21) — 阿里 AI 办公场景实际落地话术
