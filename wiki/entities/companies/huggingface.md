# HuggingFace

全球最大的开源 AI 模型与数据集托管社区，AI 工程基础设施代表性公司。Transformers / Datasets / Hub / Spaces 几乎是开源 AI 工作流的事实标准。

## 关键产品线

- **Hub** — 模型 / 数据集 / Space（在线 Demo）三合一托管
- **Transformers / Datasets / Diffusers** — 主流开源模型工程库
- **Inference Endpoints / TGI** — 推理服务
- **AutoTrain** — 无代码微调
- **[[ml-intern\|ml-intern]]** — 2026-04-25 开源的自动读 paper 训模型一条龙 Agent
- **Smol Agents / smol-course** — 小型 Agent 框架与教程

## 与 PromptIO 内容相关

- 国产 AI 厂商（DeepSeek / Qwen / MiMo / Kimi）的全球分发渠道
- 中文社区"白嫖"路线之一（免费 Hub + 免费 Space）
- 开源训练 / 微调路径的事实标准上游
- [[unsloth\|Unsloth]] / [[llama-cpp\|llama.cpp]] 等本地推理与训练工具的上游模型源

## 近期动态

- **ml-intern 开源** (2026-04-25) — HuggingFace 把 ml-intern 开源了，自动读 paper / 选 baseline / 跑训练 / 出实验报告一条龙，AI 研究工作流首次进入"自动 PhD 实习生"段
