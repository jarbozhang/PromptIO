# Moonshot / Kimi

Moonshot AI（月之暗面）是国内头部大模型公司之一，Kimi 智能助手是其代表产品。Kimi 系列模型（K 系列、K2.6-code）在国产 AI 生态中持续迭代，并在 2026-04 进入 Agent CLI 形态竞争。

## 关键产品线

- **Kimi K 系列** — Moonshot 主打长上下文与多轮对话的大模型
- **Kimi K2.6** — 2026-04-22 正式版偷跑发布
- **Kimi K2.6-code** / **K2.6-code-preview** — 编码方向子模型，2026-04-21 登陆 OpenRouter
- **[[kimi-cli|kimi-cli]]** — 2026-04-22 随 K2.6 正式版同步发布的官方命令行 Agent，对标 Claude Code / Codex CLI

## 近期动态

- **Kimi K2.6 正式版+官方 CLI 同步发布** (2026-04-22) — K2.6 凌晨"偷跑"，官方 kimi-cli 随之上线，中文社区对比 Claude Code / Codex CLI 配置与反常识点
- **Kimi K2.6-code-preview 登陆 OpenRouter** (2026-04-21) — 国产编码模型正面对标 Claude / GPT，OpenRouter 成为国产模型出海渠道
